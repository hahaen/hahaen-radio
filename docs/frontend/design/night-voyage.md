# 夜航设计规范

状态：2026-10-18 用户要求整体优化，沿用全屏地球构图、深海配色与字体角色；质感和交互调整见[页面整体优化](../../iterations/2026-10-18-visual-polish/README.md)。2026-10-16 已由用户确认初始视觉方向。阶段 4 已接入本地字体、立体地球、流派与双端构图；实际验证范围见[探索界面记录](../../iterations/2026-10-17-exploration-interface/README.md)，本文继续约束后续界面。

## 1. 视觉基准与适用范围

项目名称：声屿 HAEN。品牌标语：嗯，听听世界。

![夜航：电脑端与手机端概念图](assets/night-voyage-concept.png)

已确认的「夜航」以深海底色、立体地球和少量琥珀光点形成安静、沉浸的听觉探索体验。地球承担主要视觉表达，界面保持克制，不让装饰与播放操作争夺注意力。

- 本规范适用于后续页面、列表、搜索、弹层、播放器及其状态展示；具体功能范围由另行确认的功能规格决定。
- 概念图是视觉基准，不是整页背景素材。真实文字、控件和可交互场景分别实现，不能以图片覆盖页面代替界面。
- 图中的京都、电台名称、坐标、时刻、头像及上下曲等控件均为示意，不据此添加账号系统、曲目切换或其他功能，也不能作为真实业务数据。
- 图中的地理细节、文字及图标可能存在生成误差。实现时使用经核验的地理数据、语言资源与统一图标，文字规范、真实状态和可访问性优先于图片细节。
- 文字规则约束实现，概念图约束整体气质与视觉层次。主配色与字体角色继续沿用；本次核心构图按用户明确给出的布局要求与截图调整，见[全屏地球与紧凑播放器](../../iterations/2026-10-18-celestial-layout/README.md)。后续未被明确授权的视觉方向变化需先确认。

## 2. 颜色与设计变量

以下数值是对已确认风格的工程化约定，不宣称为图片逐像素取色结果。初始化前端时集中定义 CSS Variables，组件通过语义变量使用，不在各页面另配主题。

| 变量 | 基准值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#0B151B` | 页面深海背景 |
| `--color-surface` | `#15252D` | 播放器、浮层与输入区域 |
| `--color-text` | `#E8E9E1` | 标题、正文与主要操作 |
| `--color-text-muted` | `#A6B7B8` | 次要说明与坐标 |
| `--color-secondary` | `#83AAA3` | 辅助地理点与次级标识 |
| `--color-accent` | `#D8AD6B` | 当前电台、播放主操作及焦点强调 |
| `--color-on-accent` | `#0B151B` | 琥珀实心底上的文字与图标 |
| `--color-border` | `rgba(166, 183, 184, 0.18)` | 装饰分隔线与弱边框 |
| `--color-selected-bg` | `rgba(131, 170, 163, 0.12)` | 当前行的轻量背景 |
| `--color-panel` | `#14252D` | 图标工具与浮层底色 |
| `--shadow-panel` | `0 24px 80px #0005, 0 4px 16px #0002` | 收听卡片与浮层层次 |
| `--shadow-control` | `0 4px 18px #0001` | 搜索工具的轻量阴影 |

- 暖白是主要文字颜色，青灰为辅助，琥珀只用于少量重要位置；不得把整片背景或所有按钮都染成金色。
- 弱边框仅作装饰。输入框、可操作边界和焦点环不能仅靠弱边框识别，使用足够对比的描边、文字或形状。
- 错误、警告等语义状态须有文字与图标，后续根据实际状态补充语义变量，并核对暗色背景上的对比度；不能以琥珀同时表达所有状态。
- 不使用紫蓝渐变、大面积霓虹、强反射金属、重毛玻璃或高饱和多色光晕。

## 3. 字体、尺寸与组件质感

| 角色 | 字体方向 | 基准 |
| --- | --- | --- |
| 品牌与短标题 | `Noto Serif SC`、衬线回退字体 | 品牌 20–24px；展示标题桌面 48–64px、手机 28–36px，行高 1.2–1.35 |
| 界面与正文 | `Noto Sans SC`、系统无衬线回退字体 | 正文 16px、行高 1.5–1.7；导航与列表辅助信息 14px |
| 坐标、时刻与短标识 | `IBM Plex Mono`、系统等宽回退字体 | 12–14px，克制增加字距 |

- 字体已按角色本地分发并附 OFL 许可。中文子集覆盖两种界面文案，外国电台名与未覆盖字形使用系统回退；新增文案后按[字体文档](fonts.md)重新生成子集。
- 衬线字形用于品牌和短标题，避免把整页操作文字都变成衬线。桌面短标题左对齐，手机以当前电台为中心组织信息。
- 以 `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px` 建立间距层级。普通列表行至少 56px；触屏操作目标至少 44×44px，相邻目标保持足够间距。
- 主面板圆角 22–24px，图标工具 14–16px，选中行 10–12px；主播放按钮为琥珀色圆形。不把每一条信息都包成独立卡片。
- 使用 Lucide 线性图标，常用尺寸 20–24px、统一线宽。图标按钮必须具备可访问名称，顶栏采用纯图标按钮，保留可访问名称与悬停提示；面板内重要操作保留可见说明。
- 面板通过底色差、细描边与柔和阴影分层；列表使用留白与弱分隔形成秩序。浮层标题固定、内容独立滚动，手机端为底部播放控制预留空间，保持关闭按钮可用。

## 4. 双端构图

### 电脑端：全屏地球与角落操作

- 地球以视口水平中心为中心，画布不再受左右双栏或装饰边框限制；保持拖动、滚轮、双指与键盘操作，移除屏幕上的放大、缩小、重置和定位按钮。
- 左上品牌下展示当前电台地点、可核实的当地时间及地球/流派切换。没有 GeoNames 时区证据时显示时间占位，不以国家推断当地时间。
- 左下单个紧凑播放器包含电台名、地点、流派、码率、收藏、沉浸、分享、状态与详情，以及切台、播放、固定和音量控制。地图精度与覆盖数量、手势提示和地理署名放在播放器上方，随实际播放器高度定位。
- 右上搜索图标就地伸展成输入栏，输入后直接更新结果，兼容中文输入法。结果、收藏、帮助和设置均使用紧凑面板，保留页面背景和可用播放操作；支持 Escape 与关闭后焦点回到入口。
- 底部横向流派条显示类别、色点与真实可播放数量，支持单类别切换和完整筛选。流派数量遵循其他筛选条件，不把当前类别以外的数量全部清零。
- 主界面和沉浸界面移除曲目与歌词、手动识曲入口；已有后台接口与本地歌曲收藏数据保留兼容。

### 平板与手机：按空间重排

- 390×844、320×700 和 844×390 为响应式检查视口；顶栏图标保持至少 44px 操作目标，搜索展开占据独立一行。
- 地球保留完整轮廓，窄屏根据宽高比调整相机视野；播放区仍位于左下，窄屏使用可用宽度，底部流派标签横向滚动。
- 页面固定单屏。长电台信息在播放器信息区内滚动，播放操作保留在固定控制行；弹出面板独立滚动并考虑安全区。

## 5. 地球、动效与播放状态

- 采用暗色立体地球，以细点阵和轮廓细线呈现大陆，视角空间艺术明暗与柔和边缘光提供体积感，不表达实时昼夜。电台点和大陆点在边缘逐渐淡出，避免密集目录形成整片亮斑。底色保持深海色，外围允许稀疏、低对比星点，不增加装饰仪表。
- 电台使用青灰光点与柔和光晕，按位置错开缓慢明暗变化；选中地点使用琥珀点及轻量光环；通过大小、标签和列表选中状态辅助识别，不能只靠颜色区分。
- 标注随密度控制，避免地名重叠或大量标签遮挡地球。地理位置、名称和时区以经核验的数据为准。
- 悬停、焦点和普通控件反馈约 160–240ms，面板过渡约 220–320ms；优先使用透明度与位移，避免强烈弹跳、频闪及无意义漂浮；电台光点仅缓慢呼吸，每秒最多绘制约 30 帧，减少动态效果与省电模式下静止。
- 不强制持续自动旋转。若后续交互需要缓慢转动或视角过渡，用户操作时可停止，减少动态效果模式下去除非必要运动。
- 播放、暂停、连接中、缓冲及失败的视觉必须与音频引擎状态一致。无法分析实际音频时，不把装饰动画标成真实声谱或音量。
- 直播流不默认展示可拖动的曲目进度与固定总时长。播放器按钮、信息和状态由实际能力决定，风格不能制造虚假能力。
- WebGL 不可用或性能不足时，保留同一配色、文字、列表与播放器，通过静态地理画面承接氛围；不能让核心浏览与播放随装饰场景失效。

## 6. 实施与视觉验收

- 实现沿用 CSS Modules、CSS Variables、Radix UI、Lucide 和 Three.js 原生 API。设计变量、字体和场景已接入，本文不引入新框架。
- 先建立统一设计变量和基础组件，再扩展页面；后续搜索、收藏、设置等经确认的界面都继承本规范。
- 界面 Review 必须同时检查深海色层次、地球主次关系、字体角色、琥珀用量和留白，不能退化为通用深色后台或卡片仪表盘。
- 普通文字对比度至少 4.5:1，大字与必要非文字控件至少 3:1；核对选中、禁用、错误和焦点状态，所有核心操作支持键盘与触屏。
- 按实际功能覆盖电脑、平板、手机、窄屏和横屏，检查长名称、文字放大至 200%、弹层、底部安全区及减少动态效果。截图中的文字和操作不能被画布、播放器或软键盘遮挡。
- 后续验收记录视口、浏览器、设备、页面状态和真实检查结果；模拟视口与真实手机分开记录。地球、流派与播放器的检查结果见探索界面记录；真实设备的触摸、音频与后台仍待单独验收。
