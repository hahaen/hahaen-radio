# 刷新恢复与地球入场连续性

## 需求与实际变更

刷新恢复上次电台时，原实现先显示欢迎标题，再切换台名、工具栏、播放器与流派条；欢迎动画也会随状态切换被撤销。本次让已保存电台及有效分享链接直接采用收听布局。

- 等待电台详情时展示已保存的台名；不同电台的分享链接显示载入文案，不借用上次台名。地点、码率、详情与次要操作使用静态占位，播放按钮保持最终尺寸和位置，详情到达后仍暂停。
- 播放器公开当前请求的电台 ID 供恢复界面匹配；用户主动选择新电台、请求失败或取消时退出旧恢复占位，保留现有请求取消与禁止自动播放规则。
- 目录尚未就绪时数量显示破折号，数字区域预留宽度。
- 地球在首次实际绘制完成后标记就绪，通过独立的 450ms 透明度过渡显示；移除欢迎状态专属的地球缩放动画，避免恢复电台时中断。载入中不闪现平面地图，WebGL 失败仍保留降级图与重试。定位说明稍后淡入。
- 减少动态效果与省电模式关闭新增过渡。相同分组引用重复传入地球时跳过标记与柔光纹理重建。

## Review

范围仅限本次恢复展示、请求 ID、地球首帧就绪和相关样式及回归测试。检查首次访问、有效与无效分享、慢请求、失败、主动换台、StrictMode 生命周期、图形清理及动效偏好。缓存只用于展示台名，不代替服务端电台详情或音源。

## 验证

- 回归用可控延迟阻塞恢复请求；修改前能够复现欢迎标题闪现，修改后检查缓存台名、导航及播放位置稳定。
- 已完成 Chromium 的 9 项专项，包含 1440×900、768×1024、390×844、320×700、844×390 的首次打开与刷新，恢复前后播放按钮坐标差小于 1px；已人工核对上述尺寸截图，未见新增遮挡或横向溢出。
- 24 项相关组件、音频控制及图形单元测试通过；前端与浏览器工具 TypeScript、定向 ESLint/Prettier、Vite 构建通过。
- Chromium、Firefox、WebKit 共 81 项定向浏览器检查最终通过，包含刷新专项、首次欢迎、字体、收藏及恢复。首轮发现既有欢迎标题断言遗漏换行，已修正；3 项 Chromium 并发等待超时在串行复验中通过。
- 产物预算、文档链接与差异检查通过。同步最新主分支后，复审无未解决项；36 项三浏览器专项复验全部通过（刷新、恢复、分享、WebGL 降级与上下文恢复），24 项单元测试、类型检查、定向 lint/格式、构建及预算复验通过。

## 发布与未完成项

仅需更新前端静态资源（`radio-frontend`）；无需更新 `radio-api`、`radio-jobs` 或数据库，无配置迁移。本次未部署。

浏览器在 macOS 以 Playwright 无头模式和视口模拟运行，使用模拟目录及可控音源；尚未进行真机、生产网络或硬件 GPU 性能验收，不据此宣称实际设备的长任务耗时或帧率提升。
