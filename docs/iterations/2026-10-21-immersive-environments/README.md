# 全屏沉浸环境与地图地点说明

日期：2026-10-21。

## 需求与实际变更

用户认为唱片形式不适合沉浸收听，要求查看其他沉浸体验后重新设计；随后要求台湾电台悬浮显示“中国台湾”。

- 移除唱片、孤立球体和线条画，改为铺满视口的流光、潮汐、远山环境；场景在顶部直接切换，下方保留真实电台信息与磨砂播放托盘。
- 新增独立 Three.js 全屏环境引擎，使用单平面着色器、静态 SVG 回退、有限场景过渡、可见性/减少动态效果/省电管理和完整释放；沿用同一音频控制器，不开启额外分析或音频请求。
- 新场景偏好为 `aurora`、`ocean`、`dunes`，自动模式仍按流派选择。读取旧值时兼容映射 `record`、`orb`、`landscape`，不覆写旧原始记录；新选择保存到既有场景键。
- 地点统一通过 `countryName` 展示，`TW` 中文为“中国台湾”、英文为“Taiwan, China”；确切坐标点保留城市。新增鼠标点悬停预览，不改变选台与播放；指针拾取复用点击逻辑并按帧合并，触摸与拖动不走鼠标悬浮分支。

## 实际查看的体验

通过普通 Chrome 查看 [Endel 播放页](https://app.endel.io/player/focus)，实际可见铺满屏幕的几何动态环境、场景选择、定时与简洁播放操作；查看 [Poolsuite](https://poolsuite.net/)，实际可见视频环境与电台播放控制结合。将环境作为视觉主体、让信息与操作退到次要层级，是本轮采用的设计判断；未复制其素材或加入其服务。另访问的 Lofi 目前只呈现 Discord 推广入口，未将其旧版画面当作已确认现状。

## Review 与验证

审查范围限定本轮沉浸组件、样式、图形引擎、偏好兼容、地点命名与悬浮拾取、相关测试和文档。检查一次性懒加载、StrictMode 清理、模式切换不重建音频、场景时间暂停/后台冻结、帧缓冲限制、上下文恢复与销毁、窄屏标题/操作区域、双语和无障碍。

应用与图形/个人库 4 文件 25 项通过；完整适用回归 64 项通过，覆盖 Chromium、Firefox、WebKit 和手机 Chromium 模拟。包括三种环境与窄屏英文无障碍、五种视口、同一实际音频会话、动态画面变化、暂停/减少动态效果/省电停绘、上下文丢失/恢复、GL 资源释放、旧偏好和台湾两种精度悬浮。

测试代码补齐 canvas 模拟的 `this` 类型后，前端 TypeScript、定向 ESLint、`/radio/` 生产构建与静态资源预算通过。新增场景独立懒加载块约 约 7kB（gzip 约 3kB），未新增依赖或外部环境资源。复核补充了上下文丢失时隐藏黑色画布、首帧完成后再隐藏静态环境的处理，避免只保留 SVG 却被黑画布遮住；修正后 8 项场景生命周期/降级跨浏览器用例再次通过。另复用 4 项完整 30,000 标记/停绘/省电回归，均通过。当前无未解决 Review 问题；同步后 40 项浏览器复验与 25 项单元测试、类型、构建及预算通过。复核将可能出现负底数的 GLSL 平方显式改为乘法，避免不同驱动的幂函数差异；随后的一组 Chromium 省电检查暴露重复尺寸通知触发额外重绘，已对相同尺寸与 DPR 去重，修正后 8 项跨浏览器场景生命周期/降级用例通过；最终调整确保配置改变时即使尺寸相同也能唤起绘制，Chromium 两项受影响用例再次通过，最终类型、格式、ESLint、生产构建、预算和文档链接检查通过。34 个任务文件在远端同步恢复后逐字节一致；复审及后续修正均限定本次范围，无未解决问题。
