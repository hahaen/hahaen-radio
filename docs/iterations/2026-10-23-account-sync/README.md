# 可选账号登录与收听同步

## 需求与行为

- 提供统一“登录 / 自动注册”与退出，已有账号校验密码，新账号自动创建；入口在“我的收听”。未登录继续直接收听，现有本机收藏、历史、设置与文件导入导出保留。
- 登录时自动合并本机新增或更新的电台收藏、历史及兼容保留的歌曲收藏；每个账号记录本机已合并项目，重复登录不恢复已在账号中删除的旧收藏。
- 登录后收藏与历史保存在账号中；退出恢复独立的游客数据。设置、音量、睡眠、界面语言与画面偏好仍留在设备。
- 服务端使用版本校验写入，前端在冲突时合并本次增删与远端数据；历史按时间排序保留最近 100 个电台，电台与歌曲收藏各限 5000 项。
- 账号收藏或历史变更后延迟 400ms 同步；页面可见时每 30 秒、窗口重新聚焦和网络恢复时检查同步，也可手动立即同步。账号请求都带预期用户 ID，其他标签页切换账号后旧页面不能向新账号写数据。
- 网络失败保留此标签页的待同步快照，重新登录相同账号时重试；同步未完成不执行退出。待同步数据使用 sessionStorage，关闭标签页可能丢失尚未同步的数据；页面离开前有浏览器提示。已同步数据保存在服务器。

## 实现与安全

- 共享契约：账号输入、用户、安全错误码、收藏与历史、版本快照。
- 后端分层：accounts 路由、业务服务、Drizzle 仓储。新增 `account_users`、`account_sessions`、`account_libraries` 与 `0003_accounts` 迁移。
- 账号为 3–32 位字母、数字、下划线，统一小写；拒绝 test、admin、administrator、root、system、guest、support、service、security、moderator、webmaster、haen、api、www、null、undefined 及以它们开头的账号；密码为 6–128 个字符，使用随机盐与 Node.js 异步 scrypt（N=32768、r=8、p=3），支持密码管理器与粘贴。
- 256 位随机会话，数据库只保存令牌 SHA-256；Cookie 使用 HttpOnly、SameSite=Lax、30 天有效期，生产附加 Secure，Path=/，不设置 Domain。登出撤销服务端会话；登录轮换当前会话，同账号最多保留 10 个有效会话，登录时清理过期项。
- 修改接口要求 JSON 与自定义请求头，拒绝跨站 Fetch Metadata；不启用跨域凭据访问。请求响应禁止缓存，日志继续隐藏 Cookie，错误不暴露密码、SQL 或堆栈。
- 限制单账号及连接 IP 的 15 分钟尝试次数，最多同时执行 2 个密码派生操作；限流状态是单 API 进程内存，重启会重置。保留 `trustProxy=false`，经代理的连接 IP 可能共享预算；上线需在可信入口按真实来源配置辅助限流，不直接信任客户端转发头。
- 暂无找回密码、邮件验证、密码修改与账号注销界面。

3. 运行账号需要新表的 SELECT、INSERT、UPDATE、DELETE 权限；沿用现有服务端数据库环境变量，无新增密码或密钥配置。现有 Node 启动命令显式加载 `.env.local`；迁移命令加载 `.env.migration.local`。生产必须通过 HTTPS 使用登录 Cookie。
4. 数据库备份现在包含密码哈希、会话摘要与个人收藏历史，仍只存入受限备份位置，不进入 Git、前端或构建产物。
5. SQL 已生成；隔离库验证、开发库/正式库执行与发布结果分别记录，不能相互代替。当前尚未执行目标环境迁移或部署。
