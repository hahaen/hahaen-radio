# 产品说明与帮助

右下角“关于与帮助”提供关于、隐私及使用帮助。沿用夜航深海底色、衬线短标题、正文留白、原生模态焦点管理与 44px 操作目标；主题按钮横向排列，正文单列滚动，不改变探索主构图。

## 内容与实际行为

中英文正文统一放在 `apps/web/src/locales/i18n.ts`。说明免登录与本地保存、导入合并、浏览器直连电台、系统媒体曲目信息、背景与自动播放限制。帮助覆盖探索、固定、筛选、播放失败、睡眠和全部快捷键。打开说明不暂停播放，也不自动进入闲置沉浸。

隐私说明区分本站请求、浏览器直连电台及服务器向歌曲服务发出的请求；没有把第三方电台的处理规则描述为本站可控。收藏和历史不上传，不接入广告或访客行为统计。今后新增诊断收集或改变请求行为时，必须同步实际内容与验证。
