# 地球画布去除左侧裁切

日期：2026-10-22。状态：实现完成，适用验证通过；未发布。

## 需求与实际变更

用户要求去掉左侧遮挡，地球放大后可以延伸到文字后面，文字与按钮继续浮在上面。

原桌面画布从视口宽度的 18% 处开始，放大后出现垂直裁切边界。本次让画布覆盖完整舞台宽度，用相机偏移投影保留原有球面大小与 59% 横向中心；平板、手机保持 50% 居中与原有纵向布局。准星与停留选台计算共享中心位置，点击射线、选中标签沿用完整画布坐标。播放器保持透明，保留既有渐暗背景与按钮层级；WebGL 降级静态地图保留原有构图。

## Review 与验证

Review 限于画布样式、相机视野与准星距离计算、相关浏览器断言及本文档。核对桌面/手机断点、纵向桌面视野、射线坐标、标签边界、播放居中、缩放与销毁逻辑，无未解决问题。新增回归检查旧裁切区域在缩放前后的真实像素变化，以及完整画布边界和按钮可操作性。

- 56 项 Playwright 回归通过：Chromium、Firefox、WebKit 与移动 Chromium，覆盖画布完整边界、旧裁切区域像素变化、最大缩放、播放/暂停、跨电台居中、减少动态效果、省电、延迟加载、搜索与筛选操作。
- 截图检查覆盖 1440×900、1920×1080、1024×1200、768×1024、390×844、320×700、844×390。桌面放大后球面连续穿过左侧透明信息区，按钮可操作，无页面横向溢出。
- 12 项图形相关单元测试通过；前端与工具 TypeScript、定向 ESLint/Prettier、生产 `/radio/` 构建、资源预算、文档链接与差异检查通过。构建保留既有大包提示，预算未超限。
- 测试在独立副本及端口中使用合成电台和可控媒体夹具。首轮 Chromium 普通动画用例因执行超过 60 秒超时，单独复跑通过，随后完整 56 项批次全部通过；未放宽断言或测试超时。

同步两个远端后复审本次差异，任务代码与验证副本一致；在同步后的已提交界面上下文重新通过 4 项跨浏览器缩放回归、12 项相关单元测试、TypeScript、生产构建与资源预算。
