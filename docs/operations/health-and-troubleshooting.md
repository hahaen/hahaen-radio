# 健康检查与排障

## 健康检查层次

| 层次 | 检查范围 | 不能据此推断 |
| --- | --- | --- |
| 进程存活 | HTTP 进程可以响应 | 数据库和业务一定正常 |
| 服务就绪 | 配置、数据库连接和迁移版本满足要求 | 所有外部服务可用 |
| Web 入口 | HTTPS、HTML、静态资源与路由 | 音频已实际输出 |
| 后台任务 | 最近运行、租约、进度与失败状态 | 数据全部准确完整 |
| 用户端验收 | 浏览器、媒体、图形和网络实测 | 所有地区和设备都可用 |

计划设置 API 存活和就绪入口，实际路径、响应 Schema 与 Compose 配置在实现时确定。对外不暴露内部路径、凭据或异常栈。

## 排障顺序

1. 确认目标环境、发布版本、镜像和最近配置变更。
2. 检查 Caddy、API、任务容器及重启次数。
3. 按 requestId 或 runId 读取对应日志。
4. 检查磁盘、持久卷权限、SQLite 写锁与迁移版本。
5. 检查上游服务可达性与返回格式，再定位客户端差异。

## 常见问题分类

- 页面可开、API 失败：检查代理前缀、内部网络、服务就绪和契约版本。
- 页面资源 404：检查镜像内静态文件、构建路径与缓存策略。
- 数据库无法写入：检查运行用户、卷挂载、磁盘空间、只读设置和长事务。
- 音频失败：区分用户网络、上游地址、浏览器策略、编码和跨域分析权限。
- 图形空白或卡顿：检查 WebGL 能力、初始化错误、上下文状态与设备负载。
- 任务重复或停滞：检查调度实例数、任务租约、超时和恢复记录。

## 结果记录

记录系统、浏览器、设备、时间、版本、失败范围和重现步骤。检查项目按已通过、失败和未验证区分，修复后仅扩大到受影响的验证范围。

生产故障涉及数据恢复时转入[备份与恢复](../data/backup/backup-and-restore.md)，不以反复重启替代原因判断。
