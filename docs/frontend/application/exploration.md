# 夜航探索界面

## 实施方案与设计复核

本阶段沿用已确认的[夜航规范](../design/night-voyage.md)：深海 `#0B151B`、面板 `#15252D`、暖白 `#E8E9E1`、青灰 `#83AAA3`、琥珀 `#D8AD6B`。衬线 Noto Serif SC 用于品牌与短标题，Noto Sans SC 用于操作，IBM Plex Mono 用于坐标和时间；字体本地分发并保留系统回退。

```text
电脑：品牌与语言                         搜索入口
      当前电台与地点           地球 / 流派切换与缩放
      播放状态与说明           大地球、位置提示与准星
      搜索目录与地点列表按需以弹层展开
      底部播放器，始终可操作

手机：品牌与语言
      地球 / 流派与触屏操作
      当前电台、地点与播放状态
      搜索与电台列表通过顶栏弹层展开
      固定播放器与安全区
```

复核以地球作为唯一主要视觉重心，保留文字与地球的非对称关系；不增加装饰仪表、闪烁星空、虚构频谱或账号入口。大陆轮廓和点阵来自本地地形数据，实心电台标记来自原始坐标；缺原始坐标但国家已知的电台以空心国家聚合点展示，无法确定国家展示位置的电台保留在列表与流派范围内。初始实现与双端截图见[阶段记录](../../iterations/2026-10-17-exploration-interface/README.md)，国家级位置调整见[任务记录](../../iterations/2026-10-18-country-map/README.md)。

## 数据与交互契约

- 场景按完整目录版本与屏蔽规则摘要读取精简分片，详情与线路按电台 ID 获取。缓存只接受完整且一致的版本；损坏存储或缓存受限不阻断基本列表播放。
- 搜索、筛选、随机调台和场景使用同一候选集合；缺坐标的电台仍可搜索和播放。
- 地点聚合明确区分已知城市与坐标附近，不能将附近地点写成精确城市。
- 国家级电台仅使用独立展示位置，不改写原始经纬度、城市或时区。定位按钮可定位国家聚合点，点击后分页浏览同国家的低精度电台；不称为同城或附近，也不进行同城螺旋展开。
- 地球旋转稳定约 650ms 后调台；固定时仅停止自动选择，明确点击和播放器操作仍可选台。暂停后拖动不恢复声音。
- 切换视图不重建音频引擎；隐藏页面、改变数据、固定或销毁时清理待选计时与图形资源。
- WebGL 初始化失败或上下文丢失时保留搜索、列表与播放器，提供静态地理画面与恢复入口。
