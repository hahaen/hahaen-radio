# 电台地图地理位置修复

## 需求与实际变更

- 电台亮点应对应其地理范围；已知省/州的电台应显示在对应行政区内。
- 展示位置按可信坐标、省/州、国家依次确定。坐标先检查数值、国家和已匹配的省/州范围；明显冲突时使用已知行政区的大致位置。
- 新增 Natural Earth 5.1.2 的 4,584 个行政区名称、内陆三角形和范围索引。支持中英文、繁体、带声调名称、标准代码及明确的省名与城市组合；歧义名称保守回退。明确填写台湾、香港、澳门的中国电台使用对应地理单元，不回落至大陆。
- 省/州级电台按 ID 在所属行政区的安全内陆三角形内固定取样；按行政区分组，展示空心点和省/州级大致位置说明。仅知国家的电台继续在所属国家安全内陆范围取样。
- 展开同地点电台不再移动坐标亮点；详情不将已判定冲突的来源坐标展示为准确地图位置。
- 行政区数据通过本站静态资源读取，单次加载共享缓存、15 秒超时、4MiB 响应上限及运行时结构校验；分组与详情订阅加载状态。失败沿用地图降级与重试，列表和播放仍可用。
- 保留原始电台坐标、地区、API、目录缓存和数据库内容；不改变目录同步、播放或服务端地名补充。

## 边界与精度

国家校验采用半度网格，省/州采用四分之一度网格，包含边界单元并容忍相邻一格，避免海岸、边境和小岛的数值误差。这用于排除明显矛盾，不是精确行政测绘。近似亮点使用原始多边形内的安全三角形取样，与上述容差判断分开。

缺少省/州依据或名称无法唯一匹配时，只展示国家级位置；不从台名、语言或服务器 IP 猜省份。上游国家、省份与坐标均可能有错，本次检查不能替代逐家电台真实地址核验。

Review 只覆盖本任务的定位、分组、精度说明、地理资源与对应测试；保留工作区其他任务的视觉和沉浸改动。检查输入边界、歧义、原始数据不变、缓存/取消/失败恢复、批量绘制和资源释放。全量检查发现来源重名行政区，已保留歧义回退，并加入唯一来源代码以验证每个行政区。

Review 已通过，无未解决的本任务问题。最终复验结果：
