# 电台目录管线

实现位于 `apps/server/src/modules/catalog/`，共享契约位于 `packages/contracts/src/catalog.ts`。目录来自 Radio Browser，保留必要的数据来源署名，外部接口见[服务说明](https://api.radio-browser.info/)。

## 同步与发布

1. 通过 SRV 或 DNS 反查发现受限镜像，保留已知镜像作为最后候选；最多尝试 4 个镜像。
2. 每页最多 1000 条，单请求 20 秒、响应最多 4MiB；整轮抓取最多 5 分钟和 10 万条，达到上限而未读到结尾时拒绝发布。
3. 校验 UUID、字段长度、坐标及 URL，清理控制字符并按 UUID 去重。失效检查结果保留；不把 HTTP 自动改成 HTTPS，不保留含认证信息或私网字面量的线路。
4. 空数据、异常结构或异常记录超过 5% 时拒绝本镜像；镜像切换重新抓取，不混合失败镜像的局部结果。已有至少 1000 条上轮有效记录时，骤减超过 30% 的目录需要排查后处理。
5. 生成新版本，按 200 条一批暂存。每批先锁定租约并核对令牌，防止失去租约的旧进程继续写入。
6. 检查暂存总数后，在单一事务中更新注册表、版本状态和唯一活动版本指针。失败继续使用此前成功版本；下次从完整抓取重新开始，避免拼接时间不一致的局部数据。

上游分页不是事务快照，抓取期间的源数据变化仍可能影响边界记录；当前使用稳定 UUID 去重、完整结束检查和骤减保护，不能声称上游提供了强一致快照。

## 状态与保留

- 数据库保存 8 张业务表：版本、活动指针、分片实体、持久注册表、人工屏蔽、租约、任务记录和离线地名。
- 连续 3 次完整成功同步都缺失的电台标为不可用，注册信息仍保留，不能因单次客户端播放失败而全局下线。
- 人工屏蔽在 API 返回详情、分片、搜索和线路时覆盖应用，线路被清空；进程内屏蔽缓存最多 5 秒。
- 每次同步前清理 7 天以前的任务记录、超过 1 天的失败暂存版本，以及最近两版以外的成功快照；始终保护当前指针。最多每轮扫描 1000 个版本，长期未运行时可需多轮清理。
- API 在数据库内筛选与分页，详情按需读取，不先载入整个目录；场景摘要每片最多 1000 条且不含流地址。旧版本已清理时返回 404，客户端应刷新清单。
- 未确认城市和时区保持 `null`，附近地名与实际城市分别表示。离线地名导入和地图资源将在探索阶段补齐，当前不捏造城市和当地时间。

## 运行命令

先按[迁移流程](migrations/workflow.md)准备开发库与身份，再配置私有环境文件。

```bash
pnpm db:migrate
pnpm catalog sync
pnpm catalog status
pnpm jobs
```

调度时间为每日 UTC 02:00，默认不在任务进程启动时额外同步。手动命令与调度共用数据库租约：有效期 2 分钟，每 30 秒续租。源数据抓取被取消或续租失败后停止发布。

人工处理使用 `pnpm catalog block <uuid> '<reason>'` 和 `pnpm catalog unblock <uuid>`，只改变项目屏蔽记录。原因不出现在普通日志中；参数不接受远程 URL。API 身份只读，运维命令使用任务身份。

## 外部请求边界

只接受 HTTPS；解析后的每个地址必须为公网单播，实际连接固定到已校验地址，保留原主机名做 TLS 验证。每次重定向重新校验，最多 3 次，目录调用还限制到供应商镜像域名。DNS、响应体、连接均受时限和体积限制。

`REMOTE_DNS_MODE=system` 为默认方式。本机网络使用 Fake-IP 时，不将保留网段放入允许列表；可以显式选择 `https`，使用 Cloudflare 加密 DNS、校验证书并固定解析服务的公开引导地址，再校验所有最终地址。缓存不超过源记录 TTL 和 30 秒，仅保存最多 256 个主机。

该模式会向 Cloudflare 发送待解析的上游域名，不发送数据库配置或访客标识；正常系统解析可用时无需启用。协议字段见[Cloudflare JSON DNS 说明](https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/make-api-requests/dns-json/)。
