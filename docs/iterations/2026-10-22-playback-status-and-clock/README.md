# 播放状态动效与秒钟显示

日期：2026-10-22。

## 需求与实际变更

让“正在收听”旁的珊瑚色竖条在实际播放时错落起伏。沿用 19×14px 图标区域、颜色与状态文字，使用 1.1 秒循环的 CSS 背景尺寸动画；不新增定时器、音频分析、组件或依赖。暂停及其他非播放状态不运行该竖条动效，缓冲和连接继续沿用原有细线提示。

减少动态效果或省电模式下保留静态竖条。动画表示播放状态，不代表实时音频频谱。

中国时间增加秒，显示为 `HH:mm:ss`，按整秒校准更新。继续使用 `Asia/Shanghai`，中英文日期、农历、页面恢复校准与计时器清理保持原有行为。

## 品牌唱片跟随播放（同日追加）

按用户要求，左上角品牌唱片在实际 `playing` 时以 8 秒一圈匀速旋转，仅旋转 SVG，文字和橙色定位点保持固定。暂停、连接、缓冲和失败时停在当前角度，恢复播放后继续旋转；省电模式暂停动画，系统减少动态效果沿用全局规则禁用动画。

Review 覆盖品牌状态绑定、CSS 旋转与暂停规则、现有浏览器回归扩展，确认不新增计时器或音频实例，不影响链接语义和布局。验证使用固定生产构建快照与本地音频夹具，避免并行开发热更新干扰。

- 前端 TypeScript、定向 ESLint/Prettier、3 项应用入口单元测试、Vite 构建和资源预算通过。
- Chromium、Firefox、WebKit 的 15 项回归通过，覆盖 1440×900、768×1024、390×844、320×700、844×390；已检查五种视口的截图，品牌大小、文字与布局保持不变。回归实际采样旋转变换，并检查暂停后角度不变、缓冲、减少动态效果和省电模式。
