# 0005：匿名诊断采用事务额度与固定容量

日期：2026-10-17。范围：用户主动提交的精简播放故障报告。

没有登录与访客追踪时，诊断需要明确字段、可控写入量和无需长期访客标识的保护。仅允许电台、当前线路、固定故障与单次随机回执；不使用原始 IP、用户代理、音源 URL 或自由文本，报告不触发目录下线。

使用 MySQL 单例额度行串行控制每日 UTC 1000 条，回执唯一索引实现有效期内的重试去重。写入与额度在同一事务完成，不靠进程内计数约束重启后的调用。单次回执仅标识本次报告，不是持久访客身份。

报告以 10000 个固定槽位循环写入，数据库约束限制槽位、故障枚举和最长 7 天有效期。独立清理减少过期数据，但存储上限不依赖调度成功。有效期与物理删除分开说明：到期不进入摘要，停机时删除可能延后；容量满时可提前替换旧记录。

短时限流仅使用全局请求数与公开线路/故障键，不读取或保存访客 IP。免登录用户共享有限容量，不能承诺每人独立额度。需要改变保留、字段、容量或增加账号时，先评估数据边界并同步隐私说明与测试。
