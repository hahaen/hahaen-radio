## 独立检出与冻结安装

源提交2d83485cc2e518a1907744e8205c574876261c21，macOS arm64，Node.js24.9.0、pnpm12.5.1。使用本地Git克隆且不共享Git硬链接，检出状态干净；无node_modules、三个dist、私有环境文件或本地运维目录。依赖采用全新专用存储，pnpm install --frozen-lockfile在13.365秒成功；没有复制原工作区的node_modules或生成产物。

启动子进程仅继承必要系统路径、用户目录、语言、网络代理与证书设置，不继承项目DB_*、识曲、维护或发布变量。没有复制真实配置，也没有连接任何数据库。Playwright使用本机已有浏览器缓存，因此这是干净源码与依赖存储验收，不声称全新操作系统或浏览器冷安装验收。

在仍无私有配置且Git状态干净时，独立检出执行pnpm check，45.759秒通过：格式、Lint、TypeScript、53个通过的测试文件、219项普通测试、全部生产构建与资源预算。两个真实MySQL测试文件共10项用例按范围跳过，Vite大分包警告继续保留。之后只为忽略规则验证覆盖该检出的.gitignore，并在运行测试中创建不含凭据的临时环境文件；没有把这个阶段说成未改动的检出。
