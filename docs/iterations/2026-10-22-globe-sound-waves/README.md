# 地球播放声波与平缓收束

日期：2026-10-22。

## 需求与实际变更

- 选中电台周围添加三圈错峰扩散的细声波，单圈周期 4.8 秒，向外逐渐淡出。精确位置使用珊瑚橙，区域位置保持灰绿声波、空心定位与精度说明，不伪造精确台址。
- 整颗地球外缘增加三圈低亮度墨绿波纹，约 7.2 秒缓慢向外扩散；球缘同时以约 6.9 秒周期轻微呼吸。波纹跟随实际球体轮廓与缩放，地表、球体大小、定位环和刻度保持稳定。
- 首次播放与切台时沿用平滑转向，播放期间不自动旋转。暂停后恢复同一电台不再拉回中心，保留手动探索视角。
- 播放与暂停通过 900 毫秒渐变衔接；暂停收束结束后停止持续绘制。减少动态效果与省电模式直接保持静态，页面隐藏、场景停用、上下文丢失及销毁沿用原有停止与清理机制。
- 在现有 Three.js 循环中增加一个声波平面，复用几何和材质资源回收，不新增依赖、音频分析或逐帧 React 更新。动效表示播放状态，不表示实际音频频谱。

## Review 与验证

Review 限于地球引擎、播放与居中回归及相关文档，核对渐变中断、视角保持、区域精度、减少动态效果、省电、前后面可见性和资源释放。未发现未解决问题。

- 24 项播放与居中 Playwright 回归通过，覆盖 Chromium、Firefox、WebKit 和 Pixel 7 Chromium 模拟：选中声波像素变化、无可绘制电台时整颗地球外侧波纹、暂停延迟停止绘制、恢复同台视角保持、跨洲切台、减少动态效果与省电。
- 人工检查 1440×900、768×1024、390×844、320×700、844×390 截图，精确位置和区域声波均可见，播放控件可用，无横向溢出。
- 15 项相关单元测试、前端与工具 TypeScript 检查、定向 ESLint/Prettier、Vite 构建及资源预算通过。构建仍有既有大包建议，未超过预算。文档链接与差异检查通过。
- 浏览器验证使用基于任务开始提交的隔离源码副本、独立端口、模拟目录和可控音源，未使用真实外部电台作自动化验收。

补充整颗地球外围波纹后，8 项播放专项跨浏览器复验通过；测试单独采样旧大气边界以外的像素，确认外围波纹在变化。WebKit 响应式截图增加缩放后的绘制等待，避免捕获刚清空的画布。同步后复审确认地球实现未与其他界面变更冲突，已复验 6 项 Chromium 播放/居中用例及 15 项单元测试；最终外围着色器通过类型、lint、生产子路径构建和预算检查。
