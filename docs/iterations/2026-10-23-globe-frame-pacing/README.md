# 地球播放动效帧连续性

日期：2026-10-23。

## 需求与实际变更

用户反馈在页面没有操作时，地球播放动效仍有顿挫。实际引擎原先对所有绘制应用 32 毫秒节流，60Hz 下每隔一帧绘制、120Hz 下每隔三帧绘制，波纹和球缘也受此限制。

移除该统一节流，播放、有限过渡和交互沿浏览器刷新调度；拖动阻尼按经过时间换算，保留原有惯性衰减速度。球体大小、地表、声波颜色和周期不变；暂停渐隐结束、减少动态效果、省电、隐藏及非活跃状态沿用按需绘制和停止规则，不引入永久空转循环。

## Review 与验证

Review 仅覆盖引擎帧调度、阻尼、相关回归与文档；核对重复帧调度、暂停渐隐、减少动态效果、省电、资源释放和现有切台逻辑。未发现未解决问题。

- 修改前：受控 60Hz 时钟下，实际引擎 60 次刷新仅绘制 30 帧，回归用例明确失败。
- 本机 Chromium 有界面、Apple M1 Pro Metal 加速、1440×900、30,000 条合成目录及可控音源：修复前约 497.6 毫秒的 60 次浏览器刷新只绘制 15 帧；解除节流后约 496.9 毫秒绘制 60 帧。该结果仅说明本机短时采样，不是所有设备的帧率保证。
- 无界面 Chromium 在本环境使用 SwiftShader 软件渲染，其耗时不能代表用户设备的 GPU 表现，因此用有界面硬件加速采样做前后对比。
- 36 项 Playwright 回归通过，覆盖 Chromium、Firefox、WebKit 与 Pixel 7 Chromium 模拟：受控 60/120Hz 连续绘制、完整目录播放、暂停收束、省电、减少动态效果、跨洲切台和恢复同台视角保持。最终版本的本机 Chromium 采样为约 493 毫秒内绘制完整 60 帧。
- 检查桌面 1440×900 与手机 390×844 截图，沿用既有颜色、波纹和构图；响应式回归还覆盖 768×1024、320×700、844×390。
- 9 项相关单元测试、前端与测试工具 TypeScript、定向 ESLint/Prettier、生产 `/radio/` 构建、资源预算、文档链接与差异检查通过。构建仍保留既有大包建议，但未超过预算。

同步后复审未发现冲突；与最新页面代码整合后，7 项 Chromium 帧连续性与居中回归、9 项单元测试、生产子路径构建、预算及文档检查再次通过。
