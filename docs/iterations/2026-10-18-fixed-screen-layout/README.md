# 单屏收听布局

## 需求与变更

将收听页面改为固定一屏，禁止页面本身上下滚动，兼顾电脑、手机、窄屏与横屏。

- 页面使用动态视口高度，主体按播放器实测高度预留空间；地球填充剩余高度。
- 搜索、筛选、电台目录由顶栏「查找电台」或 `/` 打开弹层，选台后关闭；无坐标入口同样打开目录。
- 地点和流派电台列表改为模态弹层。弹层与过长的信息区域保留内部滚动，支持键盘关闭和焦点恢复。
- 沿用现有夜航配色、字体与桌面左右、手机纵向构图；没有接口、配置或数据库变化。
