# 可选响度校准与调台音效

## 需求与实际变更

补齐阶段 6 的音量统一与调台音效，沿用夜航设置面板和中英双语。两项均默认关闭，使用独立版本化偏好键，保持基础音量、既有设置和跨标签页同步。

音量统一读取当前线路的有界 CORS 样本，通过离线解码计算衰减；主 HTMLAudioElement 不接入分析音频图。每次最多读取 64KiB，网络阶段 4 秒，正常采样间隔至少 30 秒；同线路缓冲恢复保持冷却，未结束的解码不重叠。只降低较响样本，不放大安静片段，不承诺专业 LUFS 或实时逐帧电平控制。关闭或暂停恢复基础音量，旧线路和已取消任务的结果失效；HLS、无分析许可、无法解码或设备音量不可控时保留基础播放。

调台音效采用 110ms 低音量合成音。只有开启后从已有电台切换到另一台且有播放意图时发声；首次播放、同台重试、暂停选台、静音和零音量均不触发。暂停停止节点并挂起上下文，销毁关闭上下文；延迟恢复完成后仍检查当前意图。

技术边界见[可选音频增强](../../frontend/audio/enhancement.md)。新增中英界面文案已重新生成中文字体子集，随项目本地分发。

## Review 与验证

Review 仅覆盖本次新增音频模块、引擎与协调器接入、设置、存储、双语、字体、测试及文档。已修正增强状态通知重复报告暂停而取消加载中播放意图、延迟恢复的音效上下文在暂停后仍运行，缓冲恢复重复采样绕过冷却，以及设备在基础音量为 1 时忽略实际衰减却误报生效的问题。跨域样例显式使用不匹配的允许源，避免测试工具自动补上许可；有限音源的循环只在测试钩子中启用。

格式、Lint、类型检查、132 项普通测试、前后端生产构建与文档链接检查通过。完整浏览器回归 189 项通过、3 项桌面触摸合成不适用；新增增强用例 16 项均通过。设备忽略实际音量的边界修复已有单测；修复后再次执行音频、设置与增强回归，113 项通过、3 项桌面触摸合成不适用。Vite 仍有大于 500kB 的分块提示，完整性能预算留待阶段 8。六项 MySQL 集成用例本次不适用，没有后端持久化访问或表结构变更。

同步后复审修正了零音量恢复与解除静音时使用旧状态判断音效解锁的问题，132 项普通测试与构建复验通过。首次同步后浏览器复验出现 1 次 Firefox AAC 媒体时钟停在零点，音源网络均返回完整 206；独立媒体事件诊断 8 轮、16 次播放均推进，同场景追加 12 次三并发复验全部通过。随后同步后整组复验为 113 项通过、3 项桌面触摸合成不适用。该偶发现象的根因仍未确证，已列入阶段 8 长期稳定性观察；不将重复通过视为根因已修复。

真实外部线路从开发目录只读取得，三浏览器分别执行同一 MP3 候选：Firefox 实际播放且校准生效，基础音量 0.07、样本输出约 0.048；WebKit 实际播放但分析不可用，保留 0.07；Chromium 此次线路播放失败（原因未确证），不能将其算为增强成功或据此推断全目录情况。Firefox/WebKit 观测有媒体时间推进且 error 为空。未持久化原始音频，仅记录状态；媒体可解码与实际扬声器听感仍是不同验收项。

本项目短 MP3 前 64KiB 的独立离线解码实验在三浏览器成功；可控 WAV 样本的实际解码、输出衰减、禁用恢复、跨标签页、跨域失败和能力缺失另行验证。真实线路的网络、编码和 CORS 差异不能用可控样例代替。
