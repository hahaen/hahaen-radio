# 夜航设计规范

状态：2026-10-22 完成[收听页面布局优化](../../iterations/2026-10-22-listening-layout/README.md)，同日按用户要求将地球改为真实精确坐标的连续柔光分布，所有缩放级别仅对悬停或选中位置显示目标定位符号，本轮实现与最终验证状态见[地球柔光分布与交互定位](../../iterations/2026-10-22-globe-radiance/README.md)。用户已确认电影感夜航方向，当前基线为暗墨绿背景、暖白文字、珊瑚橙强调色、连续暗色陆地与柔光分布、透明收听区；全系统范围见[全系统样式统一](../../iterations/2026-10-18-unified-visual-style/README.md)。早期概念图仅保留为历史材料，后续实现以本文和当前组件为准。

## 1. 适用范围

项目名称：声屿 HAEN。品牌标语：嗯，听听世界。

本规范覆盖地球、搜索、收藏、历史、设置、帮助、筛选、播放器和沉浸画面。沿用已有业务能力、真实电台信息与地理精度说明，不通过样式变化添加账号、音频或其他未经实现的能力。

- 按钮使用圆形或胶囊轮廓，表单输入与选择使用 10px 圆角；浮层使用 16px 圆角、14% 暖白细边框、28px 背景模糊与 125% 饱和度与柔和阴影；内部统一 20px 无衬线标题、14px 正文、13px 操作和 12px 辅助说明。桌面内边距 24px，手机 18px。
- 播放器不加实心卡片背景、边框或独立卡片阴影。全屏背景底部渐暗，承托电台文字。
- 普通文字与背景维持 4.5:1 对比度；一般控件焦点有明确的珊瑚橙轮廓，搜索输入与清除按钮改用灰绿焦点，遵循用户去掉红圈的要求。颜色变化不能代替文字、选中语义或播放状态。

## 3. 字形与层级

- `Inter` 为拉丁界面与品牌字形，中文优先系统 `PingFang SC`，以本地 `Noto Sans SC` 回退。品牌中文与电台展示标题采用本地 Noto Serif SC，品牌拉丁字使用 Inter。桌面电台标题 48px、400 字重，超长标题 32px；正文和操作文案保持无衬线。
- 宽度 360px 及以下或高度 500px 及以下隐藏地球上的重复浮动台名，保留选中环与播放器台名，避免遮住地图信息。
- 手机电台标题使用 `Noto Serif SC` 与系统衬线回退，依宽度调整；较长名称允许换行，信息区独立滚动。
- 坐标、统计与时间使用本地 `JetBrains Mono`，保留 `IBM Plex Mono` 回退。桌面中国时间为 28px 实心字形，手机为 18px 实心字形；公历日期、星期与农历月日作为下一级文字，农历另起一行。
- 字体全部由本站提供，附 OFL 许可。普通构建和浏览不访问字体服务；覆盖与生成方式见[本地字体](fonts.md)。
- 图标沿用 Lucide；图标按钮具有可访问名称与焦点状态，悬停不承载唯一功能。

## 4. 页面与组件规格

### 首次进入

- 未选择电台且当前标签页尚未进入探索时，展示品牌、标语、欢迎标题、说明、开始收听和先浏览入口。欢迎与未选台标题统一为“把世界，听近一点。”，中英文按完整语义分行。背景使用安静的墨绿渐变与低亮度真实地球；地球尚未就绪时保持安静背景，不展示装饰场景的加载文案。地图操作长说明与地理署名链接不放在主界面；关于与帮助仅保留关于、隐私与使用帮助。品牌下方保持标语。
- 地球在首次绘制完成后以 450ms 透明度过渡显示，保持最终尺寸；首次欢迎文案与操作仍分批浮现，不阻塞开始或浏览。刷新恢复上次电台时直接显示缓存台名与收听布局，详情使用静态占位，分享链接不显示无关缓存台名。减少动态效果与省电模式关闭入场动效。验证见[刷新入场连续性](../../iterations/2026-10-23-startup-continuity/README.md)。
- 直接开始收听使用已有随机选台逻辑；先浏览入口展示完整工具。只在 sessionStorage 保存当前标签页的进入标记，拒绝存储时仍可在内存中使用。
- 已选电台、已进入探索或恢复电台时使用正常收听布局；欢迎界面不会改变音频自动播放约束。

### 桌面与平板

- 页面固定一屏。桌面边距随宽度在 32–64px 之间变化，1024px 以下为 24px；横屏低高度下为 20px。
- 左上为品牌和真实目录统计，1024px 以下收起统计以容纳工具；右上依次放搜索、带数量的收藏入口、设置与语言选择。帮助入口在右下角，底部流派条为其保留横向空间。
- 桌面宽度至少 1024px 时，地球画布覆盖完整视口宽度，通过相机投影保持中心位于视口宽度的 59%，缩放后球面可连续延伸到左侧透明收听区后方，不再在 18% 处裁切；平板与手机居中。768–1023px 且高度至少 600px 的平板将地球放在播放器上方，按实际播放器高度划分舞台，避免长台名压住球面。右上固定显示带秒的中国时间（`HH:mm:ss`，`Asia/Shanghai`、UTC+8）、日期、星期和农历月日，不依赖选台或电台时区；时钟下方不显示电台地址。欢迎页及低高度横屏也保留时钟，沉浸页沿用独立布局。
- 透明播放器在左下，桌面宽度最多 400px。播放状态先于标题；地点、流派、码率、详情、切台与次要操作逐层呈现。播放主按钮使用桌面 60px、手机 64px 的珊瑚橙实心圆形，播放与切台独占一行，收藏、沉浸与分享在下一行左侧，音量在右侧；细音量条保留 44px 高触控区；播放状态用信号符号和文字共同表达：实际播放时珊瑚色竖条错落起伏，暂停后恢复静止横线；减少动态效果和省电模式保留静态竖条，不作为实际声谱。
- 搜索/收藏/设置工具和地图工具使用 42% 墨绿轻磨砂、14px 模糊与 120% 饱和度；浮层保留更强的模糊，播放主按钮保持珊瑚实心。
- 底部流派条取消外围胶囊与底色，以顶部细线划分功能区，桌面为 40px 高、手机为 44px 高的横向滚动项；当前流派采用暖白实心底色和深色文字，其他项采用透明背景，筛选入口保留细描边。类别色点和真实数量共同标识类别。筛选面板在桌面从右下展开，手机放在收听操作区上方。
- 搜索结果、收藏、设置和地理分组使用浮层，各自独立滚动，关闭和标题保持可用。搜索采用单一浮层：可见标题、输入框、清除与关闭位于固定顶部，结果数量与紧凑筛选位于同一工具行，下方结果独立滚动；站名 15px，地点与流派放在第二行。桌面顶栏搜索入口显示图标、文字和已有的 `/` 快捷键提示；小于 1024px 收成图标按钮，不展开输入框、不移动其他导航；输入框使用 16px 字号与灰绿焦点边界，保留中文输入法、即时筛选、Escape 与焦点返回。

### 手机

- 390×844、320×700、844×390 为必需检查视口；页面随动态视口变化并考虑安全区。
- 品牌和主要工具共用第一行；搜索打开后从第一行工具下方显示完整搜索浮层。
- 地球使用暗色连续陆地与柔光分布，所有缩放级别仅显示悬停或选中目标的定位符号，手机与桌面保持同一规则。画布在底部控制区上方构图；当前电台名称使用 30–36px 衬线字，较长名称降为 28px，采用均衡换行。画布高度结合实际播放器高度调整，在小屏保持地球可见。中国时间、公历与农历置于顶部左侧，语言置于顶部右侧；打开搜索时暂时隐藏同一区域的时钟与语言，避免重叠；输入焦点沿浮层内的输入区域显示，保留一个显式清除按钮。地图精度置于收听区上方，目录统计收进地图信息。
- 保留直接切台、收藏、固定、分享、沉浸和音量操作，以及底部横向流派条。可用高度至少 600px 的手机界面将播放/切台/固定与收藏/沉浸/分享/音量分成两行，操作目标至少 44×44px；低高度横屏使用紧凑布局。播放器信息可滚动，播放操作不随长名称移出屏幕。
- 手机浮层使用可用宽度与安全高度，内容独立滚动，底部播放操作仍然可用。设置、收藏与搜索按 `--panel-controls-clearance` 为操作区预留高度，睡眠倒计时显示时额外留出一行。

### 地图信息

- 电台地点采用统一展示名称：`TW` 中文显示“中国台湾”，英文显示“Taiwan, China”；坐标点保留城市并附地区名。鼠标悬停电台点时只更新地点预览，不自动选择或播放，拖动和触摸沿用现有操作。

- 默认仅保留选点预览、位置精度、同地点电台入口与 44px 地图信息按钮。
- 拖动、双指缩放、滚轮或方向键操作地球时，收起搜索、收藏、设置、帮助、分组、筛选和手动展开的地图信息；保留目录加载/失败的必要信息，不改变播放或筛选值。
- 地图信息按需展开，包含目录统计、国家级数量与未知位置查找；点击外部、关闭按钮或 Escape 收起，显式关闭后焦点回到入口。
- 目录加载与失败时自动展示信息，重试与错误不会随折叠隐藏；使用完整缓存目录时保持折叠，不单独显示缓存提示。欢迎页隐藏整组地图工具。
- 浮层位于地图工具上方，可独立滚动；小屏限制高度，关闭按钮不被顶部工具覆盖。

### 沉浸收听

- 手机竖屏（宽度小于 768px、高度至少 500px）的潮汐采用月光、细碎水纹和倒影，远山采用完整屏宽的五层错落山脊与薄雾；不叠加独立同心圆或谐波线。静态降级沿用相同构图，保留既有配色和播放状态控制，详见[手机沉浸美化](../../iterations/2026-10-23-mobile-immersive-landscapes/README.md)。下述涟漪与谐波形态保留于桌面和低高度横屏。

- 三种环境与地球页共用墨绿、灰青与暖白方向：暗部保持安静，雾光局部提亮，避免大面积亮绿与偏黄高光。着色器从全局背景、表面、辅助色与文字变量读取颜色，经线性空间运算后统一输出；静态 SVG 与加载底色沿用相同变量。画面与验证见[沉浸收听配色](../../iterations/2026-10-22-immersive-palette/README.md)。

- 全屏环境占据整个视口，不再以唱片或孤立物件为中心；流光为缓慢移动的多层光帘，潮汐为地平线与渐远水纹，远山为雾中多层轮廓。沿用墨绿、灰绿、暖白与珊瑚操作色，场景不作为真实声谱。
- 顶部保留返回、三个环境切换与品牌；电台信息位于下方留白区，标题采用衬线展示字，底部沿用磨砂播放托盘。手机和横屏按可用空间压缩，英文窄屏保留完整可访问名称。
- 三种环境采用不同的声浪形态：流光为交织光带与游走高光，潮汐为水面扩散涟漪，远山为层叠谐波轮廓与微光。各自保持不同节奏与缓慢幅度变化；暂停时动态振幅收敛，横屏低高度时调整位置与幅度。声浪是播放状态驱动的装饰，不声称跟随实时音频频谱，不改变电台直连播放。
- 独立 Three.js 引擎使用全屏单平面着色器，目标最多约 30fps，画布总像素不超过 160 万。暂停、减少动态效果、省电或隐藏时停止持续绘制；用户切换场景使用有限过渡，减少动态效果和省电时直接切换。
- 场景不可用或上下文丢失时显示静态矢量环境，返回、收藏与播放器继续可用；离开时释放图形与监听器，不重建音频控制器。旧唱片、球体和山峦偏好兼容映射至新场景。

### 收听、筛选与辅助面板

- 电台收藏与最近收听采用等宽标签，名称与真实数量并排显示，保留带数量的完整可访问名称、珊瑚色下划线选中态、细分隔列表和简洁的导入导出区域。
- 空收藏、空历史与无搜索结果统一使用低调圆形线条图标、标题和简短说明；空清单不显示无效的批量处理按钮。搜索空状态保留重置筛选，收藏空状态保留导入入口。
- 设置使用低调的分组标题与右侧开关；睡眠时长为一组胶囊。错误、浏览器能力限制与定时反馈仍按真实状态展示。
- 搜索列表使用类别色点、站名、地点、类别和播放图标，不再使用方形图标卡片。
- 帮助与沉浸页继承相同色彩变量。沉浸中的唱片、星球与山峦使用墨绿、暖白与珊瑚橙组合。

## 5. 图形与动效规格

- 地球周围使用暖白与灰绿分层星空，包含固定分布的细星和少量柔光亮星，顶部与底部渐隐；十字亮星、光晕与背景雾光保持克制，手机进一步减少密度和亮度。星空位于地球画布后方，仅播放时轻微闪烁，暂停、减少动态效果、省电、隐藏或非活跃场景下静止，不阻挡地图交互。中心准星采用 24px 四角标记，默认低亮，悬停适度增强，键盘聚焦时保持清楚；减少动态效果时关闭其过渡。基础机制见[地球周围星空](../../iterations/2026-10-22-globe-starfield/README.md)。
- Three.js 原生 WebGL，38° 基础视野；初始相机和重置距离为 3.8，窄屏通过纵向视野换算保持中心。用户仍可拖动、缩放和键盘移动。
- 使用本地陆地多边形生成 2048×1024 单通道遮罩，球面着色器按经纬度采样。海洋受光面 `#071A18`、暗面 `#020908`、大陆受光面 `#214139`；左上侧光、低亮海岸线与渐隐的大气薄光拉开明暗。大陆装饰点为 1.2px、透明度 0.018，海洋装饰点为 1.2px、透明度 0.006，海岸线透明度 0.038；不展示经纬网。遮罩处理内洞、独立岛屿与南极边界，纹理随引擎销毁释放。
- 地形细节使用本站提供的 2048×1024、187,548 字节灰度 JPEG，由公开领域地形阴影数据缩小生成，完整保留全球经纬度范围与方向；该纹理用于地表明暗，不作为高程或位移数据。加载失败时保留基础球面与电台操作，浏览器不向外部底图服务请求资源；来源、哈希与加工记录见[资源元数据](../../../apps/web/public/geography/relief-source.json)。
- 所有缩放级别使用当前精确电台坐标生成的 2048×1024 柔光纹理，按经纬度栅格合并重复贡献，通过宽窄两层柔和扩散与非线性亮度压缩控制密集区域。纹理随目录数据更新，考虑经度环绕与高纬度距离；不在每帧重建。柔光仅作为位置分布的装饰表达，不作为定量统计。
- 普通独立点与区域圈在所有缩放级别隐藏，地表柔光持续作为主体，近景适度减弱亮度；仅交互预览与选中目标显示定位符号。精确位置保留柔边光核，省、州与国家级分组使用灰青空心环；区域选择保留“地区分组”说明，不显示精确坐标光核。桌面与手机采用相同的显现规则。
- 选中电台使用暖白细环、12 根短刻度、暖色光核和珊瑚小点，按实际画布维持可读尺寸；精确点的珊瑚状态点居中；旁侧显示锁定状态或地区分组、流派、码率与名称，随点移动、背面与出界时隐藏。
- 仅实际播放时，选中位置扩散三圈淡声波（单圈 4.8 秒），精确位置用珊瑚橙、区域分组用灰绿，整颗地球外围以约 7.2 秒周期扩散三圈低亮度墨绿波纹，球缘以约 6.9 秒周期轻微呼吸；地表、球体大小与定位环保持稳定。播放和暂停用 900 毫秒渐变衔接，暂停收束后停止持续绘制。首次播放与切台平滑转向，恢复同一电台保留手动视角；减少动态效果、省电时保持静态，页面隐藏与场景不活跃时停止绘制。装饰亮度不代表真实音频能量，见[地球播放声波](../../iterations/2026-10-22-globe-sound-waves/README.md)。
- 交互目标的定位符号随画布尺寸、缩放与受限 DPR 调整大小，悬停与选中位置保持辨识度。保留所有来源坐标、命中检测与选台能力；缺坐标成员只通过区域分组汇总，不参与柔光生成，不生成替代散点。本轮实现与验收见[地球柔光分布与交互定位](../../iterations/2026-10-22-globe-radiance/README.md)。
- 地球播放、转向与交互跟随浏览器刷新绘制，不统一限制在 30fps；拖动阻尼按经过时间换算，暂停渐隐完成后停止持续绘制。验证见[帧连续性修复](../../iterations/2026-10-23-globe-frame-pacing/README.md)。
- 省电模式关闭海洋装饰点阵并降低大陆精度；减少动态效果、页面隐藏、场景切换和销毁沿用既有资源管理规则。
- 图形是独立实现，地理、目录、字体渲染和设备差异会影响最终画面。不宣称逐像素相同。
- WebGL 不可用或丢失时保留静态地理、列表和播放器。动画只表达实际播放或场景状态，不将装饰图形标记为真实声谱。
