# 夜航界面整体精修

日期：2026-10-21。

## 需求与实际变更

继续提高页面美观度，在现有夜航配色与全屏地球构图内，强化地球质感、品牌识别、浮层排版和播放操作的主次。

- 品牌采用细描边唱片标记、珊瑚色点、中文衬线字与紧凑拉丁字，统计和标语与字标对齐。
- 桌面电台名称使用本地衬线字，调整行高与上下留白；手机保留既有长标题换行与信息滚动。
- 播放按钮采用描边外圈与珊瑚实心内圈，播放中保留轻微外晕；静态信号符号与真实播放状态关联，不模拟音频分析。
- 减少背景装饰点的亮度，以更柔和的墨绿光场和侧面渐暗承托电台信息；底部流派以轻分隔线组织，桌面视图切换补充图标。
- 沿用原有播放、换台、收藏、筛选、地理精度、时钟、键盘与减少动态效果行为，无新增依赖或外部字体请求。
- 按用户要求移除地图操作长说明、缓存目录提示与主界面的地理署名链接，使用缓存时不自动展开地图信息；关于与帮助仍保留资源署名，加载失败与重试保持直接可见。
- 合并已授权的歌曲清单移除：我的收听只保留电台收藏和最近收听，保留已有歌曲数据和文件兼容性。
- 地球使用一致的左上侧光、渐暗半球与定向薄边缘光；降低海洋装饰点，增加低亮度 30° 经纬网。经纬网为单个批次，省电时关闭，沿用已有资源销毁。国家级空心电台点进一步收细、减弱亮度，完整标记数与精度语义保留。
- 搜索、收藏、设置、帮助与筛选共用 23px 衬线标题、14px 正文、13px 操作、12px 辅助说明与 24px/18px 双端内边距；统一关闭按钮、分组和选项间距。收藏改为横向双标签，筛选在窄屏保留两列可换行选项。
- 清理隐私与资源署名中的旧歌词、识曲操作指引；保留系统媒体曲目元数据说明，历史歌曲随导出文件兼容保留。

## Review 与验证

Review 范围为本次 App 标记与样式、歌曲清单移除、地图说明精简、回归用例、设计规范及导航，核对响应式选择器、状态表达、装饰语义、播放控件和沉浸页面复用。先审查后验证，每轮修正重新审查。

审查修正了品牌变宽后的平板搜索空间：中等宽度收起目录统计，展开搜索允许按实际空间收缩。确认地球新增几何与材质进入统一释放集合，省电隐藏经纬网；歌曲视图删除不改动存储模型和文件契约。当前无未解决的代码审查问题。

| 检查 | 结果 |
| --- | --- |
| 视觉、空状态、帮助、欢迎和缓存回退 | 四浏览器共 96 项场景最终通过；含 1440×900、1280×720、390×844、320×700、844×390 及大字模式 |
| 收听控制与历史兼容 | 四浏览器 36 项通过，覆盖设置、睡眠、快捷键与沉浸、筛选、收藏状态、恢复与历史歌曲导入导出 |
| 地图与流派最终复验 | 四浏览器 16 项通过：完整标记、国家级精度、分组分页、省电、旋转缩放、停绘、DPR、WebGL 降级与流派暂停状态 |
| 相关单元测试 | 6 文件 33 项通过，覆盖应用、存储、目录缓存和地图模型/标记/密度 |

初批浏览器检查有两项因验证批次共用产物目录导致录制文件丢失，两项因并行负载超过整例时限；隔离产物目录并串行重跑原用例后四项均通过，未修改业务代码或放宽断言。检查批次有重叠，不合并为独立场景总数。

同步 upstream 与另一目标远端均无新增提交，36 个任务文件恢复后摘要逐一一致；同步后仅针对本任务差异复审，无冲突或未解决问题。同步后 12 项四浏览器定向用例、33 项相关单元测试、前端类型、生产构建、预算、文档链接与差异检查再次通过。
