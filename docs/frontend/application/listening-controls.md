# 收听设置与系统操作

## 构图与范围

沿用夜航深海 `#0B151B`、面板 `#15252D`、暖白 `#E8E9E1`、青灰 `#83AAA3` 和琥珀 `#D8AD6B`；短标题衬线、界面无衬线、倒计时等宽。设置使用已有模态面板与左对齐表单，播放器提供 44px 设置入口与剩余时间。手机沿用纵向重排，矮横屏将唱片与电台信息并排，实际播放器高度继续用于正文占位。

```text
播放器：当前电台 / 状态与睡眠剩余时间     传输控制     音量 / 设置
设置：界面语言 → 收听语言 → 音量与提示 → 睡眠 → 快捷键说明
沉浸：退出入口 → 唱片与真实电台信息 → 原有播放器
```

不新增装饰性状态卡片。唱片只表达收听氛围，随实际播放状态转动，减少动态效果时静止，不表示声谱或歌曲进度。沉浸与设置不重建音频引擎。

## 交互不变量

- 刷新后的上一站使用成功收听 ID 恢复导航，不用伪造完整电台字段；分享台优先，失败与暂停不擅自恢复声音。
- 偏好按版本保存，音量与静音双向同步时避免反馈循环。收听语言继续使用统一筛选集合；音量统一和调台音效在音频增强阶段实现后接入。
- 睡眠支持关闭和 15/30/60 分钟，按截止时间核对，页面恢复、焦点与可见性变化触发复核。到期记录与取消记录不同，保证另一标签页不会把到期误当作取消；不承诺系统挂起时精确执行。
- 快捷键忽略输入框、选择框、可编辑内容、中文组合输入、重复按键和修饰键；保留按钮、链接及画布的原生键盘操作。Enter 进入沉浸，Esc 返回。
- Media Session 按能力逐项注册，提供真实电台信息及播放、暂停、上一站、下一站；不虚构直播时长或歌曲位置。不支持时核心操作仍可用。
- 闲置自动进入默认关闭；启用后只在正在收听、页面可见且没有面板或编辑操作时，约 30 秒无操作进入沉浸。用户活动与页面恢复重新计时。

实际实现、验证及未完成项见任务记录和产品进度。
