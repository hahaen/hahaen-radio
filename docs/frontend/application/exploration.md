# 夜航探索界面

## 实施方案与设计复核

当前沿用[夜航规范](../design/night-voyage.md)：墨绿背景、暖白文字、灰绿辅助色与珊瑚橙强调。界面采用 Inter 与中文无衬线回退，手机电台大标题使用 Noto Serif SC，坐标与时间使用 JetBrains Mono；字体由本站分发。

当前构图以视口中心的大地球为主，左上显示品牌，右上显示中国时间、公历与农历；左下播放器整合电台信息与操作，其上显示地图位置、覆盖数量与署名；右上图标展开搜索或紧凑面板，底部放流派筛选标签。窄屏保持地球完整和首屏播放操作。最新调整见[全屏地球记录](../../iterations/2026-10-18-celestial-layout/README.md)。

地球外围使用稀疏星点，电台逐点使用柔和光晕及错开的缓慢明暗变化。减少动态效果、省电、后台标签页和不可见视图下停止非必要动画。地图保留手势与键盘交互，移除放大、缩小、重置和定位按钮。来源坐标与省/州、国家分组分别显示，不用随机散点代替缺失台址。

2026-10-22 起仅保留地球探索，移除顶部视图切换、流派星云及 G 快捷键。旧的流派视图偏好兼容读取为地球，音量、静音等设置保留；底部流派筛选与电台分类信息继续使用。见[任务记录](../../iterations/2026-10-22-remove-genre-view/README.md)。

## 搜索结果分页

搜索面板保持每页 30 台，使用数字页码直接跳转，保留上一页、下一页及首末页禁用状态。宽面板展示连续五页、必要的省略号与末页；页码随当前页移动，点击第 5 页即可看到第 6 页，窄面板按可用宽度保留连续邻页，点击目标保持至少 44px。当前页使用暖白实心底色及 `aria-current="page"`，普通页码使用灰绿文字，箭头采用细边框圆形按钮。搜索或筛选变化后返回第一页。实现与验收见[数字分页记录](../../iterations/2026-10-23-station-pagination/README.md)。

## 数据与交互契约

- 场景按完整目录版本与屏蔽规则摘要读取精简分片，详情与线路按电台 ID 获取。缓存只接受完整且一致的版本；损坏存储或缓存受限不阻断基本列表播放。
- 搜索、筛选、随机调台和场景使用同一候选集合；缺坐标的电台仍可搜索和播放。
- 地点聚合明确区分已知城市与坐标附近，不能将附近地点写成精确城市。
- 通过范围校验的来源坐标逐台定位；缺少或冲突坐标的电台按已知省/州、国家各汇总为一个空心圆，锚点固定于区域内陆，与电台 ID 无关。悬停显示分组数量，点击进入全部成员的分页列表；选择、定位和光环使用同一锚点。分组不称为具体台址、同城或附近，不改写原始数据。
- 同坐标电台保留全部标记；展开列表不移动任何坐标，不截断成员数量。省电模式降低大陆细节与像素比例，保留电台数量；手机总览使用更细的点，放大后适当增大。
- 地球旋转稳定约 650ms 后调台；固定时仅停止自动选择，明确点击和播放器操作仍可选台。暂停后拖动不恢复声音。
- 进入沉浸不重建音频引擎；隐藏页面、改变数据、固定或销毁时清理待选计时与图形资源。
- WebGL 初始化失败或上下文丢失时保留搜索、列表与播放器，提供静态地理画面与恢复入口。

页面时钟固定使用 `Asia/Shanghai`，中英文界面均显示 24 小时制的 `HH:mm:ss` 时间与对应公历日期、星期和农历月日（含闰月）；切换电台不改变时区，时钟下方不显示电台地址。农历由浏览器内置 Chinese calendar 计算，公历和农历统一按中国时区跨日；不支持农历的运行时保留公历和时钟。对齐整秒更新，页面恢复可见或重新获得焦点时立即校准；电台详情仍仅在有明确时区资料时显示该台当地时间。见[中国时间记录](../../iterations/2026-10-18-china-clock/README.md)。
