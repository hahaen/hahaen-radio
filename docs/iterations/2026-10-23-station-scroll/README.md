# 电台搜索滚动加载

## 需求与实际变更

取消数字分页，改为在搜索面板内持续向下滚动加载，直到最后一条电台。

- 默认每批 30 台；接近列表底部 180px 时自动追加，保留已显示的条目。完整目录使用本地分批展示；远端路径使用 TanStack Query 的无限查询，保留各批数据和取消信号。
- 远端按响应 offset 与实际条数推进，按 ID 去重；达到总数或返回空批次即停止，避免空请求循环。完整目录加载完成后，保留先前远端已展示的条目数量。
- 待加载、错误重试和末尾提示沿用夜航样式；请求失败保留现有列表，停止自动重试循环。底部保留键盘与不支持 IntersectionObserver 时的加载入口。
- 搜索、筛选变化后重置滚动位置，本地显示范围重置；远端按条件隔离缓存，旧响应不能覆盖新结果。关闭面板释放滚动观察器。
- 删除数字页码组件及旧分页专项，替换为滚动加载回归。API 与数据库契约不变。

## Review 与验证

- Review 仅覆盖本次列表状态、滚动观察器、错误恢复、双语文案、样式与专项测试；已核对请求去重、取消、缓存隔离与观察器释放，无未解决问题。追加时禁用浏览器滚动锚定，修复 Firefox/WebKit 横屏自动跳到末尾的问题。
- 前端 TypeScript 检查、相关 ESLint/Prettier、Vite 生产构建、文档链接及差异空白检查通过；App 与目录衔接单元测试共 4 项通过。
- Playwright 专项 36 项通过，覆盖 Chromium、Firefox、WebKit、mobile-chromium；视口为 1440×900、768×1024、390×844、320×700、844×390。使用隔离模拟目录及可控音源，验证 30→60→75 条、滚动位置稳定、末尾停止、最后一台可选、重复条目去重、空批次停止、加载失败重试、搜索条件切换、键盘与无滚动观察器回退。
- 同步 upstream 后确认两个远端均无新增提交，任务文件完整保留；重新 Review 后，类型检查、4 项单元测试、生产构建、文档检查及 12 项远端加载边界回归通过。
