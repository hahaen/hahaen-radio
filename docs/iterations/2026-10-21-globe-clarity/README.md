# 地球亮度与清晰度

日期：2026-10-21。范围：前端地图材质与点阵；保持墨绿夜航风格。

## 需求与实际变更

目标为深色背景上清晰发亮的地球，改善大陆偏暗、海洋与边缘泛灰的问题，同时保留全部电台、精度说明、选择、旋转与缩放。

- 海洋改为更深且偏纯绿的受光面、暗面；降低表面泛白边缘光，缩窄外缘光，减少灰雾。
- 大陆点阵改为浅薄荷白并提高透明度，海岸线轻微提亮；海洋装饰点缩小并降低透明度，拉开海陆层次。
- 电台提高核心亮度、收紧光晕，使用普通透明混合限制重叠亮度。国家级空心点使用单独的尺寸与透明度系数，保留空心中心与精度说明。没有裁剪电台或改变坐标、标记数量、聚合与螺旋展开算法。
- 没有新增绘制层、几何体、纹理、后处理或逐帧状态；沿用 DPR 上限、按需绘制、省电与减少动态效果策略。
