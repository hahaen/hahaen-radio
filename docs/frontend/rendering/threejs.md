# Three.js 渲染约定

## 当前实现

`apps/web/src/graphics/globe.ts` 封装原生 Three.js 和 OrbitControls，`GlobePanel.tsx` 负责懒加载、状态与恢复。地形取本地资源，电台取完整精简目录，详见[探索目录](exploration-data.md)。

地球、轮廓与标记使用批量 Geometry；普通模式仅在真实播放时允许电台光点以约 30fps 低频呼吸；暂停、减少动态效果或省电时仅按变化申请帧，隐藏或切换到流派时停止地球帧循环。像素比上限为窄画布 1.5、宽画布 1.75；这属于控制参数，不等于已完成真实手机帧率验收。

选中环包含批量刻度、细环与着色器光核，旁侧 DOM 说明由引擎更新投影 transform 和可见性，不逐帧触发 React 状态；背面和画布边缘隐藏或换边。图形几何、材质沿用统一释放集合。

电台材质区分实心坐标点与空心国家级点，使用平滑球面邻域密度调节尺寸和亮度；缩放时恢复局部细节，选中点保留独立暖白细环、暖色光核与珊瑚色状态点。该过程不改变坐标、标记数或拾取对象。

地球使用本地陆地多边形生成的 1024×512 单通道 `DataTexture`，球面着色器按经纬度采样，区分连续陆地与海洋，不请求外部底图。扫描线保留多边形内洞、岛屿与南极边界；纹理关闭 mipmap、线性过滤、横向重复，销毁显式释放。侧光与薄球缘统一方向，大幅降低装饰点阵亮度并移除经纬网；省电仍关闭海洋装饰并降低大陆点精度。画面与双端验证见[电影感夜航](../../iterations/2026-10-21-cinematic-night/README.md)。

方向键、鼠标和触摸操作由引擎处理；候选稳定约 650ms 后选择，界面重新核对选择版本、暂停与固定状态。程序定位沿球面插值，减少动态效果时直接定位。销毁清理计时、观察器、监听、几何、材质、控件和上下文；上下文恢复只重建图形，不重建音频。

流派使用独立正交相机和单画布，各类别星云与 DOM 按钮中的装饰区域对齐。布局由 CSS Grid 管理，尺寸、内部滚动、焦点、悬停和当前类别变化时按需绘制；不通过拖动相机移动标签。桌面显示四列，窄屏按容器高度横向浏览；焦点滚动、无 WebGL 降级和上下文恢复共享同一组按钮。销毁同时释放观察器、监听器、几何、材质和上下文。具体画面见[地球与流派美化](../../iterations/2026-10-21-globe-and-genre-polish/README.md)。

## 技术与模块边界

使用 Three.js 原生 API、WebGL 2 和 GLSL。场景模块负责初始化、尺寸变化、数据更新、交互、帧循环和销毁。React 组件通过场景控制接口传递变化。

Three.js、附加模块及对应类型声明的版本需要匹配。渲染初始化失败时保留 DOM 界面和基本操作能力，实际降级表现随界面设计明确。

## 渲染与性能

- 大量点状对象优先使用 `Points` 和 `BufferGeometry`，重复几何使用实例化。
- 标签和复杂对象按距离、密度和可见性控制数量。
- 统一帧循环管理相机、动画和渲染，避免每个对象独立启动循环。
- 根据屏幕和设备能力限制像素比、粒子数量与后处理成本。
- 坐标转换、索引生成等适合的重计算可放入 Web Worker。
- 页面不可见或场景不活跃时减少不必要计算，返回后正确恢复。

具体帧率和设备预算待真实场景与目标设备确定后测量，不预先将目标写成已达到的性能结果。

## 坐标与交互

集中封装地理坐标、场景坐标和屏幕坐标转换。输入统一处理鼠标、触摸和缩放；拾取策略根据点密度选择射线或屏幕距离方法。

相机和渲染参数集中配置，界面层不直接修改内部对象。高频输入保持在场景内部，只在选择等语义状态变化时向外发事件。

## 资源生命周期

销毁时停止帧循环，移除监听器，释放 Geometry、Material、Texture、RenderTarget 和后处理资源。共享资源由明确的所有者释放，防止重复释放。

处理容器尺寸变化、WebGL 上下文丢失和重建。开发环境下 React 生命周期重复执行也应保持初始化与清理配对。


## 全屏沉浸环境

`graphics/immersion-scene.ts` 使用单平面程序化着色器绘制流光、潮汐和远山，`app/ListeningArt.tsx` 懒加载并连接模式、实际播放与省电状态。颜色、低频变化和水纹均是装饰，不接入或冒充实时音频分析。图形与音频控制器独立。

着色器中的 `soundWaves` 按场景分配动态形态：`lightRibbons` 绘制五层交织光带与移动高光，`tidalRings` 绘制五圈渐淡水面涟漪，`harmonicRidges` 绘制八层谐波轮廓与微光。动态与环境一起参与 700ms 切换过渡；潮汐地平线与水面遮罩对齐，低高度横屏单独调整。`waveActivity` 连接实际播放布尔状态，暂停时动态振幅收为零，减少动态效果和省电时随现有引擎保留静态画面。不新增 AudioContext、流请求、GPU 资源或逐帧 React 更新；仍沿用单次全屏绘制与既有帧缓冲限制。

环境最多约 30fps，帧缓冲上限 160 万像素；桌面 DPR 上限 1.25、窄屏 1、省电 0.65。暂停保留当前时间；减少动态效果和省电停绘；后台取消帧并在恢复后续绘，不累积隐藏时间。主题切换过渡为 700ms，减少动态效果和省电时直接切换。

静态 SVG 始终保留作为无 WebGL 或上下文丢失的环境。恢复后重新设置尺寸并重绘；离开时断开 ResizeObserver、媒体偏好和可见性监听，释放几何、材质与 renderer 并主动释放上下文。GL 探针只存在于浏览器测试，不新增生产调试接口。
