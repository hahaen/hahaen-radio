# LINUX DO 微应用协作规范

- 应用名称统一为「声屿 HAEN」。本目录维护 LINUX DO 入口、SDK 适配、直播清单和 ZIP 构建。与官网共用上一级 `src` 的界面、目录筛选、图形和播放器控制。
- 通过 SDK 和清单声明的固定 HTTPS 端点，从现有 `radio-api` 读取公开电台目录和详情。微应用端点复用官网目录服务，跨域范围限于 `https://linux.do`。账号和凭据留在原有业务边界。收藏和设置保存在 SDK 应用存储。
- 地图随包发布。目录下载完成后可在本次会话中筛选、搜索、同城和随机选台，重载或定时刷新时重新检查目录版本。
- 直播从官网目录里的电台详情校验来源，只连接有运营方公开依据且声明在 SDK 清单中的 MP3 端点。待验收候选只进入沙箱和本地检查包。正式候选需要记录桌面和手机的真实沙箱验收。试听由用户点击触发，在当前页播放。
- 本地隔离检查可用真实直播的短样本检验解码、调度和停止。真实沙箱验收需在 LINUX DO 内执行。
- 仅本目录受影响时，只构建微应用。共享代码变化时，检查并更新受影响产物。官网上传目录与微应用 ZIP 输出必须分开。应用 ID 只从 Git 忽略的仓库根 `.env.local.linuxdo` 读取。应用 ID 配置与生成的 ZIP 都留在本机。正式上架由用户操作。
