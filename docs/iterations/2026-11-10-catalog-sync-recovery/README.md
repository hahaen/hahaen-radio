# 电台目录同步恢复

生产每日目录同步在获取上游分页时失败，线上继续读取上一份成功目录。生产任务容器实测首批及中间位置的 1,000 条分页约 63–86 秒返回完整响应，超过原来的 20 秒单页时限。

单页时限提高至 120 秒，首个分页成功后最多并行抓取 4 页，按偏移量顺序处理。遇到目录末尾时忽略其后的并发结果。重试次数、单页体积、镜像隔离、数据校验、目录骤减保护和原子发布继续沿用现有流程。正式任务通过 `CATALOG_SYNC_TIMEOUT_MS` 配置 45 分钟整轮上限，本地默认仍为 5 分钟。

服务端 221 项测试通过，覆盖并发窗口、乱序响应、分页末尾、镜像切换、重试与整轮取消。类型检查、构建、改动文件的 ESLint 和格式检查、文档链接检查通过。

2026-11-10 生产已发布 `radio-jobs` 版本 `8a44dec903a9925593f5c72c185f672e3ea4e6b9`，确认新时限和调度器启动。生产手动补跑用时 20 分 52 秒，读取 53,400 条上游记录，校验过滤 2 条。生产库记录 `succeeded`，公开目录和就绪接口一致返回新快照 `0e6e045d-d9e2-42bd-9d5f-1ee29f76ef6c`，含 72,088 条电台。自动任务继续每日北京时间 10:00 调度，下一次自然触发尚未发生。

前端和 API 无需更新，无数据库结构迁移。
