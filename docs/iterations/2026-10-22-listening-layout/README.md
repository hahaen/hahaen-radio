# 收听页面布局优化

日期：2026-10-22。状态：实现完成，适用验证通过；未部署。

## 需求与设计

优化整体页面的构图、字体层级、工具与浮层一致性，同时保留地球探索、真实目录和收听能力。沿用墨绿 `#081310`、表面绿 `#142923`、暖白 `#F5F1E8`、灰绿 `#B3C1B7`、辅助灰青 `#91AAA0` 与珊瑚橙 `#F36B45`。本地衬线字体负责电台标题，Inter 与中文系统字体负责界面，等宽字体限于时间和数据。

桌面保持左侧透明收听区、右侧地球的构图。手机保持地球在上、台名与播放在下；平板竖屏单独划分上下区域，避免套用桌面布局后标题与球面重叠。装饰保持克制，以真实地球作为视觉中心。

## 实际变更

- 桌面边距调整为 32–64px，收听区最多 400px，标题提升至 48px，时钟缩至 28px。欢迎与未选台文案统一，并按语义换行。
- 播放、切台与固定为第一层；收藏、沉浸、分享和细音量条为第二层。保留键盘操作与音量真实值，手机主要操作保持至少 44px。
- 桌面搜索入口增加文字和 `/` 快捷键提示，小尺寸保留图标。搜索面板增加可见标题，统一行间距、播放标记与输入区。
- 搜索、收藏、设置与其他浮层共用更安静、不透杂乱背景的底色和细边框。底部流派条取消外层胶囊，选中类别改为暖白底深色字。
- 手机设置与收藏浮层为播放器预留独立空间，开启睡眠倒计时后增加预留高度；搜索面板沿用相同预留变量。
- 平板按播放器实际高度划分地球舞台，回归断言要求舞台不进入收听区。低高度横屏适当减小台名，保留信息滚动。
- 没有修改电台位置、目录接口、播放引擎、数据库或外部服务配置。

## Review 与验证

本次 Review 限于五个前端实现文件、平板与浮层布局断言及配套文档。检查响应式层叠、长名称、双语、原生 range 行为、焦点、减少动态效果和沉浸播放器复用。截图检查发现并修复了未选台标题断行、平板台名覆盖地球、手机欢迎页署名与帮助入口挤占空间，以及手机设置面板遮住播放键上沿的问题。设置浮层修复前断言实测面板底部 656px、播放键顶部 638px；新增断言同时检查睡眠定时开启和关闭时的边界。

浏览器批次存在重复场景，不将重复次数称为独立用例总数。首次 3 worker 扩展批次出现 4 项 Chromium 超时；单 worker 最小复现 4/4 通过，随后 64 项完整补充批次串行通过。没有为通过测试修改业务行为或放宽断言。

测试复用现有本地 Vite 服务，临时 Playwright 配置仅关闭自动启动服务；目录、媒体与异常响应由已有夹具在浏览器上下文拦截。桌面、平板、手机、窄屏、横屏分别为 1440×900、768×1024、390×844、320×700、844×390，另覆盖中英文、英文 200% 文字、减少动态效果、键盘和 WebGL 降级。浏览器模拟不替代真机或外部电台线路稳定性验收。
