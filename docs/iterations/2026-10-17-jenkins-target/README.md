# Jenkins 目标交接与独立审批

## 需求与实际变更

接通根 Jenkinsfile 的默认关闭目标阶段：同任务先完成工程/隔离镜像检查、人工分发，再单独确认目标站点、配置指纹、源提交、范围和交接摘要。审批前不分配目标节点；审批上下文和四项默认false的操作确认保存在CPS Map，目标阶段用明确withEnv重建，避免节点环境覆盖已批准范围。

构建节点 seal 关联同run的build/image-check/release、源和迁移摘要，交接只传严格字段的脱敏JSON。目标节点从同提交干净检出冻结安装/构建，accept核对原始文件SHA及上下文，恢复600私有文件后才绑定独立只读拉取凭据和加载工作区外的Node环境。编译入口在连接数据库前再核对实际配置指纹与批准文件SHA，target配置站点也须一致。

已有文件/数据库release锁仍由目标执行器覆盖完整维护窗口；没有将停写、备份、迁移拆成绕开入口的Jenkins命令。无新增自动触发、状态性retry、历史“最近成功”产物选取或阶段重启。回退和恢复仍须通过明确的既有流程操作，不自动执行。

新私有环境模板只含变量、用途和空值；支持常见@2工作区路径，不把节点配置、凭据或备份写入交接和归档。公开导航、配置说明和执行顺序已同步，未修改SQL、Schema、API、播放器或页面。

## Review 与修复

范围仅本轮Jenkins DSL、交接CLI、连接前守卫、站点/路径兼容及相关测试/文档；读取既有产物、锁和目标执行流程作为上下文。核对默认关闭、同批产物关联、跨节点上下文、输入确认、凭据绑定时机、失败停止、精确归档和独占文件发布。

复审补齐build与交接上下文的提交/平台一致性，拒绝未知release字段；审批数据不从目标节点环境重新取值。macOS目录别名最初让工作区内环境文件通过了外置检查，定向测试暴露后改为实际路径核对并复验。Node环境文件拒绝进程启动/调试注入字段；目标节点改用新的独占空工作区，不在配置校验前删除旧文件，同时拒绝私有环境位于新旧工作区的情况。已结束工作区的受控保留/清理由管理员在确认进程状态后执行。

## 验证范围

完整工程检查通过：格式、Lint、TypeScript、209项普通测试、前后端生产构建；普通命令中10项MySQL用例按设计跳过，本轮未运行数据库验收。14项定向检查通过，其中新增6项普通测试。结果见[结构化证据](results.json)。新增原生Node CLI与文件测试覆盖：两个干净临时Git检出间的seal/prepare/accept、644交接恢复600、独占产物拒绝覆盖、原始字节/目标/站点/配置指纹/范围改变拒绝、旧批次混入和未知凭据字段拒绝、私有环境权限/位置/启动变量校验，以及实际文件SHA和配置指纹的连接前守卫。既有目标配置用例增加站点错配拒绝。

临时Git库、交接和模拟私有配置由测试清理。测试使用明确的夹具元数据，不调用Docker、Jenkins、数据库、sudo或真实目标；不把帮助工具通过当作实际发布成功。

本轮没有新增数据库查询或迁移写入；连接前校验为原生文件/摘要逻辑，独立MySQL验收仍以[上一轮](../2026-10-17-target-deployment/README.md)的已归档结果为准，不伪造本轮数据库执行。正式库/开发库均未执行本轮SQL，未触发远端任务、上传镜像或上线。

同步upstream没有新增提交，23个任务文件的内容、权限和空暂存状态完整恢复。同步后仅复审本轮差异，再次通过完整检查（209项普通测试、10项数据库用例在普通命令跳过）与97份Markdown/581条本地链接检查。最终文档复审明确区分镜像产物已分发和目标部署成功、构建目录清理和目标新工作区，并记录两类独立认证配置的实际生命周期。
