# 收听唱片图标随播放旋转

## 需求与实际变更

让播放控制区的沉浸收听唱片图标在实际播放时持续旋转。仅图标以 8 秒一圈匀速旋转，按钮命中区域与布局不动；暂停、缓冲时保留角度，恢复播放后继续。省电、减少动态效果、页面隐藏及进入沉浸画面时停止旋转。移除该图标原有的点击缩放反馈，避免覆盖旋转变换；按钮名称、键盘操作与沉浸入口保持原有行为。

## Review 与验证

- Review 仅覆盖唱片图标、CSS 状态选择器与相关文档；确认沿用真实播放状态、现有动效开关和旋转关键帧，不新增监听器或音频实例。未发现待修复问题。
- 通过前端应用与工具 TypeScript 检查、相关 ESLint、Prettier、Vite 生产构建、资源预算、文档链接及差异检查。构建保留既有大 chunk 提示，预算未超限。
- Playwright 临时检查共 7 组通过：Chromium 1440×900、768×1024、390×844、320×700、844×390，Firefox 与 WebKit 1440×900；人工查看全部五种 Chromium 视口截图。
- 检查实际变换随时间变化、按钮边界不变、暂停后角度保持与恢复续转、缓冲停止、减少动态效果、省电、模拟隐藏页面、无横向溢出、单音频元素和沉浸入口。
- 同步最新主分支后重新 Review，并复验类型检查、格式、ESLint、生产构建、资源预算及桌面/手机旋转交互。临时检查改为等待实际播放状态后采样，避免把连接阶段误判为播放。
- 使用可控目录与音源，未复验真实外部电台、真机触屏和系统后台行为。本次不改变音频与触屏逻辑。
