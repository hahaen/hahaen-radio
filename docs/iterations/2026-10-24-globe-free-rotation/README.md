# 地球连续球面旋转

日期：2026-10-24。

## 需求与变更

- 电脑网页、手机网页及 Android App 的地球，同方向反复拖动时应持续旋转。
- 共享引擎原先使用保持固定向上的轨道控制器，南北极存在极角边界；键盘方向键也限制纬向移动。已在修复前通过浏览器复现：连续向上拖动第 4 次，选中位置的屏幕投影移动量为 0。
- 改用独立的四元数球面控制器，同时旋转相机位置与上方向，鼠标、单指及方向键都可跨越南北极。方向随球面自然翻转，重置恢复初始位置、缩放与朝向。
- 保留按时间换算的拖动阻尼、滚轮/双指/按钮缩放距离边界、点击与停留选台。自动转向同步运输相机上方向，避免翻转后定位或重置发生极点退化。
- 触摸取消、失去捕获、场景停用、页面隐藏及销毁时清理对应手势与惯性；监听器和触摸样式按生命周期释放。
- Android 直接打包共享实现，versionCode 从 4 增至 5，版本名仍为 `0.1.0`，应用 ID 与签名配置沿用现有值。

## Review 与验证

本次 Review 仅覆盖新增控制器、共享引擎接入、浏览器/Android 图形回归、版本号与关联文档；检查连续旋转、相机方向、动画中断、缩放边界、多指切换、捕获释放、渲染停帧及资源清理。Review 与回归中修正了方向键方向、初始屏幕上方向、多指取消清理和方向键额外惯性，复审无未解决问题。

- 控制器单元回归 6 项通过：完整纵向转圈、过极后横向/斜向拖动、双指及滚轮缩放边界、多指取消后重拖、惯性收束/停用、拖动中销毁。
- 新增浏览器回归 24 项通过：Chromium、Firefox、WebKit 桌面拖动 1440×900，Pixel 7 触屏模拟拖动 390×844；键盘与点击场景沿用设备默认视口，桌面为 1280×720、Pixel 7 为 412×839，独立点击场景画布为 300×300。四方向各连续拖动 12 次，另验证连续键盘旋转、完整重置及鼠标/触摸点击选台。Chromium 手机拖动使用浏览器触摸事件协议，其余桌面使用鼠标。
- 既有受影响浏览器回归 40 项通过：三种动态模式下的播放定位和视角保留、延迟加载定位、60/120Hz 连续绘制、完整目录绘制、手机反复拖动、浮层关闭、固定电台及暂停后停留选台。定位用例还覆盖 768×1024、320×700、844×390。
- 同步修正两处测试准备：帧绘制测试为画布提供同尺寸父容器，避免桌面宽视口把球体投影到画布外；停留选台测试去掉与亚洲测试坐标冲突的默认英国归属，并独立模拟游客会话。生产地理校验与账号实现未改。
- Android 独立图形入口 6 项通过，覆盖连续触摸过极、双指缩放、沉浸往返、隐藏停绘、上下文丢失与重建；单元测试 48 项、Android Lint、Debug 与正式签名 Release 构建通过。并发运行时出现的浏览器超时已在隔离复验通过，未放宽断言或超时。
- 前端 TypeScript、定向 ESLint/Prettier、Vite 生产构建、资源预算、文档链接和差异格式检查通过。浏览器均使用受控目录与测试音源，不代表外部电台或真机听音验收。
