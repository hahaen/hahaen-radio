# 浏览器与本地存储

## 支持策略

以主流桌面浏览器和移动浏览器为验收对象，具体最低版本在初始化时结合构建目标与实际用户设备冻结。WebGL 2、HLS、Web Audio、Media Session 和 Web Share 分别检测，不用单一浏览器名称推断全部能力。

## 本地数据

| 存储 | 用途 | 约定 |
| --- | --- | --- |
| localStorage | 少量偏好和轻量状态 | 使用命名空间、版本号和解析校验 |
| sessionStorage | 当前标签页是否已进入探索 | `haen:exploring:v1` 只保存布尔标识，失败时使用内存 |
| IndexedDB + idb | 较大缓存或结构化本地数据 | 设置 Schema 版本、升级和淘汰策略 |
| 内存 | 临时交互和运行状态 | 刷新后可丢失 |

本地存储可能因隐私模式、配额、用户清理或环境策略而不可用。读写失败要有可运行的内存回退，不将本地缓存当作唯一的服务器数据来源。

当前 IndexedDB 目录缓存的版本、淘汰与降级见[探索目录](../rendering/exploration-data.md)。

个人清单使用 `haen:personal:v1:` 命名空间：`favorite:<UUID>`、`history:<UUID>`、`song:<编码歌曲键>` 独立保存版本化记录；`filters` 和 `last` 保存当前筛选及恢复项。不同电台的收藏动作不会覆盖另一台的记录；存储事件重新读取当前键值，避免迟到事件恢复已经移除的收藏。历史只记录真实播放成功并保留最近 100 台，清空同时删除恢复项。

格式无法读取时保留原记录，当前会话使用可用数据；写入失败明确提示不能保证持久化，导出仍可用。迁移格式、分卷和输入限制见[个人收听工具](../application/listening-tools.md)。

歌曲收藏继续使用原来的 `song:<编码歌曲键>`，按规范化后的歌手与曲名去重，支持独立取消、跨标签页和文件合并。歌词与元数据只作有界内存缓存，不写入收藏导出；剪贴板不可用时保留可选择的清单文本。

未登录时继续使用原有浏览器存储；可选登录通过 API 同步账号收藏与历史。账号编辑草稿和已确认版本原子保存到当前标签页 sessionStorage，待同步项在同标签页重载后恢复；每账号的游客自动导入标记留在 localStorage，防止重复导入已删除收藏。密码不持久化，认证令牌仅在 HttpOnly Cookie 中，详见[账号同步](../../iterations/2026-10-23-account-sync/README.md)。

## 设置与睡眠

`haen:personal:v1:preferences` 保存版本化音量、静音、提示、视图和闲置偏好；修改前读取当前值，只更新变化字段。音量订阅具有回写保护，避免其他标签页同步时产生反馈循环。界面语言使用独立 `haen:language:v1`，手动选择及其他标签页的有效值均更新页面语言和标题。

`haen:personal:v1:audio` 单独保存默认关闭的 `normalize` 和 `tuning`，不修改旧版 `preferences` Schema。修改前合并当前键，存储事件同步开关；校准增益只在内存中用于实际输出，不反写基础音量。

`sleep` 保存随机计时 ID、15/30/60 分钟、绝对截止时间和 `expired`。关闭删除计时，到期保留明确到期记录；到期前重新读取当前键，防止已取消或重设的旧计时暂停音频。一个计时在每个已打开播放器只处理一次；页面恢复后重新核对。到期后用户可再次显式播放，浏览器挂起期间不保证准点暂停。

平台适配位于 `apps/web/src/platform`，分别管理截止时间、Media Session、快捷键和闲置计时，挂载与清理成对。系统动作逐项检测，不注册直播 seek 或虚构 duration。快捷键避开输入、模态面板和画布原生操作；沉浸切换保留音频与图形实例，隐藏场景停止帧循环，退出后恢复焦点。详见[收听设置](../application/listening-controls.md)。

## 界面平台能力

使用 Pointer Events 统一输入，处理触摸目标、窗口尺寸变化与安全区。国际化使用 i18next；时间使用 UTC 数据和明确时区格式化。

尊重 `prefers-reduced-motion`，保持键盘导航、可见焦点和基本语义。浏览器或系统不支持的增强能力采用可解释的降级。

兼容性结果在实现后记录浏览器、系统、设备与验证范围；WebKit 自动化结果不能替代真实 iOS 音频验收。

真实设备步骤与结果入口见[手机验收](../../engineering/real-device-acceptance.md)。
