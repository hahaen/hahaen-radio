# 产品说明、资源署名与本地反馈

## 需求与实现

补齐完整产品范围中的关于、隐私、数据与资源署名、使用帮助和问题反馈说明。顶栏提供双语主题面板，沿用夜航变量、原生模态焦点与响应式布局。面板期间保持实际播放，阻止闲置自动沉浸覆盖说明。

隐私内容与当前本地存储、浏览器直连、元数据、显式歌词和可选识曲行为对应。GeoNames、Natural Earth、Radio Browser、LRCLIB、AudD、字体与图标有实际署名入口；字体许可和 Lucide 完整声明随静态资源交付。新增中文已重新生成本地字体子集。

反馈为可预览的本地问题说明，按字段生成有效电台/线路标识及播放状态。点击复制才写入剪贴板，不自动发送；没有在线联系配置时明确说明。拒绝剪贴板后可手动选择文本。不收集任意日志、完整 URL、收藏或音频。

## Review 与验证

本轮仅 Review 新增说明界面、本地快照、入口与闲置排除、语言、字体、许可、测试和文档，以及本轮完整回归发现的调台音效恢复问题。核对来源署名、第三方边界、无自动请求、字段最小化、无秘密、焦点返回、触屏目标、长文滚动与双语文案。初始格式、Lint、类型、153 项普通测试与生产构建通过；76 份 Markdown 的 399 个本地链接有效。新增 12 项说明浏览器用例在 Chromium、Firefox、WebKit 与手机 Chromium 通过，实际播放使用项目合成音；静态构建内三份字体许可、Lucide 完整许可与字体文件均与源资源字节一致。

首次完整浏览器回归为 219 项通过、2 项 Firefox 失败、3 项桌面触摸合成不适用。失败分别为 HLS 加载中暂停后媒体时钟未推进，以及调台音效的 AudioContext 停在 suspended。保留了原始失败证据，没有放宽断言。

定向诊断中，串行 8 项通过，并发 16 项中复现 1 次音效失败；记录显示同一上下文的重复暂停尚未结束，恢复已发出但未完成。确定性的状态时序回归在修改前失败，修改后通过。音效现在合并正在进行的暂停，等待其完成后再恢复并创建节点；暂停或销毁仍取消迟到音效，不改变主媒体路径。HLS 场景在这些重复检查中未重现，不将其归为音效修复成果，后续兼容验收继续观察媒体时钟。

修复后格式、Lint、严格类型、154 项普通测试及前后端生产构建通过；6 项 MySQL 用例本轮不适用，没有 Schema 或 MySQL 查询变更。原始 Firefox 定向并发 16 项全通过，其中 8 次音效记录均没有在暂停未完成时发出恢复；完整浏览器回归 221 项通过、3 项桌面触摸用例不适用。Vite 大分块提示保留，完整兼容与资源预算仍属于后续阶段。同步没有远端变更或冲突，26 个任务文件内容与权限完整恢复；复审后 154 项普通测试、前后端生产构建、24 项说明/闲置/音效/HLS 浏览器复验及文档检查通过。调试探针仅保存在被排除的私有归档中，没有进入应用或构建产物。
