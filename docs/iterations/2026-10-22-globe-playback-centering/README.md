# 播放电台居中

日期：2026-10-22。

## 需求与实际变更

播放时让地球转向正在收听的电台，使其标记位于地球正中央。

`globe.ts` 在实际进入播放状态或播放中换台时，以选中光环的展示点作为转向目标，保持当前缩放距离；复用 500ms 球面插值、待选计时取消和帧循环，不新增定时器、依赖或音频请求。减少动态效果和省电模式直接定位。

确切坐标、省/州与国家大致位置沿用现有精度与展示点，不修改原始地理资料；未知位置仅播放、不转向。暂停不会触发转向，恢复播放重新居中。手动拖动、缩放和键盘操作可中断过渡；不会持续强制锁住视角。图形较晚加载或恢复时，通过初始化时同步的选台与播放状态完成居中。

## Review 与验证

Review 仅覆盖本次引擎变更、居中回归与相关文档，核对选台/播放调用顺序、连续切台覆盖旧过渡、缺位置、相机距离、手动中断、减少动态效果、省电与既有资源清理，无未解决问题。

- 32 项 Playwright 回归通过：Chromium、Firefox、WebKit 与 Pixel 7 Chromium 模拟，覆盖桌面 1440×900、平板 768×1024、手机 390×844、窄屏 320×700 和横屏 844×390。直接断言标记投影与地球中心偏差小于 1 个 CSS 像素，检查跨半球切台、国家大致位置、未知位置、暂停后手动移动/恢复、固定状态及地球延迟加载。普通动效、减少动态效果与省电均通过；既有光点动效和地理 GPU 坐标回归通过。光点采样区域随自动居中调整到中心标记。
- 40 项相关单元测试通过；前端 TypeScript、定向 ESLint/Prettier、生产 `/radio/` 构建、资源预算与文档链接检查通过。构建保留既有大包体积建议，预算满足。
