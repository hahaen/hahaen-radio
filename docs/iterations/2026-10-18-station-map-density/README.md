# 电台逐台地图展示

## 需求与变更

将大量电台合并成少数标记的画面调整为逐台绘制，提高地图密度，并保留夜航风格和位置精度说明。

- 列表逻辑分组与绘图标记分离：每台有可用位置的电台都保留一个标记；原始坐标保持不变，即使多个电台重合也不删除成员。
- 缺原始坐标时按电台 ID 稳定取样于本地国家陆地内部区域，以空心点显示；筛选、排序和刷新不改变该台位置。取样不代表真实台址，不补城市或当地时间。
- 国家内陆区域从固定版本 Natural Earth 地图单元三角剖分生成，排除孔洞，收缩和量化后检查包含关系；每代码最多 16 个安全区域，250 个代码均有区域。来源、许可和摘要随资源交付，数据只进入地球模块。
- 点击点直接选择对应电台，密集点按指针距离优先命中；定位和选中环与绘图点对齐。国家与附近位置列表、分页继续保留。
- 同位置展开时全部成员在有界范围内错开显示，省电模式不缩减电台数量。手机总览点径更细，放大后适当增大，以控制密集画面亮度。
