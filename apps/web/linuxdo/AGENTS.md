# LINUX DO 微应用协作规范

- 应用名称统一为「声屿 HAEN」。本目录维护 LINUX DO 纯前端入口、SDK 适配、数据快照和 ZIP 构建。与官网共用上一级 `src` 的界面、目录筛选、图形和播放器控制，不维护另一套应用界面。
- 不新增或依赖任何自建后台。运行时禁止请求 `radio-api`、`radio-jobs`、MySQL、自建代理、云函数及其他自建服务。官网和其他客户端继续按各自需求开发。
- 仅在准备版本时对已发布的公开目录执行只读导出。保存快照版本、UTC 导出时间和条数，仅保留公共电台字段。不得导出账号、会话、私有收藏、诊断记录、凭据或直播地址。
- 运行时用 `sdk.assets.readJson()` 读取目录和直播索引，用 SDK 读取随包地图。目录、详情、搜索、筛选、同城或附近城市、随机选台和收藏都在本机完成。收藏和设置用 SDK 存储。
- 可搜索不代表可播放。正式可播名单只允许收录有第三方授权依据、且已在 LINUX DO 沙箱的桌面和手机验证实际出声的电台。待验收候选只能进入沙箱包。直播走已批准的 SDK 端点；不打包音频，不自动播放，不用外部链接、新标签页或页面跳转兜底。
- 本地隔离检查必须拦截声音与直播请求；本地检查不算 LINUX DO 沙箱验收。当前用户要求不测试声音，真实设备听测留待用户安排。
- 仅本目录受影响时，只构建微应用。共享代码变化时，检查并更新受影响产物。官网上传目录与微应用 ZIP 输出必须分开。应用 ID 只从 Git 忽略的仓库根 `.local/linuxdo/.env.local` 读取。正式上架由用户操作。
