# 可访问性扫描、键盘和双端复验

## 需求与实际变更

补齐阶段8的界面可访问性回归，保持夜航主配色、字体、构图与核心收听行为。原生dialog显式管理Tab/Shift+Tab循环，跳过不可用控件，保留Esc与返回打开按钮；普通与沉浸收藏按钮的辅助功能名称包含可见状态，电台行名称包含可见地点/流派并补充逻辑文字分隔。地球控制、流派按钮与时间歌词滚动区增加对应具名group/region。

选择框沿用原生select，统一箭头和预留内边距，修正WebKit原生外观导致的高度不足；覆盖设置语言、筛选码率及歌词版本。没有新增可见文案、字体资源、账号或运行依赖。固定axe-core只作为开发测试依赖，锁文件同步更新，发布目标为Web；本轮没有SQL、迁移或实际部署。

新增5个场景在四个浏览器项目执行，共20项、140次状态扫描，覆盖中英界面、播放、空结果、筛选、全部面板主题、歌词版本、已收藏歌曲、沉浸和列表降级。键盘、目标尺寸、窄屏、横屏及200%文字另检查。名称变更相关的既有组件/浏览器选择器同步更新，仍按真实可访问名称定位；组件测试精确断言完整双语名称，未放宽播放器、目录或资源断言。

## Review 与发现

范围仅本轮界面、样式、相关测试/依赖及文档；读取原有快捷键、焦点恢复、歌词与可控目录作为上下文。检查原生控件行为、禁用/隐藏元素、DOM顺序、组合键、语义名称、语言变化、标签与可见文字一致性、双端布局和测试数据边界。

基线暴露模态末尾焦点离开、可见文字与名称不符及WebKit选择框不足44px；首轮全量中249项通过、3项不适用跳过，8项新增审计在最后的沉浸收藏名称处失败。修复沉浸同类问题及三个普通容器的命名语义，复审统一选择框对歌词版本的影响并补齐样式和审计；新增测试按真实流程提交搜索、手动查找/选择歌词，而不是依赖未触发的查询。最终结果以[结构化记录](results.json)为准。

不禁用规则、不排除区域、不接受已知违规基线。对比度incomplete继续保留；采集到的实际文字颜色、实心背景及祖先透明度/滤镜用于人工复核，选择框箭头不在文字背后。仅这些已解析颜色对的最小比为7.56:1，不将它推断为任意叠层或未来主题的结论。方法、颜色表和外部规则依据见[检查说明](../../engineering/accessibility.md)。
