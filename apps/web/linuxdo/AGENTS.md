# LINUX DO 微应用协作规范

## 应用与运行边界

- 应用名称统一为「声屿 HAEN」。微应用入口、官方 SDK 适配、目录快照、直播清单和 ZIP 构建都在 `apps/web/linuxdo`，与官网共用 `apps/web/src` 的界面、筛选、图形和播放器控制，分别构建。
- 微应用以访客模式纯前端运行。目录、详情、筛选、搜索、同城和随机选台使用包内快照，地图随包发布。通过 SDK 读取资源，收藏和设置保存在 SDK 应用存储。运行时禁止调用 `radio-api`、`radio-jobs` 及其他声屿后台，禁止接入登录、账号同步、识曲或自建代理。
- 更新 `data/catalog.json` 时，只在准备版本阶段运行 `pnpm --filter @haen/web export:linuxdo:catalog`，从官网公开接口只读导出，记录目录版本、导出时间和条数。快照排除账号、凭据、私有收藏、诊断和音频。打包复用已有快照，并无损重排以压缩体积。

## 可播范围与验收

- 电台目录与 `data/streams.json` 可播清单分别维护。只有具备第三方使用依据且声明在 SDK 清单中的 HTTPS MP3 音源可进入候选。用户点击播放后通过 SDK 直连音源，在当前页面收听。禁止打开新标签页、跳转到官网或电台站点，也不以跳转替代播放失败。
- 新增或更换音源时，在桌面和手机的真实 LINUX DO 沙箱验证实际出声、停止和切台，并记录 `verification`。未经确认的音源只进入沙箱和本地检查包。默认用无声隔离检查验证包和界面，实际出声以真实沙箱验收为准。首个正式可播电台为 Radio Paradise 主频道，最新名单以 `data/streams.json` 为准。

## 构建与交付

- 微应用版本只从 `version.json` 读取。界面、功能、目录、正式可播名单等实际发布内容变化时，交付正式候选包前将补丁版本加 1，例如 `0.1.9 → 0.1.10`。同一次交付的检查包、沙箱包、正式候选包和重复构建使用同一版本。官网版本单独管理。
- 每次变更影响微应用产物时，先做相关检查，再运行 `pnpm --filter @haen/web package:linuxdo`，交付 `apps/web/linuxdo/dist/package/app.zip`。按最终 ZIP 验证 4096 KiB 上限、目录与正式可播名单，并在交付中给出文件路径、版本和实际大小。待验收音源单独用 `package:linuxdo:sandbox` 打包，正式候选包继续使用已验收名单。如果没有合格音源或正式打包失败，说明阻塞原因。
- 只构建和更新受变更影响的产物。仅微应用变更不重建或发布官网 H5、后台和 Android。仅改文档、协作规则或不会改变包内内容的工具时，保留版本和现有包。官网上传目录与微应用 ZIP 分开。
- 应用 ID 由用户填写在仓库根 `.env.local.linuxdo` 的 `MINI_APP_ID` 中。配置文件和 ZIP 都留在本机，禁止提交。打包是本地交付，上传、提审和正式上架由用户操作。
