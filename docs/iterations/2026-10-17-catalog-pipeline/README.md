# 数据库与真实目录管线

## 需求与实际变更

完成产品阶段 2：建立 MySQL 8.0.46 数据模型、受控迁移、真实电台目录同步、版本发布、目录 API、就绪检查及独立调度。用户允许本机不安装、不实测 Docker，容器验收延后到实际部署环境，具体清单见[部署文档](../../deployment/README.md)。

- 建立 8 张业务表与两条 Drizzle Kit 迁移，显式约束表选项与 ASCII 字段例外；提供配置预检和脱敏迁移入口。
- 开发库已创建，迁移已实际执行；API、任务、迁移采用不同身份，权限限于本项目所需表或目标库，普通运行身份无 DDL 和迁移历史写权限。
- 真实目录按页读取、校验和去重，完整通过后批次暂存并事务切换版本；失败保留旧版本，连续缺失保留状态，人工屏蔽覆盖播放线路。
- 实现 2 分钟租约、30 秒续租、写入令牌校验、任务记录清理，以及每日 UTC 02:00 调度和手动命令。
- API 在数据库内搜索与分页，按需读取详情和分片；就绪与清单不加载整库。新增真实数量、筛选交集、批量查询、同城边界及 OpenAPI 契约。
- 外部请求固定已校验公网地址并校验证书，每跳重定向重新验证。提供显式加密 DNS 模式处理本机 Fake-IP，保持私网拒绝策略。
- 构建前清理限定包的 dist，测试辅助文件不进入生产编译结果；私有配置和诊断不纳入版本控制。

## Review 与修复

仅审查本次新增和修改的配置、契约、仓储、同步、API、测试、迁移和文档及必要上下文，核对环境隔离、权限、资源释放、超时、完整发布、任务互斥、异常数据与错误脱敏。

修复了同步配置改为同步读取后的测试调用、驱动结果类型、异常控制字符清理、构建残留、暂存取消边界，以及首次 API 查询加载整个目录的问题。实际 MySQL 验收发现 LOCATE 不满足拉丁重音匹配，已改为显式排序规则的参数化 LIKE，并对 `%`、`_`、`!` 做字面量转义；修复后复审并回归。

首次开发迁移的身份来源限制不匹配，预检失败；检查确认开发库尚无业务表或迁移记录后，按实际隧道来源收紧身份范围，再执行成功。没有修改现有业务库、正式库或服务器安全配置。

## 验证证据

- Node.js 24.9.0、pnpm 12.5.1，冻结安装、格式、Lint、strict 类型检查、34 项普通测试与生产构建通过。
- 专用 MySQL 8.0.46 临时库：首迁移初始化、Unicode 数据保留升级、重复迁移、表选项与字符例外、目录同步、失败保留、租约接管、人工屏蔽、事务回滚、操作超时和排队超时恢复，共 5 项数据库用例通过。临时库已删除。
- 开发库真实同步成功发布 68,803 条，来源记录 68,805 条，异常记录 2 条；清单包含 40,554 条符合上游检查与 HTTPS 条件的候选、242 个国家/地区代码、69 个摘要分片。这些是本轮目录状态，不等于逐台播放已验证。
- 编译后 API 实测：就绪约 116ms、清单约 73ms、组合搜索约 213ms；首分片 1000 条、末分片 803 条约 1.2–1.3 秒，详情、线路、批量去重、零选项与开发 OpenAPI 均通过。耗时为本机 SSH 链路单次观测，不作为生产性能承诺。
- 编译后任务入口实际启动，报告 UTC 02:00 配置并正常停止；自然跨日调度尚未观察。
- 本机数据库通过已验证主机密钥、仅绑定回环地址的 SSH 隧道访问。服务器直连 TLS 仍待部署验收；本机工具的原有 TLS 设置未更改。

本次不包含界面功能变更，Chromium、Firefox、WebKit 与 Pixel 7 模拟视口的基础入口回归共 8 项通过；真实手机、音频、地图和完整规模渲染属于后续阶段。普通测试中的 5 项数据库跳过项由独立 MySQL 命令实际执行，不冒充普通测试已覆盖。
