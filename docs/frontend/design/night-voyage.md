# 夜航设计规范

状态：2026-10-21 在统一夜航样式基础上继续优化画面层级与双端布局，新增验证见[画面与信息层级优化](../../iterations/2026-10-21-visual-refinement/README.md)。当前基线为墨绿背景、暖白文字、珊瑚橙强调色、点阵地球与透明收听区；本次范围和验收见[全系统样式统一](../../iterations/2026-10-18-unified-visual-style/README.md)。早期概念图仅保留为历史材料，后续实现以本文和当前组件为准。

## 1. 适用范围

项目名称：声屿 HAEN。品牌标语：嗯，听听世界。

本规范覆盖地球、流派、搜索、收藏、历史、设置、帮助、筛选、播放器和沉浸画面。沿用已有业务能力、真实电台信息与地理精度说明，不通过样式变化添加账号、音频或其他未经实现的能力。

## 2. 统一变量

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#101F1D` | 页面墨绿背景 |
| `--color-surface` | `#1C3430` | 控件与输入区域 |
| `--color-text` | `#F5F1E8` | 暖白正文与选中胶囊 |
| `--color-text-muted` | `#B3C1B7` | 次要信息 |
| `--color-secondary` | `#91AAA0` | 辅助描边 |
| `--color-accent` | `#F36B45` | 播放、固定、收藏与焦点 |
| `--color-on-accent` | `#172D2A` | 实心强调色上的文字 |
| `--color-error` | `#F2AC99` | 错误文字 |
| `--color-border` | `rgba(245,241,232,.16)` | 弱分隔与轮廓 |
| `--color-selected-bg` | `rgba(245,241,232,.08)` | 轻量悬停状态 |
| `--color-panel` | `rgba(19,38,34,.92)` | 浮层底色 |

- 控件使用圆形或胶囊轮廓；浮层使用 16px 圆角、细边框、24px 背景模糊与柔和阴影。
- 播放器不加实心卡片背景、边框或独立卡片阴影。全屏背景底部渐暗，承托电台文字。
- 普通文字与背景维持 4.5:1 对比度；焦点有明确的珊瑚橙轮廓。颜色变化不能代替文字、选中语义或播放状态。

## 3. 字形与层级

- `Inter` 为拉丁界面与品牌字形，中文优先系统 `PingFang SC`，以本地 `Noto Sans SC` 回退。桌面电台标题 44px、500 字重，超长标题 32px。
- 手机电台标题使用 `Noto Serif SC` 与系统衬线回退，依宽度调整；较长名称允许换行，信息区独立滚动。
- 坐标、统计与时间使用本地 `JetBrains Mono`，保留 `IBM Plex Mono` 回退。桌面中国时间为 76–104px 自适应描边字形，手机为小号实心字形；公历日期、星期与农历月日作为下一级文字，农历另起一行。
- 字体全部由本站提供，附 OFL 许可。普通构建和浏览不访问字体服务；覆盖与生成方式见[本地字体](fonts.md)。
- 图标沿用 Lucide；图标按钮具有可访问名称与焦点状态，悬停不承载唯一功能。

## 4. 页面与组件规格

### 首次进入

- 未选择电台且当前标签页尚未进入探索时，展示品牌、标语、欢迎标题、说明、开始收听和先浏览入口。背景使用安静的墨绿渐变与低亮度真实地球；地球尚未就绪时保持安静背景，不展示装饰场景的加载文案。品牌下方保持标语。
- 直接开始收听使用已有随机选台逻辑；先浏览入口展示完整工具。只在 sessionStorage 保存当前标签页的进入标记，拒绝存储时仍可在内存中使用。
- 已选电台、已进入探索或恢复电台时使用正常收听布局；欢迎界面不会改变音频自动播放约束。

### 桌面与平板

- 页面固定一屏。桌面默认边距 40px，1024px 以下为 24px；横屏低高度下为 20px。
- 左上为品牌和真实目录统计；右上依次放搜索、地球/流派胶囊、带数量的收藏入口、设置与语言选择。帮助入口在右下角。
- 地球画布覆盖整个视口。右上固定显示中国时间（`Asia/Shanghai`、UTC+8）、日期、星期和农历月日，不依赖选台或电台时区；时钟下方不显示电台地址。欢迎页及低高度横屏也保留时钟，沉浸页沿用独立布局。
- 透明播放器在左下，桌面宽度最多 480px。播放状态先于标题；地点、流派、码率、详情、切台与次要操作逐层呈现。播放主按钮使用 60px 珊瑚橙描边圆形，音量独立一行。
- 底部流派条使用 34px 高的横向滚动项；仅当前流派保留暖白胶囊，其他项采用透明背景和弱化数量，筛选入口保留细描边。类别色点和真实数量共同标识类别。筛选面板从左下展开。
- 搜索结果、收藏、设置和地理分组使用浮层，各自独立滚动，关闭和标题保持可用。搜索保留中文输入法、即时筛选、Escape 与焦点返回。

### 手机

- 390×844、320×700、844×390 为必需检查视口；页面随动态视口变化并考虑安全区。
- 品牌和主要工具共用第一行；视图切换位于右侧第二行，搜索展开独占第二行，结果从其下展开。
- 地球使用较大的点阵轮廓，画布在底部控制区上方构图；当前电台名称使用 30–36px 衬线字，较长名称降为 28px，采用均衡换行。画布高度结合实际播放器高度调整，在小屏保持地球可见。中国时间、公历与农历置于顶部左侧，视图与语言置于顶部右侧；打开搜索时暂时隐藏同一区域的时钟、视图与语言，避免重叠；输入焦点沿整个胶囊显示，保留一个显式清除按钮。地图精度置于收听区上方，目录统计收进地图信息。
- 保留直接切台、收藏、固定、分享、沉浸和音量操作，以及底部横向流派条。可用高度至少 600px 的手机界面将播放/切台/固定与收藏/沉浸/分享/音量分成两行，操作目标至少 44×44px；低高度横屏使用紧凑布局。播放器信息可滚动，播放操作不随长名称移出屏幕。
- 手机浮层使用可用宽度与安全高度，内容独立滚动，底部播放操作仍然可用。

### 地图信息

- 默认仅保留选点预览、位置精度、同地点电台入口与 44px 地图信息按钮。
- 地图信息按需展开，包含目录统计、国家级数量、未知位置查找、操作说明与地理署名；点击外部、关闭按钮或 Escape 收起，显式关闭后焦点回到入口。
- 目录加载、失败与缓存过期时自动展示信息，重试与错误不会随折叠隐藏。欢迎页隐藏整组地图工具。
- 浮层位于地图工具上方，可独立滚动；小屏限制高度，关闭按钮不被顶部工具覆盖。

### 收听、筛选与辅助面板

- 收藏、历史与歌曲采用等宽标签，名称与真实数量分层显示，保留带数量的完整可访问名称、暖白选中态、细分隔列表和简洁的导入导出区域。
- 空收藏、空历史、空歌曲与无搜索结果统一使用低调圆形线条图标、标题和简短说明；空清单不显示无效的批量处理按钮。搜索空状态保留重置筛选，收藏空状态保留导入入口。
- 设置使用低调的分组标题与右侧开关；睡眠时长为一组胶囊。错误、浏览器能力限制与定时反馈仍按真实状态展示。
- 搜索列表使用类别色点、站名、地点、类别和播放图标，不再使用方形图标卡片。
- 帮助、歌曲收藏与沉浸页继承相同色彩变量。沉浸中的唱片、星球与山峦使用墨绿、暖白与珊瑚橙组合。

## 5. 图形与动效规格

- Three.js 原生 WebGL，38° 基础视野；初始相机和重置距离为 3.8，窄屏通过纵向视野换算保持中心。用户仍可拖动、缩放和键盘移动。
- 海洋为低对比墨绿球体，规则经纬点阵覆盖表面，大陆与边界降为辅助层；大陆点透明度 0.2，海洋点透明度 0.1。电台为暖白辉光点，选中电台为珊瑚橙标记；国家级位置保持空心样式和文字说明。
- 普通电台光点尺寸为 6px 乘以画布短边与 600px 的比例（比例至多 1，尺寸至少 1.8px），再乘以受限 DPR；基础透明度 0.68，国家级空心点额外使用 0.42 的透明度系数，避免密集区域叠成白块；边缘淡出、低频呼吸，保持逐台标记与同地点螺旋展开。
- 流派场景采用加法混合的柔和点光，单类别最多 6000 点；省电模式减少点数，不改变类别名称、数量或可访问按钮。
- 省电模式关闭海洋装饰点阵并降低大陆精度；减少动态效果、页面隐藏、场景切换和销毁沿用既有资源管理规则。
- 图形是独立实现，地理、目录、字体渲染和设备差异会影响最终画面。不宣称逐像素相同。
- WebGL 不可用或丢失时保留静态地理、列表和播放器。动画只表达实际播放或场景状态，不将装饰图形标记为真实声谱。

## 6. 验收

按桌面、平板、手机、窄屏和横屏核对：初始状态、选台、暂停、搜索、收藏、设置、筛选、地球/流派切换、详情和沉浸。检查长名称、双语、焦点返回、无横向溢出、浮层滚动与播放器可点击性。
