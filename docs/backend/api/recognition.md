# 手动识曲 API

状态：默认关闭的适配、额度与界面已接入并有[可控验证记录](../../iterations/2026-10-17-manual-recognition/README.md)。真实服务需要用户提供有效凭据及明确额度，不能据可控样例声称真实识曲已完成。

## 能力与入口

`GET /api/v1/capabilities` 返回 `recognition=disabled/available/quota-exhausted/unavailable`，不公开凭据、预算标识、剩余次数或状态文件路径。禁止缓存。

`POST /api/v1/stations/:id/recognition` 只接受严格 JSON `{ streamId }`；UUID 与 24 位线路 ID 均由共享契约校验，额外 URL、查询参数及跨站浏览器请求被拒绝。默认关闭时返回明确的 disabled 原因，不采样、不访问供应商；启用后先验证当前目录、电台状态及线路归属。

响应 `RecognitionResult` 明确携带电台、线路、`source=audd` 与 `timing=unknown`。状态为 `found/not-found/unavailable/busy/cooldown/quota-exhausted/error`。只有 found 含有效歌手、曲名与识别完成时间；其他状态的 song 为 null。retryAfter 为可空的 1–86400 秒建议等待值，不表示自动重试或已匹配歌曲进度。

基础播放不经过识曲服务，也不因识曲失败改变电台可用状态。API 更新后再更新 Web；旧服务缺少能力接口时，Web 保留基础收听并提示增强不可用。

## 采样与请求边界

只取当前目录线路，不接受客户端音频上传或自定义 URL。HTTPS 源地址继承全部 DNS 公有地址校验、连接地址固定、系统 TLS 信任与每次重定向复核。HLS、非 MP3/ADTS AAC、压缩传输、交错 ICY 元数据及过小片段如实不可用。

采样网络阶段上限 8 秒、最多 128KiB，至少 16KiB 才上传；网络用时与字节数不冒充精确的音频时长。只在内存保留当前片段，完成或取消即释放，不保存音频文件。供应商请求最多 10 秒、响应最多 64KiB；整项有 20 秒取消信号，浏览器请求等待上限为 25 秒。

固定向 AudD 标准端点发 multipart file 与服务端 api_token，令牌不进入 URL；不将电台地址交给供应商抓取，不请求额外第三方歌曲元数据。带凭据 POST 遇到重定向立即拒绝，不转发到新地址。供应商错误原文、令牌与音频不进入普通日志。

## 调用保护

全局最多一个采样/识别任务；同一电台、线路及地址最多合并 8 个等待者，不重复扣费。新任务至少间隔 10 秒；供应商限流扩大全局冷却。结果缓存最多 128 项、1MiB，通常保持 60 秒；失败 30 秒。没有自动识曲或后台持续轮询。

浏览器关闭面板、暂停或换台会取消本地请求。服务端只有最后一个等待者离开才取消共享任务；预扣前取消不消耗额度；已开始预扣、上传或可能已被供应商处理的请求保守保留次数。API 在关闭前阶段取消识曲任务，再等待请求退出并释放额度锁；清理可重复调用。

[持久化额度](../../operations/recognition-quota.md)在每次上传前原子预扣。重启不重置，写入失败关闭识曲，达到上限不再采样。全站共享同一额度，免登录接口不承诺每人额度；公开请求可以消耗已授权预算，因此上线前须设置可接受的总次数。

适配依据 [AudD 官方接口文档](https://docs.audd.io/)，核对日期 2026-10-17。上游可能允许超出套餐继续计费，应用不会把试用或套餐描述为无限免费；计费与实际账户余额仍由用户核对。
