# 收听入口与播放器

当前布局固定为一屏，搜索、筛选和电台目录由顶栏「查找电台」或 `/` 进入弹层，选台后返回收听界面。底部播放器始终保留占位，长详情在信息区内部滚动；双端方案与验证见[单屏布局记录](../../iterations/2026-10-18-fixed-screen-layout/README.md)。以下阶段 3 内容保留作为早期实现记录。

## 阶段 3 的界面方案

沿用[夜航规范](../design/night-voyage.md)，本阶段建立真实电台列表、搜索与底部播放器；地球及流派场景在下一阶段接入，不改变主配色、字体角色或后续核心构图。

| 角色 | 设计变量 |
| --- | --- |
| 深海底色 | `#0B151B` |
| 面板底色 | `#15252D` |
| 暖白正文 | `#E8E9E1` |
| 青灰辅助文字 | `#A6B7B8` |
| 地理与次级色 | `#83AAA3` |
| 当前播放与主操作 | `#D8AD6B` |

品牌、短标题使用衬线，操作和列表使用无衬线，码率等短数据使用等宽。字体资源尚未交付时保留既有系统回退，不依赖在线字体服务。错误增加独立语义色与文字，不让琥珀同时表示失败。

```text
电脑：品牌                                  界面语言
      左侧短标题与当前电台       右侧搜索与电台行列表
      当前状态及开始入口         分页与数据说明
      底部横向播放器：电台 / 播放暂停 / 音量

手机：品牌与语言
      短标题与当前电台
      搜索与纵向电台行列表
      底部紧凑播放器，内容预留占位与安全区
```

采用实际电台信息形成页面层次；列表用行和留白，不将每台包成独立卡片。不添加虚构曲目、频谱、收听人数或假地理画面。与已确认方向复核后保留深海底色与衬线短标题，移除通用展示页式的装饰标签，让选台和播放状态成为主要内容。

## 已实现的播放契约

- 用户明确开始后才请求播放；浏览器拒绝自动播放时保留当前电台并提供再次播放入口。
- 音频引擎独立于 React；界面根据真实媒体事件显示连接、缓冲、播放、暂停、需要手势和失败状态。
- 每条线路最多连接 8 秒，每台最多 3 条候选；快速切台立即使旧请求、媒体事件和 HLS 实例失效。
- 未固定时最多自动尝试 2 个其他电台，排除本轮已失败台；固定后停留并提供显式重试。随机在完整筛选结果中选择，不仅抽取当前页面。
- 只在需要 HLS 且原生不支持时加载 hls.js；持续音频由浏览器直连，不转为后端代理。
- 暂停、静音、音量和重试均有触屏与键盘入口；音频可播放与可分析分别验证。

本阶段仅包含列表和播放器。地球、完整筛选、持久收藏历史、分享和系统媒体等继续按产品阶段实现；验收证据见产品矩阵和阶段归档。
