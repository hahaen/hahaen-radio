# 有限播放诊断与保留清理

## 需求与实现

补齐精简播放故障接口、持久化、7 天有效期、定期清理和受控维护命令。前端将本地问题说明与报告分开，只有当前失败且有效的电台/线路允许手动提交，不自动上传、重试或下线电台。

新增严格契约与小请求体、线路归属校验、一次性回执去重、单在途/短时限流、每日持久额度及 10000 槽硬上限。两张诊断表与新迁移由 Drizzle 管理；后台启动与每小时清理，summary/cleanup 命令维护有效报告，基础播放不依赖诊断成功。

仅 Review 本轮契约、Schema/迁移、仓储事务、限制与取消、API 接线、任务与工具、双语手动界面、字体、测试和文档。核对无任意 URL/日志/音频、无访客信息、无目录状态写入、UTC 时间、重启保留、去重、并发、硬容量及物理清理边界。
