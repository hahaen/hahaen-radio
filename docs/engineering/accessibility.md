# 可访问性回归与人工复核

本页记录可重复的界面检查范围，不是WCAG合规认证。真实屏幕阅读器、系统字体放大、移动浏览器手势/软键盘和真实设备音频仍需单独验收。视觉沿用已确认的夜航规范，新增检查不切换主题、字体角色或核心构图。

## 执行入口与数据

```sh
pnpm test:e2e apps/web/tests/e2e/accessibility.spec.ts --workers=2 --retries=0
```

根开发依赖固定@axe-core/playwright与axe-core 4.14.0，使用现有Playwright 1.64.1和Node.js 24.9.0；它们不进入前端运行包。仅测试上下文拦截目录、曲目、歌词和自制可解码音源，生产没有默认假电台。测试不调用真实识曲供应商、不发送外部反馈或改变用户数据。

每个浏览器项目有五个用例，共20项：中英两种界面的多状态扫描、目录场景服务不可用时的列表降级、三个弹窗的正反向键盘循环与返回焦点、窄屏/横屏/文字放大下的目标与焦点。项目为Chromium、Firefox、WebKit及Pixel 7移动Chromium模拟；普通视口为1440×900与390×844，另检查320×720、844×390和390×844的200%文字。

扫描包括地球、流派、展开筛选、无结果、真实测试音源播放、设置、三种收听清单、五个产品说明主题、带原创样例歌词的曲目面板、已收藏歌曲清单及沉浸模式；每种语言17个状态，加四个项目各自的列表降级，共140次扫描。测试按实际操作提交搜索、点击查找歌词，不用跳过交互来伪造已打开状态。

## 自动检查与边界

axe使用wcag2a、wcag2aa、wcag21a、wcag21aa、wcag22aa和best-practice标签，不排除页面区域、不禁用规则、不允许已知违规快照。报告包含状态、引擎/浏览器版本、视口、违规目标和incomplete条目；不确定项不能作为自动通过。检测方式与局限依据[Playwright可访问性测试说明](https://playwright.dev/docs/accessibility-testing)。

键盘检查通过真实浏览器Tab与Shift+Tab多轮遍历设置、收听清单和说明弹窗，确认焦点保留在弹窗、有可见轮廓、没有完全移出视口；Esc后返回真实打开按钮。可见性检查不等于所有焦点像素均未遮挡，也不代替真实屏幕阅读器朗读。

弹窗继续使用原生dialog实现模态和Esc，显式管理内部Tab次序，跳过禁用、隐藏和inert内容，保持正反向循环；只拦截Tab，不吞掉输入、方向键或浏览器组合键。依据[WAI模态对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。

布局用例遍历设置弹窗中当前可用按钮、输入与选择控件。checkbox按关联可点击label计算命中区域，其余用实际控件边界，样式下限为44×44 CSS px（几何断言容忍0.5px的布局取整误差）；这是项目触屏基线，不把原生平台pt/dp或WCAG最小目标规则混为一谈。文字放大先读取原有字级再统一加倍，避免层层继承导致多次放大；检查无内部横向溢出、可滚动及键盘可达，不宣称模拟了全部系统字号或浏览器页面缩放。

## 语义与视觉处理

电台行的辅助功能名称保留动作、台名和可见地点/流派；DOM文字之间有明确分隔，使可见文字能够作为语音控制的识别依据，真实语音控制仍待对应环境验收。收藏按钮名称包含实际显示的已收藏状态和取消动作，保留aria-pressed；沉浸与普通视图一致。图形控制与流派按钮使用具名group，带时间戳歌词的可聚焦滚动区使用具名region，不给没有相应语义的普通div强加名称。

WebKit原生select在本机曾忽略期望高度，现使用统一外观、原有语义颜色的小箭头和预留内边距，保持至少44px高；它仍是原生select，键盘和系统选项功能不替换为自制菜单。没有新增可见文案，字体子集与许可资源保持原样。

## 对比度不确定项的复核

原生选择控件的箭头背景与滚动弹窗中的部分文字可能使axe的color-contrast结论不确定。保留这些条目，并结合浏览器实际样式、实心背景、透明/滤镜条件及截图复核，不将其改成已自动通过。当前夜航实心颜色对按相对亮度计算如下（表格仅展示两位小数，判断使用未舍入值）：

| 前景 | 页面背景 | 弹窗背景 |
| --- | --- | --- |
| 主文字 | 15.10:1 | 12.87:1 |
| 辅助文字 | 8.87:1 | 7.56:1 |
| 琥珀强调/焦点 | 8.89:1 | 7.58:1 |
| 青灰次强调 | 7.25:1 | 6.18:1 |
| 错误文字 | 10.48:1 | 8.93:1 |

这些数值证明对应实心颜色对，不能外推到任意透明度、叠层、禁用状态、图片背景或未来配色。选择框箭头只占右侧预留区域，不位于文字背后；本轮截图核对其可见性与文字间距。普通文字的4.5:1要求及以实际样式颜色评估的规则见[W3C对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

真实VoiceOver/TalkBack/NVDA的名称、顺序、状态与动态播报，系统高对比/强制颜色，真实软键盘、安全区、触屏和锁屏仍待对应环境验证。不要把扫描零违规表述为所有这些项目完成，也不以WebKit自动化代替真实iOS。
