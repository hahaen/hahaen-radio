# 部署工具测试

本目录保存发布流水线、跨节点交接、静态目录发布/回退/篡改拒绝、目标更新及运行日志的回归测试。通过根目录 `pnpm test` 执行，使用临时目录、合成迁移和模拟 Docker CLI，不连接生产数据库，也不触发实际镜像分发或上线。

`fake-docker.mjs` 是测试专用替身，不随应用镜像分发。相关工具位于 [scripts](../scripts/README.md)，运行材料见[部署导航](../README.md)。

组件回归覆盖无迁移失败自动恢复、迁移/失锁时拒绝自动恢复、成功后单版本保留及当前静态入口保护；`public-check.test.mjs` 通过本机 HTTP 验证页面、资源和业务接口拒绝条件。
