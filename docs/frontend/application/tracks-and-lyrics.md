# 曲目与歌词交互

沿用夜航配色、标题衬线、界面无衬线和时间等宽。当前电台下方展示简短曲目信息，详细歌词、搜索与收藏放入可滚动的原生模态面板。沉浸视图共用同一份曲目状态，不新增音频实例。手机保持纵向内容与 44px 操作目标。

- 只有实际播放的电台与线路才轮询元数据；暂停停止新请求，换台或换线路使旧结果失效。电台名称不能冒充歌曲。
- 明确标记电台提供的文字及观测时间；无法分出歌手与曲名时只展示原文，不提供歌曲收藏或歌词匹配。
- 歌词由用户按需查询，保留 LRCLIB 署名。请求合并、短期缓存、全局并发与速率上限防止重复访问；无结果、服务错误及冷却均有明确状态。
- 多个准确名称匹配的歌词版本由用户选择。纯文本直接阅读；时间戳本身不能证明直播当前歌曲位置。没有可靠位置时，只有显式选择歌曲起点或“此句在此刻”后才提供手动跟随，并允许偏移和暂停跟随；换歌、换台或切换版本重置校时。
- 歌曲收藏使用既有本地格式，支持取消与复制清单；外部入口只生成经过编码的搜索链接，不标为已匹配歌曲页。

接口、验证与外部能力限制随实际实现记录到任务归档及产品进度。
