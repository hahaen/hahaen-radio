# LINUX DO 微应用协作规范

- 应用名称统一为「声屿 HAEN」。本目录维护 LINUX DO 入口、SDK 适配、直播清单和 ZIP 构建。与官网共用上一级 `src` 的界面、目录筛选、图形和播放器控制。
- 只在准备版本时通过公开接口只读导出目录，记录目录版本、导出时间和条数。地图和目录随包发布，通过 SDK 读取。目录、详情、筛选、搜索、同城和随机选台均使用包内数据。收藏和设置保存在 SDK 应用存储。
- 运行时禁止调用声屿后台服务，包括 `radio-api`、`radio-jobs`、账号、登录和识曲接口，不引入代理。快照只包含公开的电台目录字段，排除账号、凭据、私有收藏、诊断及音频数据。
- 可播清单单独维护。接入前核对官网电台与运营方公开提供的播放源，只连接有第三方使用依据且声明在 SDK 清单中的 MP3 端点。待验收候选只进入沙箱和本地检查包。正式候选需要记录桌面和手机的真实沙箱验收。试听由用户点击触发，在当前页播放。
- 本地隔离检查可用真实直播的短样本检验解码、调度和停止。真实沙箱验收需在 LINUX DO 内执行。
- 仅本目录受影响时，只构建微应用。共享代码变化时，检查并更新受影响产物。官网上传目录与微应用 ZIP 输出必须分开。应用 ID 只从 Git 忽略的仓库根 `.env.local.linuxdo` 读取。应用 ID 配置与生成的 ZIP 都留在本机。正式上架由用户操作。
