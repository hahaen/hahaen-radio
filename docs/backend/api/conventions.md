# API 约定

## 协议与路径

使用 HTTPS、REST 和 JSON。业务接口统一前缀 `/api/v1`，Fastify 和反向代理保留一致路径。接口名称、字段和资源模型待业务设计确定。

读接口遵循 GET 语义；写操作按幂等性选择方法。分页、排序、筛选参数在契约中明确，限制页大小和查询成本。

## 契约与校验

共享包保存 Zod Schema、DTO 和可公开的错误码。Fastify 接入兼容的 Zod 类型适配器，统一校验 Path、Query、Body 和响应。

OpenAPI 从接口 Schema 生成，Swagger UI 用于开发与验收。初始化时验证适配器、Schema 转换与 OpenAPI 插件版本组合。生产文档入口的可见性通过部署配置决定。

## 响应与错误

成功响应直接返回接口契约规定的资源或分页结构。错误响应统一包含 `code`、`message` 和 `requestId`，需要时增加经过过滤的字段校验信息。

HTTP 状态码表达成功、输入错误、资源不存在、冲突、限流或服务故障。内部异常栈、SQL、环境变量和第三方私密响应不对外返回。

## 请求边界

设置请求体大小、处理超时和限流策略。受信任代理配置必须匹配实际 Caddy 链路；不能无条件信任客户端传入的转发 IP。

外部调用和只读重试设置上限。取消请求能够传播到外部调用；写操作不在未知执行结果下自动重复执行。

## 发布兼容

前后端可能分开更新，同一 API 版本内优先增加可选字段和兼容行为。删除字段、改变含义或默认行为前明确迁移窗口与发布顺序。
