# 声屿 HAEN：完整产品目标与分阶段执行说明

## 一、最终目标与执行边界

将当前工程骨架建设为完整、可运行、可部署的全球电台收听网站「声屿 HAEN · 嗯，听听世界。」，同时适配电脑和手机。

用户能够通过地球、流派视图和搜索发现电台，真实收听直播，管理电台与歌曲收藏，查看可获得的曲目信息和歌词，并使用分享、睡眠定时和沉浸收听功能。

**完成标准是具备真实数据、真实播放、异常处理、测试证据和部署材料的产品，不能以静态页面、模拟播放或未接入的按钮代替完成。**

- 完成功能所需的迁移与配置；已在执行的数据库、备份或恢复操作安全收尾。

### 统一交互规则

- 搜索、筛选、随机调台和可视化使用一致的候选范围；直接打开分享电台不擅自清空已保存筛选。
- 多个筛选维度取交集，同一维度的多选取并集；零选项表示零结果，并提供恢复全部操作。
- 当前播放台被筛选排除时继续播放，明确标记其不在当前筛选中；下一次自动探索使用新筛选。
- 暂停后拖动场景可以选择电台，但不能擅自恢复播放。
- 键盘支持空格播放暂停、方向键换台、`G` 切换视图、`/` 搜索、`F` 收藏、`L` 固定、`M` 静音、`Enter` 进入、`Esc` 返回；输入框和中文输入期间不触发全局快捷键。
- 手机核心操作均有触屏入口，不能依赖悬停或键盘。

## 三、数据、接口与运行方案

### 数据接入

- **电台目录**：通过服务端接入 Radio Browser，使用稳定 UUID 和国家代码，支持服务镜像发现、切换、分页导入及明确的客户端标识。[接口说明](https://api.radio-browser.info/)
- **地名与时区**：使用 GeoNames 离线数据补充可确认的地理信息，保留必要署名；不让每次浏览依赖在线地名查询。[数据说明](https://www.geonames.org/export/)
- **地球底图**：使用 Natural Earth 数据生成本地轮廓与点阵资源，随构建交付。[使用条款](https://www.naturalearthdata.com/about/terms-of-use/)
- **歌词**：通过服务端适配 LRCLIB，控制请求、缓存和重试；上线前核对服务条件与歌词展示要求。[项目说明](https://github.com/tranxuanthang/lrclib/blob/main/README.md)
- **识曲**：预留 AudD 标准短片段识别适配器，默认关闭。只有用户提供有效凭据及明确额度后才启用；免费试用不能作为长期免费承诺。[服务说明](https://www.audd.io/pricing/)

### 目录与后台任务

- 持久化电台、线路、地点、目录版本、同步任务、人工屏蔽规则及有限诊断数据；不建立用户账号和云端收藏表。
- 每日 UTC 02:00 调度目录同步，另提供手动同步命令；采用任务租约、幂等更新和分批提交。
- 新目录完成校验后再发布为可用版本；同步失败继续使用上一成功版本，不因部分请求失败清空目录或批量下线。
- 对完整同步中持续缺失或明确不可用的电台保留状态记录；普通客户端的一次失败报告不能直接造成全局下线。
- 保留地理精度与信息可信度。无精确坐标的电台仍可搜索、列表浏览和播放；国家级聚合位置不伪装成城市位置。
- 前端按版本加载并缓存精简目录，详细信息按需读取；不能每次进入页面都串行查询全部电台详情。

### 对外接口

统一采用 `/api/v1`、Zod 共享契约和 OpenAPI，接口按以下职责建立：

| 接口组 | 最小职责 |
| --- | --- |
| 目录 | 目录版本、真实数量、流派与语言字典、场景数据分片 |
| 电台 | 分页搜索、详情、同城列表、指定 ID 批量查询、有效播放线路 |
| 曲目信息 | 当前元数据、观测时间、来源类型及时间可靠性 |
| 歌词 | 歌曲查询、纯文本或时间戳结果、未匹配及服务异常状态 |
| 识曲 | 按电台 ID 发起识别，返回结果、冷却、配额或不可用状态 |
| 诊断 | 有限播放故障报告；不接收任意日志或任意远程 URL |
| 健康与能力 | 存活、数据库与目录就绪状态、可用增强能力 |

共享类型至少区分 `StationSummary`、`StationDetail`、`StreamCandidate`、`CatalogManifest`、`NowPlaying`、`LyricsResult`、`RecognitionResult` 和统一错误响应。缺失值与未知值不能混用，电台实体不能直接暴露数据库行或私密配置。

### 音频与资源边界

- 持续音频默认由浏览器直连电台，API 不承担全量音频代理或转码。
- 优先使用可用 HTTPS 线路，分别检测原生 HLS、hls.js 和编码支持；不擅自把 HTTP 地址改成 HTTPS。
- 同台线路依次有限尝试；默认单线路连接超时 8 秒、同台最多尝试 3 条，再进入失败或有限跳台流程，禁止无限重试。
- 媒体可播放与 Web Audio 可分析分别判断。分析不可用时保留基础播放，音量统一与真实频谱相应降级。
- 曲目元数据只对正在收听的电台按需获取，同台请求合并、有限缓存，不持续监控全部电台。
- 服务端远程访问必须校验协议、解析地址及每次重定向，阻止私网与任意代理；识曲只接受电台 ID，不接受客户端指定采样地址。
- 普通日志和故障报告默认保留 7 天，脱敏并限制体积；不持久化访客跟踪标识或原始 IP。
- 所有凭据仅通过服务端私有配置注入，显式加载并校验，不进入前端、镜像层、文档或提交。

## 五、验收矩阵与完成判定

### 功能场景与后续专项清单（按本次完成标准判定）

- **核心闭环**：首次进入 → 用户开始 → 搜索或地球选台 → 真实播放 → 换台 → 收藏 → 分享 → 刷新恢复。
- **播放边界**：自动播放被拒、线路超时、备用线路、HLS 失败、网络中断、连续快速切台、暂停后操作场景、固定台失败。
- **数据边界**：空库、目录更新失败、上游字段异常、缺少坐标或时区、重复数据、版本更新时仍在播放、被屏蔽电台的旧分享。
- **本地数据**：存储不可用、旧版本数据、损坏文件、超大导入、重复合并、下线收藏、历史清空及跨标签页状态更新。
- **曲目能力**：元数据换歌、旧响应迟到、无歌词、纯文本歌词、同步歌词、时间偏移、识曲无结果、服务不可用及配额耗尽。
- **图形交互**：地球与流派切换、密集地点、拾取与拖动区分、窗口变化、WebGL 初始化失败、上下文丢失和恢复。
- **界面兼容**：Chromium、Firefox、WebKit；1440×900、768×1024、390×844、320px 窄屏及手机横屏。
- **可访问性**：键盘、可见焦点、弹层焦点管理、触屏目标、200% 文字放大、减少动态效果和暗色对比度。

### 目标模式的持续执行规则

1. 每次继续前读取目标说明、项目规则、进度与当前 Git 状态，确认已完成项和下一阶段。
2. 每个功能同时交付实际实现、适用异常状态、必要测试和文档，不积累大量不可运行的中间模块。
3. 仅 Review 本次改动及必要上下文；修复并复审后验证，按项目规则完成同步、复审、提交和推送。
4. 每个阶段记录实现状态、验证环境、执行结果、提交和遗留事项，支持中断后继续。
5. 假数据仅用于明确标记的测试与开发场景，不能成为正式应用默认数据或验收证据。
6. 验收状态使用“已通过／未通过／待外部条件／不适用”，不能把未执行检查写成通过。
7. 本次门槛满足后停止自动续跑，不因专项清单尚未穷尽继续追加任务。后续需要凭据、设备或发布时由用户另行启动，不公开秘密。
