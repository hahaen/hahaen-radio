# 电台目录同步恢复

生产每日目录同步在获取上游分页时失败，线上继续读取上一份成功目录。生产任务容器实测首批及中间位置的 1,000 条分页约 63–86 秒返回完整响应，超过原来的 20 秒单页时限。

单页时限提高至 120 秒，首个分页成功后最多并行抓取 4 页，按偏移量顺序处理。遇到目录末尾时忽略其后的并发结果。重试次数、单页体积、镜像隔离、数据校验、目录骤减保护和原子发布继续沿用现有流程。正式任务通过 `CATALOG_SYNC_TIMEOUT_MS` 配置 45 分钟整轮上限，本地默认仍为 5 分钟。

服务端 221 项测试通过，覆盖并发窗口、乱序响应、分页末尾、镜像切换、重试与整轮取消。类型检查、构建、改动文件的 ESLint 和格式检查、文档链接检查通过。生产验收以新版 `radio-jobs` 完成一次目录同步、数据库记录发布成功及公开目录接口返回新版本为准。
