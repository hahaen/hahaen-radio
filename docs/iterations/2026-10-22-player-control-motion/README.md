# 播放控制区轻动效

## 需求与范围

为透明播放控制区增加克制的播放氛围与操作反馈，保留现有布局、音量行为和夜航配色。

## 实际变更

- 地球收听页仅实际播放时显示主按钮外缘的珊瑚色柔光，5 秒明暗循环；按钮与命中区域不缩放、不位移，手机减弱光晕。
- 上一站、下一站的图标在操作后轻移 3px；收藏、固定、沉浸和分享图标短暂放大后归位。反馈持续 260ms，兼容点击、触屏激活和键盘激活。
- 暂停、缓冲及其他非播放状态不显示呼吸。减少动态效果、省电或页面隐藏时停用持续和短暂动效；离开时清理监听、待执行帧和动画。
- 音量滑块不添加动画，不读取音频频谱，不创建新的音频实例。沉浸播放托盘不增加持续光晕。

## Review 与验证

- 已检查本次差异的状态条件、交互语义、动画清理、布局与已有功能边界；短暂反馈安排在下一帧，以便固定状态切换后动画作用于更新后的图标。
- 已通过前端类型检查、针对本次 TypeScript 的 ESLint、Prettier、生产构建、资源预算、文档链接和差异空白检查。构建保留既有大 chunk 提示，资源预算未超限。
- Playwright 最终一轮 8 项通过：Chromium 的 1440×900、768×1024、390×844、320×700、844×390；Firefox 和 WebKit 的 1440×900；Pixel 7 触屏模拟的 390×844。其余 12 个重复浏览器/尺寸组合按测试分工跳过。
- 检查了光晕明暗实际变化、按钮边界稳定、无水平溢出、收藏鼠标/键盘反馈，以及暂停、缓冲、减少动态效果、省电与模拟页面隐藏时停用；验证仍只有一个音频元素。音源与目录为可控测试夹具，不代表真实外部电台或真机后台验收。
- 首轮短暂动画断言与明暗采样受观察时机影响，改为记录浏览器动画创建并检查结束、在动画时间轴的两个固定位置比较实际样式。截图检查发现光晕左侧被播放器裁切，已让外层允许光晕溢出，信息区继续独立滚动。
- 人工查看了[桌面](desktop.png)、[平板](tablet.png)、[手机](mobile.png)、[窄屏](narrow.png)和[横屏](landscape.png)截图。截图为本次控制区的验证样例，其他模块可能继续独立迭代。
