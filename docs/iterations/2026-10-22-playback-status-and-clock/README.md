# 播放状态动效与秒钟显示

日期：2026-10-22。

## 需求与实际变更

让“正在收听”旁的珊瑚色竖条在实际播放时错落起伏。沿用 19×14px 图标区域、颜色与状态文字，使用 1.1 秒循环的 CSS 背景尺寸动画；不新增定时器、音频分析、组件或依赖。暂停及其他非播放状态不运行该竖条动效，缓冲和连接继续沿用原有细线提示。

减少动态效果或省电模式下保留静态竖条。动画表示播放状态，不代表实时音频频谱。

中国时间增加秒，显示为 `HH:mm:ss`，按整秒校准更新。继续使用 `Asia/Shanghai`，中英文日期、农历、页面恢复校准与计时器清理保持原有行为。
