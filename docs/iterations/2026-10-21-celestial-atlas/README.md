# 地球质感与流派星图精修

日期：2026-10-21。

## 需求与实际变更

继续改善地球和流派页面的观感，沿用墨绿、暖白、灰绿与珊瑚橙的夜航方向，并逐项核对桌面与手机。

- 地球调整大陆明暗过渡、海面反光与球缘透光，保留原有海陆数据和电台标记语义；背景增加低亮环境光。
- 准星改为更细的定位环与四向刻度；当前电台标注增加方向引线和局部渐隐底色，提高复杂背景上的可读性。
- 流派增加标题层级和衬线名称，采用不同旋臂、环形与球状的装饰粒子形态，配合类别色、细轨道与真实电台数量；当前流派保持文字旁的珊瑚标记和 `aria-current`。
- 宽屏且高度充足时保留四列三行；低高度桌面、平板和手机根据容器空间切换为一至两行横向浏览。翻页按钮支持鼠标、触屏和键盘，边界状态自动更新；减少动态效果或省电时即时翻页。
- 轨道在悬停和焦点时变化，粒子保持按需绘制。画布按实际滚动区裁切并在绘制前清除，避免越过标题、残影或已滚出区域的图形。
- 无 WebGL 时使用同一套形态采样生成 SVG，保留流派选择、真实数量、焦点返回与暂停状态。
- 手机流派视图的地图信息移到标题侧边，避免盖住末行标签；小屏可用高度不足时减少行数，保留播放器。

## Review 与验证

每轮修改先 Review，再进行受影响验证。范围限于上述组件、样式、图形材质与测试，核对坐标及目录数量未被本次修改、装饰语义、布局、选台状态、键盘与触屏入口、减少动态效果、监听器及 GPU 资源释放。

迭代中修正了低高度图形过小、手机信息按钮遮挡、提示接近播放器、横向浏览缺乏显式入口，以及画布越界和潜在残影问题；放大文字场景还修正了相邻英文标签相互挤压和数量被翻页栏遮挡。测试明确等待两个图形引擎初始化后再验证独立释放，并用专用标记定位 SVG 降级图形。

- 地球和流派跨浏览器回归 36 项通过，覆盖 Chromium、Firefox、WebKit 与 Pixel 7 模拟：六种视口、标签可达、无重叠、44px 操作目标、axe、暂停与双语、无 WebGL 降级、按需停绘、省电 DPR 及资源释放。
- 最终流派回归 32 项在独立预览通过；另含 4 项地球检查。新增英文窄屏放大文字检查，名称为 28px、数量为 20px，验证相邻标签不重叠，焦点进入后标题与数量均位于滚动区内。各批次有重叠，不累加为独立场景数量。
- 同步当前分支与两个远端后复核本次差异，重新检查受影响的页面、类型、构建和资源预算；原有其他任务内容保持独立。
- 前端 TypeScript、定向 ESLint、生产 `/radio/` 构建和资源预算已通过；地图相关单元测试 3 文件 10 项通过。构建仍有既有大分包提示。
- 本地只读加载真实公开目录 40,567 台，六种尺寸逐项检查流派焦点可达及页面无横向溢出，截图如下。所有截图保持暂停并临时固定当前台，不代表实际音频输出验证。
