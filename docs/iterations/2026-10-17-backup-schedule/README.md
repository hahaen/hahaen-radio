# 每日备份与副本复制

## 需求与实现

补齐每日备份执行、可校验副本与服务器定时材料。新增 copy 与 daily 子命令、两端文件互斥、同目录/嵌套/同设备保护、严格文件权限和复制后完整复验。副本损坏不覆盖，复制失败保留新主备份及旧备份，并返回可重试的主备份 ID；只有副本创建成功后才分别执行两端保留清理。

每日流程与手工清理共享周期互斥，避免清理正在处理的主备份。正式库模式要求不同文件系统设备，实际物理独立性仍需操作者核对。增加 Ubuntu 24.04 systemd service/timer：每日 UTC 03:00 加随机延迟、错过后补触发、挂载断言、专用用户、共享发布文件锁、控制组终止和明确的配置加载。没有安装或启动服务器服务。

## Review 与验证

Review 仅覆盖本轮备份函数、CLI、测试、空值变量、unit 和相关文档，核对目录身份、目标防覆盖、大小/取消、主副互斥、失败清理、权限、脱敏输出和保留顺序。修正了手工清理与每日流程的交错风险，并将保留主备份 ID 的错误范围限定在副本创建失败，避免错误声称清理失败时的状态。

完整工程检查含格式、Lint、TypeScript、181 项普通测试和前后端生产构建。5 项新增普通用例及原有用例共 13 项备份测试，覆盖完整复制、相同副本重用、损坏拒绝、同目录/别名/嵌套/链接、设备保护、互斥与取消；普通命令按设计跳过 10 项 MySQL 用例。范围修正后另复跑类型、Lint、13 项备份测试及真实恢复入口。

专用 MySQL 8.0.46 验收实际执行编译 CLI：周期占用时每日与手工清理均拒绝；副本锁占用时保留新主备份及全部旧备份，返回 ID 可通过 verify；解除故障后每日流程完成，daily 清单无跨时点行数。copy 命令代替手工 cp，重复复制安全复用，删除原备份后仅从副本恢复；核对 11 张表、3 条迁移、Unicode、约束、持久额度、API 就绪以及既有锁竞争和失锁退出。结构化结果见[证据](results.json)。

同步 upstream 无新增提交，19 个任务文件的内容、权限与空暂存状态完整恢复。同步后仅复审本轮差异，再次通过格式、Lint、类型、181 项普通测试及生产构建，10 项普通命令中的数据库用例按设计跳过；专用真实 MySQL 入口再次通过全部每日、副本、恢复及清理检查。源码与 unit 摘要对应关系已复核。

## 未完成与边界

本机副本位于另一个私有目录，不是异盘或远端灾难恢复证据。本机 macOS 没有 systemd，本轮只核对官方参数和配置语义；目标 Ubuntu 需运行 systemd-analyze verify、实际服务、定时/补触发、共享文件锁、挂载失败及存储故障验收。Docker 实测继续按用户要求留到真实部署时。

没有新增迁移，没有改动开发/正式库，没有创建远端 Jenkins 任务、启用定时、上传镜像或真实备份。Jenkins 外层流程、真实存储部署、正式恢复手册、日志保留与其他剩余验收继续推进，完整目标未完成。
