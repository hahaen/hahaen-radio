# 移除流派探索

日期：2026-10-22。

## 需求与实际变更

移除顶部地球/流派切换和独立流派探索页，清理专用星云图形、样式与双语文案，撤下 G 快捷键及帮助说明。主界面固定为地球探索，手机语言按钮上移至原视图切换位置。保留底部流派筛选、电台分类、搜索、收藏、收听与沉浸。

旧版本保存的 `view: genres` 兼容读取为 `globe`，保留音量、静音、提示和闲置沉浸偏好。无需修改服务端契约与数据。

Review 仅覆盖本次入口、图形与样式清理、旧偏好兼容、快捷键、用例调整和相关文档。确认地球、流派筛选与音频生命周期保持现有行为，没有未解决问题。

- 25 项相关单元测试通过，覆盖个人库、快捷键、应用入口与地点模型。
- 前端 TypeScript、改动文件 ESLint/Prettier、Vite 生产构建、静态资源预算、文档链接与 `git diff --check` 通过。构建仍提示既有大包体积建议，资源预算全部满足。
