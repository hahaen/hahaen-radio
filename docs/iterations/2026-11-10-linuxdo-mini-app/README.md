- 官网产物位于 `apps/web/dist`。微应用 ZIP 位于 `apps/web/linuxdo/dist`，不随官网发布。打包脚本从仓库根目录的 `.env.local.linuxdo` 读取应用 ID。配置文件和 ZIP 均由 Git 忽略。已核对缺少 ID 时的打包提示及本地核验 ZIP。
