# 探索阶段：离线地理数据

## 范围与变更

阶段 4 首先准备地球真实数据：GeoNames 解析、受控地点导入、目录发布前的地理匹配，以及 Natural Earth 本地大陆轮廓、点阵和静态降级资源。本次不将阶段 4 标为完成，字体、地球与流派交互仍待实现。

- 复用既有三张地点与任务表，原两条迁移不变；增加 `pnpm places import`，显式读取任务环境文件。
- 地点全量替换在一个有界事务内，导入串行化；目录同步只读取完整已提交地点，匹配失败保留未知信息。
- 最近聚落只标“附近”，时区限定 100m 点匹配与相邻证据一致，不制造城市边界结论。
- 固定 Natural Earth 5.1.2 与摘要，生成 127 个大陆多边形和 7,595 个点，提供可重复生成脚本；不添加在线地图或访客追踪服务。页面提供 GeoNames 与 CC BY 4.0 双语署名入口。

## Review

仅审查本次解析、位置索引、导入事务、同步接入、静态资源和文档。重点检查经纬度缺失、国家不符、极区与日期变更线、时区冲突、批次取消、行锁与操作期限、来源许可和输出边界。复核时修正极区经度范围，确保跨极点时不遗漏另一侧聚落，并在最终写入后再次检查取消信号。读取元信息显式使用可重复读；独立 MySQL 验收发现当前 ORM 将两个额外事务标志拼成非法组合，已移除该组合，只保留明确隔离级别，元信息查询仍共享同一事务快照。导入标记在行锁下单调推进，避免同时发起的导入具有相同时间标记。

## 验证记录

- 格式、Lint、strict 类型检查、58 项普通测试和生产构建通过；包含数据署名的 36 项浏览器回归通过。冻结依赖安装通过；拉取远端后复审及对应检查、构建、36 项浏览器与 6 项 MySQL 复验再次通过。
- 原生 MySQL 8.0.46 隔离验收 6 项通过；新用例在首批 2,000 条写入后触发取消，确认 1,001 条旧地点完整保留，并区分成功与失败任务记录；读取中途替换为另一版本时明确拒绝继续拼接。隔离测试库已清理。
- 实际导入开发库 34,165 条 GeoNames 地点，覆盖 244 个国家或地区、356 个时区；输入文本约 8.54MB，SHA-256 为 `b63f1ce899b71dd07b489c795eb78f3edd3dd4356a4d78d0bd3b3a618f43c6be`。这是 2026-10-17 获取的数据快照，不能用作以后每日更新文件的恒定摘要。
- 地形生成输出摘要和坐标范围检查通过，静态世界图经 Chromium 渲染后人工检查；尚未接入交互地球。
- 首次真实目录补充因一次读取全部地点超过 15 秒数据库操作期限而失败，旧目录未改变。修正为每批 1,000 条读取并核对导入版本及总数，保留原超时限制；增加读取过程中替换地点的 MySQL 回归。开发库完整分批读取已验证为 34,165 条、约 22.3 秒；再次真实同步成功发布版本 `77f100f6-42ff-40cc-8d31-3e893b777408`，共 68,816 条电台，13,593 条补充附近地名、523 条补充有证据时区，精确城市仍为 0。整次目录任务约 287 秒，含上游获取、地名读取、暂存与发布。

## 交付与遗留

涉及 Web 数据署名、服务端共用仓储与任务进程、手动运维命令；API 不新增权限或契约字段，不要求数据库迁移。部署时先交付任务和 Web 代码，再由用户确认目标环境后导入地点、同步目录；正式库未执行，未触发部署。Docker 检查按用户要求在实际部署环境执行。

地球与流派场景、同城展开、自动选台、字体和双端探索构图仍在阶段 4 内，后续阶段与完整验收继续推进。
