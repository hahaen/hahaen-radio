# 浏览器端到端测试

已建立 Chromium、Firefox、WebKit 与 Pixel 7 模拟项目。执行 `pnpm test:e2e`，默认自行启动本地 API/Web，不复用其他进程。

`fixed-screen.spec.ts` 在 1440×900、768×1024、390×844、320×700 与 844×390 验证文档不滚动、视口高度变化、角落播放器、目录内部滚动与返回焦点；搜索选台用例通过共用入口展开顶栏搜索后操作。

`application.spec.ts` 检查同域接口、双语与语言保存；`audio.spec.ts` 仅在测试上下文拦截目录和媒体 URL，使用 `apps/web/tests/fixtures/audio/` 的自制 MP3、AAC 和 HLS 片段验证实际浏览器解码、进度、暂停恢复、备用线路、快速切台及清单加载中暂停。

媒体响应支持 Range 和正确 MIME/CORS。测试音量预先调低；用媒体事件和时间进度证明浏览器实际处理数据，不宣称已验收扬声器、锁屏或真实手机后台。真实外部电台结果与这些可控样例分开记录。MPEG-TS 片段虽以 .ts 结尾，但属于二进制媒体，由格式和代码检查明确排除。

2026-10-17 的历史记录包含260个项目用例，其中257项通过、3项桌面触摸合成不适用；历史证据见[可访问性记录](../../../../docs/iterations/2026-10-17-accessibility/README.md)。触摸合成仅在具备对应能力的移动模拟项目执行，不能当作真实手机验收。

`library.spec.ts` 补充 9 个场景，在四个项目验证筛选、真实播放保持、跨标签页收藏与历史、暂停恢复、分享、清理确认、文件迁移和存储降级。测试仅在专用浏览器上下文操作本地数据；媒体仍使用可控样例，分享使用可观察的剪贴板替身，不触发外部消息发送。

`controls.spec.ts` 在四个项目检查设置与语言同步、真实音量、截止时间与恢复、输入保护、刷新后的上一站、沉浸和焦点、闲置与减少动态效果、原生可用系统媒体动作、五种视口及英文 200% 文字。媒体动作的测试观察仅通过初始化脚本注入，不进入应用；不代替真实锁屏与后台验收。`listening-fixture.ts` 提供个人工具共用目录和可解码音源。

`enhancement.spec.ts` 的 4 个场景分别在四个项目验证有界 CORS 样本的实际离线解码与衰减、基础音量不被覆盖、跨标签页关闭与停止后不再取样、CORS 明确拒绝后仍播放、原生合成音节点与暂停清理、缺少增强 API 时的降级。主媒体没有连接分析音频图；WAV 循环只由测试钩子启用，源振幅与基础音量见[样例说明](../fixtures/audio/README.md)。这些观察不替代真实扬声器听感或所有外部电台的分析许可。

`information.spec.ts` 补充双语说明、署名及本地许可、持续播放与焦点返回、无自动提交的反馈预览/复制、剪贴板拒绝、窄屏/平板/横屏及放大英文文字。反馈内容为当前可控播放状态，无真实账号或私人数据。

`diagnostics.spec.ts` 覆盖当前固定电台的实际失败状态、显式提交、最小字段、未核实回执、失败/限额后的同回执手动重试，以及关闭和换台后丢弃迟到结果。API 响应为可控样例；真实数据库仓储另在隔离 MySQL 验收。

`stability.spec.ts` 使用明确的 3 万条合成目录，覆盖 30 个分片、搜索筛选、60 轮实际音源切换和视图切换、暂停及刷新缓存；Chromium 补充 GC 后堆、节点和监听器采样，其他浏览器只报告可观察范围。它不代表实际手机或真实网络吞吐验收。

本目录集中保存浏览器端到端用例及必要的可控测试数据，按实际应用路径逐步组织。测试使用独立环境，不能将生产凭据、用户数据或实际运行产物作为测试素材提交。

单元和组件测试优先靠近对应实现；移动端音频与后台行为仍需真实设备验收。

相关约定见[质量与测试](../../../../docs/engineering/quality-and-testing.md)。

`accessibility.spec.ts` 使用固定axe-core 4.14.0，对中英17种状态及各项目列表降级共140次扫描，保留incomplete与实际绘制样式，不排除规则。键盘循环、返回焦点、44px目标、窄屏/横屏与200%文字分别检查，方法和人工边界见[说明](../../../../docs/engineering/accessibility.md)。电台选择器使用动作/台名前缀并正确转义，以适配新增的地点和流派名称；组件测试另精确断言完整双语名称。

30000条目录夹具已提取到scale-fixture.ts，原短程规模断言保持不变，另供独立[生产持续运行](../performance/README.md)复用；独立配置中的六项与普通浏览器批次分别统计。

`country-search.spec.ts` 使用三地合成目录，在电脑浏览器和手机模拟视口验证“中国”“China”“CN”包含台湾电台，同时保留台湾单独搜索、组合词和页面宽度检查。真实分页仓储由隔离 MySQL 用例覆盖。

`celestial-layout.spec.ts` 验证全屏居中地球、左下播放器、顶栏展开搜索与焦点、紧凑非模态收藏面板、底部流派筛选、中英 axe 扫描及移除曲目/手动识曲入口。旧的曲目与识曲页面用例随入口移除，由新页面契约断言替代；后台与独立模块单元测试保留。

`welcome.spec.ts` 检查欢迎入口、直接开始、先浏览、手机布局与首屏 axe 扫描。测试夹具使用连续音频模拟直播，音量校准仍使用独立短采样；完整批次与定向复验分别记录，见[全系统样式统一](../../../../docs/iterations/2026-10-18-unified-visual-style/README.md)。

`china-clock.spec.ts` 在浏览器处于纽约时区时验证固定中国时间、日期、欢迎页、换台、中英文布局与 axe 扫描，覆盖桌面、窄屏手机和手机横屏。跨日更新、恢复校准及资源清理由 `ChinaClock.test.tsx` 验证。
