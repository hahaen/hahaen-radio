# 地球与电台播放动效

日期：2026-10-22。

## 需求与实际变更

播放时增强地球光圈和周围电台点的动态感。球缘光晕以约 3.5 秒周期柔和呼吸；选中电台的细环、刻度与光核同步明暗变化，细环轻微缩放。周围电台按固定位置生成不同相位与约 2.3–3.5 秒的周期，增强亮度、外晕与微小尺寸变化，始终保持可见。

动画由实际播放状态驱动，不表示真实音频频谱。沿用现有约 30fps 的按需渲染循环，不新增依赖、几何体或每帧 React 更新。暂停、减少动态效果与省电时恢复静态；页面隐藏、场景切换和销毁沿用现有停止绘制与资源清理。目录没有可绘制点时，播放中的球缘仍可呼吸。位置、拾取与精度语义不变。

## Review 与验证

Review 仅覆盖本次引擎动效、专项浏览器用例与文档，检查播放条件、无电台点状态、减少动态效果、省电、可见性、材质资源复用和固定地理位置，无未解决问题。

- 8 项播放动效 Playwright 回归通过，覆盖 Chromium、Firefox、WebKit 和 Pixel 7 Chromium 模拟；像素对比单独验证选中环、周围电台点与无电台点时的球缘变化，绘制计数验证暂停、减少动态效果、省电时停止持续绘制。
- 4 项既有地球清晰度回归通过，验证 3 万电台数量、键盘操作、DPR 上限和空闲停止绘制。
- 实际检查 1440×900、768×1024、390×844、320×700、844×390 截图，无新增横向溢出。采用受控音源和合成目录，不代表真实电台分布或真实设备验收。
- 前端 TypeScript、定向 ESLint/Prettier、生产构建、静态资源预算与文档链接检查通过。构建仍有既有大包提示，资源预算满足。
- 最初的周围光点取样失败源于旧合成目录的国家字段与全球坐标冲突，专项用例显式清空国家并保留坐标；空目录用合法空分片列表表达，减少动态效果检查等待视口与居中过渡收敛。测试修正后重新 Review 并复验。

使用独立工作副本与端口验证，未混入工作区其他地理位置任务改动。同步 upstream 与另一个远端后确认均无新增提交；复审本次差异，并复验 Chromium 两项动效、前端类型、构建与文档检查通过。
