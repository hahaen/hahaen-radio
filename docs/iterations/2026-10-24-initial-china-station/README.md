# 首次选中中国区电台

2026-10-25 更新：下文的分页选台方式已由[单次服务端随机选台](../2026-10-25-initial-playback-latency/README.md)替代；默认暂停、地区范围及手动选择优先级保持一致。下文保留原轮次验证记录。

## 需求与行为

电脑网页、手机网页与 Android App 初始选台优先中国区随机电台，进入时不自动播放，点击播放后才连接音频。

- 网页在没有分享目标、上次电台且尚未进入浏览时，预选随机中国区电台并保持暂停。已有标签页浏览状态下，首次主动开始收听也从中国区选择。已有上次电台或分享链接继续优先恢复对应目标，保持暂停。
- Android 在没有当前电台或待处理选台时静默预选；返回前台或 Activity 重建保留当前选择。进程重启后重新预选，不自动恢复播放或睡眠计时。
- 通过现有目录搜索分页读取候选，以真实 `countryCode === CN`、可用状态及类别排除再次筛选后随机选择；不是按语言判断，也不把名称匹配的境外电台作为候选。无中国区候选时保留空结果或可见错误，不静默回退到境外电台。
- 用户主动选台、下一台与恢复已有电台保持现有行为；迟到的默认选台结果不能覆盖手动选择。
- Android versionCode 由 2 增至 3，使用原应用 ID 与本机 Debug 签名覆盖升级。
