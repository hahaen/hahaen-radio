# 目录与电台 API

共享 Zod Schema 是请求和响应契约源。全部路径保留 `/api/v1`，当前响应设置 `Cache-Control: no-store`，浏览器后续按目录版本管理本地缓存。

| 方法与路径 | 行为 |
| --- | --- |
| `GET /health/live` | 进程存活，200 不代表目录就绪 |
| `GET /health/ready` | 数据库与目录都可读取时 200，否则 503；返回数据库状态、目录状态和版本 |
| `GET /catalog` | 活动目录清单、真实数量、语言和流派字典、分片清单 |
| `GET /catalog/:version/chunks/:index` | 不含播放地址的场景摘要，每片最多 1000 条；版本或分片不存在时 404 |
| `GET /stations` | 分页搜索与筛选 |
| `POST /stations/lookup` | `{ "ids": [...] }`，最多 100 个 UUID；去重返回详情及 missing ID |
| `GET /stations/random-china` | 从可用、非宗教的 `CN` 电台中随机返回一台完整详情及线路；无候选返回 `{ "station": null }` |
| `GET /stations/:id` | 电台详情、可靠的位置字段和线路 |
| `GET /stations/:id/streams` | 最多 3 条播放候选；已屏蔽或不可用时返回空数组 |
| `GET /stations/:id/same-city` | 仅在有可靠城市与国家时返回同城列表；不把未知城市归为同城 |

表中路径均以 `/api/v1` 开头。同城结果目前最多 100 条，返回未截断的总数。

## 搜索参数

`q` 最长 200 字符，按名称、已有地区/城市、附近地名及中英文国家名搜索，忽略大小写和拉丁重音。多个空格分词取交集。搜索“中国”“China”或“CN”时同时匹配台湾（`TW`）电台；“台湾”“Taiwan”和“TW”仍可单独检索台湾电台。`offset` 默认 0、最多 200000；`limit` 默认 30、最多 100。排序沿用目录 UUID 顺序，保持同一版本分页稳定。

`genres` 与 `languages` 使用逗号分隔，同一维度内多选取并集，维度之间取交集。省略参数表示全部，显式空值表示零选项、零结果。`minBitrate` 仅接受 0、128、192、320；未知码率不满足最低码率条件。

`playableOnly=true` 用于收听候选范围，只返回上游检查通过、存在 HTTPS 线路且未被人工屏蔽的电台；省略时为 false。该字段不代表已经在当前用户网络逐台播放验证。列表收听入口和随机选择使用相同条件，随机按完整结果总数选取偏移，不局限于当前页面。

`excludeIds` 可传入逗号分隔的最多 32 个 UUID，用于随机下一站与有限自动恢复时排除当前及本轮失败电台；省略表示不排除。此条件参与总数与分页计算，不以多次盲抽代替完整候选范围。

```text
/api/v1/stations?q=jazz&genres=jazz,world&languages=en,fr&minBitrate=128&limit=30
```

收藏筛选由浏览器使用同一契约数据和本地收藏集合处理，不上传个人收藏。不足城市或时区证据的字段返回 null。

## 首次随机选台

`GET /stations/random-china` 接受与列表相同的 `excludeIds` 参数（最多 32 个 UUID），返回 `{ "station": StationDetail | null }`。服务端按真实 `countryCode = CN`、可播放条件、非宗教分类和排除 ID 筛选，在同一目录版本的全部合格候选中随机选取，使用现有查询获取总数与一个随机偏移，不下载完整列表或探测外部音源。人工屏蔽参与查询；无候选时不回退境外电台。返回线路只代表目录判定可用，不保证当前设备即时出声。

网页与 Android 用此接口静默预选，点击播放才连接音频；正在进行的预选不会因点击播放而重新发起，接口返回的详情直接用于起播。分享与上次电台仍优先。新接口为增量能力，旧列表及详情接口不变；发布顺序为 `radio-api`、`radio-frontend`，Android 使用新包。无需数据库迁移或 `radio-jobs` 更新。实现与验证见[首次起播优化](../../iterations/2026-10-25-initial-playback-latency/README.md)。

## 错误与边界

请求不合法返回 400；资源不存在返回 404；未配置数据库或尚无成功目录返回 503。统一错误包含 `code`、`message`、`requestId`，不返回 SQL、异常栈或上游原始响应。

没有数据库配置的本地基础入口仍可启动，只提供存活检查，目录明确不可用。生产入口必须有数据库配置。Swagger 开发入口为 `/api/v1/docs`，生产默认关闭。

后续曲目、歌词、识曲和故障诊断接口另行实现，不将本页列出的目录接口当作完整产品接口已完成。

## 语言兼容与目录归类

语言筛选接受旧目录的常见名称和 ISO 别名，与规范语言代码匹配；接口路径、DTO 和分页结构保持不变。新目录同步将有效语言代码与名称合并去重，剔除数字、网址等错误语言值，并对明确音乐标签补充流派规则。既有快照的持久内容不会因代码发布自动改写，需要后续正常目录同步发布新版本。无新增迁移，详见[体验记录](../../iterations/2026-10-18-listening-refresh/README.md)。
