# 国家级电台地图展示

## 需求与实际变更

缺少原始经纬度、但国家信息已知的电台也能通过地球浏览与选择，沿用夜航风格，并明确展示位置精度。

- 新增独立的前端展示位置模型：原始坐标优先，缺失时使用 Natural Earth 5.1.2 的国家/地区标签点；覆盖 250 个代码，来源、许可和摘要随资源交付。
- 空心点表示国家聚合，实心点表示原始坐标；不同精度分开聚合。国家点点击后分页查看全部候选成员，使用“同国家下一站”，不展示为同城或附近电台。
- 定位、选中光环、预览、详情与地图数量同步支持国家级位置。筛选沿用相同候选集合，不扩大到被筛除的电台；没有可用国家标签的电台继续通过列表、流派和随机探索收听。
- 不改写电台原始经纬度、城市、时区及位置精度，不从台名猜城市；不推导当地时间。目录 API、数据库与缓存格式保持兼容，已有目录无需重新同步。

## Review 与验证

- 本次差异 Review 已完成：核对原始证据与展示位置隔离、同国家与同城分组语义、候选筛选、分页、选择/定位一致性、图形资源、双语和移动布局；修正 NodeNext 工具入口的模块导入兼容要求后复审通过。
- 前端及共享契约单元/组件测试 100 项通过；模型与详情针对性复验 9 项通过。类型检查、ESLint、Prettier、Vite 生产构建、资源预算、文档导航与差异空白检查通过。生成资源摘要与中文字体覆盖已核对。
- Playwright 相关回归 96 项通过：Chromium、Firefox、WebKit 和手机 Chromium，覆盖国家点选择/定位、国家与实际坐标区分、15 台分页、未知位置、双语、收藏筛选、单屏布局、可访问性与降级。电脑 1440×900、手机 390×844；既有固定布局用例同时覆盖 768×1024、320×700、844×390。可控电台与音源均为测试资料。
- 原生内置浏览器只读核对开发环境真实目录：68,816 条目录中当前候选为 40,567 台；11,023 台使用原始坐标，新增 29,265 台使用国家级展示位置，共 40,288 台可在地图浏览（约 99.3%），279 台仍无可用展示位置。该数字是开发目录快照，不代表线上目录或精确台址覆盖率。
- GitHub 与 Gitee 的 `main` 同步检查无新增提交或冲突；恢复后逐文件核对 24 项任务内容，完成本次差异复审，9 项模型/详情测试和 4 项跨浏览器国家地图场景复验通过，类型、构建、资源预算、格式、静态与文档检查通过。
- 地图双语停留提示统一使用“选择电台”，避免将国家聚合成员称为附近电台。桌面与手机截图保留在被 Git 排除的 `apps/web/test-results/country-map/`，截图不作为生产发布证明。

## 发布与未完成事项

- 仅需更新前端静态资源（`radio-frontend`），无需更新 `radio-api`、`radio-jobs`，无数据库迁移、配置调整或生产 SQL 操作。
- 本次不自动发布；实际线上效果需前端发布后确认。城市/行政区正向地理匹配不在本次实现内，国家级位置不会宣称精确台址。
- 自动化手机视口不替代真实设备验收；本轮不改变音频引擎或播放协议。
