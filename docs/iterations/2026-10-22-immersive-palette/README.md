# 沉浸收听与地球色调统一

日期：2026-10-22。

## 需求与实际变更

用户指出沉浸收听与地球页颜色不一致，要求选择更协调的方向，调整另一处并保证画面质感。

保留地球页沉稳的墨绿与灰青方向，调整流光、潮汐和远山：压低铺满画面的亮雾，收敛偏黄绿的高光，保留光帘、水纹与山影的层次。播放声浪沿用灰青与少量暖白，珊瑚色继续用于操作与状态。

- 沉浸着色器从全局 `--color-bg`、`--color-surface`、`--color-secondary` 和 `--color-text` 读取颜色，通过 Three.js `Color` 转为线性空间，输出沿用统一色彩转换；不再用各场景独立的 RGB 向量指定颜色。
- 暗部微量抖动放在输出色彩转换之后，避免低亮度下线性噪声被放大。沿用原有单平面、帧率和像素上限。
- 静态 SVG 与加载底色使用相同主题变量，无 WebGL 或上下文丢失时保持同一配色方向。
- 不改变场景偏好、默认潮汐、播放会话或动效控制。本轮未修改地球材质、星空或选台居中实现。

## Review 与验证

Review 限于本次着色器颜色、静态 SVG、加载底色与文档，核对颜色空间、初始化、样式继承、浏览器兼容、绘制与资源生命周期。当前无未解决问题。

- 前端 TypeScript、定向 ESLint、代码 Prettier、`/radio/` 生产构建、静态资源预算、文档链接与差异检查通过；保留既有大分包提示。
- 12 个既有沉浸浏览器用例最终均通过，覆盖 Chromium、Firefox、WebKit 与手机 Chromium 模拟：三场景、双语窄屏、axe、同一音频会话、播放与暂停、场景切换、减少动态效果、省电、上下文丢失/恢复和资源释放。初轮并发执行出现截图超时和 Firefox 暂停帧比对失败；Firefox 串行原断言通过，Chromium 无头长动态用例两次超时，改用有界面 Chromium 后原用例及断言通过，未修改生产逻辑或放宽断言。
- Chromium 实际截图检查桌面 1440×900、平板 768×1024、手机 390×844、窄屏 320×700、横屏 844×390 的全部三个场景；标题和播放按钮在视口内，无横向溢出。桌面与手机各检查三种静态回退，未发现运行时或着色器错误。
- upstream 与另一目标远端同步时均无新增提交；任务差异复审一致，后续 `/radio/` 生产构建与原断言复验通过。
