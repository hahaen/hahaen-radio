# 中国搜索范围调整

## 需求与实现

- 搜索“中国”时应包含台湾电台，同时保留按台湾单独搜索。
- 在共享包中统一地区搜索词，`TW` 同时匹配“中国”“China”“CN”，继续匹配“台湾”“Taiwan”“TW”。
- 前端完整目录和服务端分页搜索使用同一规则，列表、随机探索及地点候选沿用各自现有筛选链路。
- 保留上游地区代码、城市和坐标，不修改目录数据、API 字段、数据库结构或缓存格式。
- 增加前端集合、隔离 MySQL 仓储及电脑/手机浏览器回归，覆盖数量、分页、组合词和单独搜索。

## Review 与验证

- Review 范围仅包含本任务共享搜索规则、前后端调用、回归用例及文档；核对搜索词交集、地区单独搜索、可用性、分页、筛选和缓存兼容性，无未解决问题。
- 定向 Vitest：12 项通过，覆盖集合搜索、目录 API 与快照。
- 服务端与前端 TypeScript 检查、定向 ESLint、服务端生产编译及 Vite 前端构建通过。前端仍有既有大 chunk 提示。
- 隔离 MySQL 8.0.46 验收通过，包含新增仓储搜索场景；测试库由现有工具新建、迁移并清理，未修改开发库或正式库。
- Playwright：Chromium、Firefox、WebKit 和 Pixel 7 模拟共 4 项通过；覆盖中国/英文/代码查询、台湾单独搜索、组合词及无横向溢出。电脑 1280×720、手机 412×839，截图已复核，两地电台同时展示，保持原有视觉风格。
- 本机 5173 已有服务，测试使用私有临时配置将 Web 测试端口改为 5174，未停止原服务。首次用例遗漏提交搜索表单，补齐 Enter 后复审重跑通过。
- 已执行 upstream 快进拉取与 Gitee fetch，两个远端均无新增提交；暂存前复审通过，复跑 12 项定向测试、格式、ESLint、文档导航（133 份 Markdown、838 个链接）与差异空白检查均通过。
