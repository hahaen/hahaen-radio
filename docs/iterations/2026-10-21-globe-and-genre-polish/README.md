# 地球、流派与电台点美化

日期：2026-10-21。

## 需求与实际变更

目标为继续美化地球、流派场景及地图电台点，沿用墨绿、暖白、灰绿和珊瑚橙的夜航方向，兼顾桌面与手机。

- 地球提升海陆层次与球缘质感，保持点阵大陆和低亮海洋纹理。
- 电台点改为细亮核心与柔和光晕；根据球面邻域的平滑密度收紧拥挤区域的尺寸和透明度，放大时减弱抑制。保留全部可定位电台、原始坐标、拾取、同地点展开和精度说明。
- 当前电台采用独立珊瑚色圆环、柔和光晕及暖色核心，免于密度弱化；国家级位置仍为空心点，不当作确切台址。
- 流派从可重叠的自由位置改为稳定分区的星云，类别具有不同旋臂、外缘、大小与色彩，名称和真实数量置于星云下方。桌面四列避开播放器与时钟；手机和低高度场景按可用高度横向浏览一至三行。
- 使用单画布和正交相机与 DOM 装饰区对齐，滚动、字体布局、焦点及当前类别变化时按需绘制；无 WebGL 时保留静态点阵与同一组按钮。星云按绘制面积调节亮度，避免手机中心过曝。
- 当前电台所属流派增加标识；中英文浏览提示和英文数量单复数同步完善。修正流派视图地图工具的透明区域挡住标签的问题，键盘焦点主动滚入可见范围。

## Review 与验证

Review 仅覆盖本任务的图形材质、密度计算、流派布局与文案、相关测试及文档，检查位置与标记数量不变、缩放边界、透明混合、选中态、精度语义、响应式布局、键盘、观察器与资源释放。各轮修改先复审，再进行受影响验证。

- 初轮修复低高度末行截断、横屏透明工具区域挡住标签、焦点进入横向隐藏项时未充分滚动的问题；补充目录加载完成的测试等待。
- 新目标加入电台点后，增加平滑密度、缩放恢复、选中核心与光圈，并保留国家级空心语义；核对真实目录的全景和欧洲密集区域。
- 测试夹具修正了刷新时覆盖语言偏好、媒体尚未真正播放便暂停造成历史未写入的时序，未以产品改动规避测试。
