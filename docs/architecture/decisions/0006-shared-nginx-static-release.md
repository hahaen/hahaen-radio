# ADR-0006：复用共享 Nginx 发布静态前端

## 背景与决定

2026-10-18 用户要求复用服务器已有 Nginx，取消独立 Radio Web 容器。本决定修订 ADR-0001 的生产 Web 入口：常驻应用容器只有 `radio-api`、`radio-jobs`，共享 Nginx 服务 `/radio/` 并将 API 子路径代理到后端。

## 发布与约束

Jenkins 分为前端、API、任务三个独立任务，仅构建所需镜像并验收固定摘要；后端有迁移时才构建迁移工具。Web 镜像中的 Caddy 只用于隔离验收；正式发布从未启动的临时提取容器取得公开静态文件，验证内容摘要后原子切换目录。共享网关只读挂载项目发布根和维护标记，不读取私有配置。

各组件版本由 component-release.json 和 format 2 持久状态分别记录，结构版本独立保存。同结构回退重新验证保留产物并切换目录，失败继续维护；数据库 TLS、指纹、本机锁、数据库发布锁及备份/迁移保护保持。共享网关的其它路由和证书仍由原部署管理。

## 验证状态与调整条件

静态切换、回退、篡改拒绝和失败清理已有文件系统回归；共享网关模板通过原生语法、维护开关和页面/API 503 检查，其他站点返回 200。完整上线状态见[正式部署记录](../../iterations/2026-10-17-production-deployment/README.md)。

需要多主机、CDN 或动态前端运行时，再单独评估产物分发与版本切换，不通过增加副本绕过目标锁。
