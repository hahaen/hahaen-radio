# 磨砂界面、夜航动效与沉浸收听

日期：2026-10-21。

## 需求与实际变更

用户认为点击搜索后的搜索框与弹窗仍不好看，要求继续改善。本轮保留电影感夜航方向，调整搜索整体结构；用户随后明确要求磨砂弹窗、首次入场和电台选中/播放闪动，随后补充常驻控件磨砂、地图操作收起浮层、光点突出和沉浸页重做。

- 顶栏只保留固定位置的搜索按钮；输入、清除、关闭、筛选和结果进入同一个 460px 桌面浮层，手机按可用宽度缩放。输入字号 16px，使用灰绿焦点边界，移除双层橙圈和重复可见标题。
- 输入与关闭保留在顶部，结果区域独立滚动；结果数量和紧凑筛选并排，筛选内容展开在下方。错误状态另用纵向排列，避免重试与筛选重叠。
- 结果以 15px 站名、第二行地点与流派、右侧播放符号组织；选中电台使用细珊瑚色标记，去掉类别点光晕，减少分隔线。
- 保留即时筛选、清除、分页、空状态、错误重试、资源署名、点击外部关闭和焦点返回；修正输入框移入浮层后，中文输入组合期间 Escape 不应关闭面板的处理。

- 所有浮层统一为 70% 墨绿底、28px 模糊、125% 饱和度、轻微高光与 18% 暖白边框；不支持背景模糊时恢复高不透明度。搜索聚焦不使用橙红边框，改为灰绿边界。
- 常驻视图切换、搜索/收藏/设置、地图工具和底部流派容器使用较轻的 42% 墨绿底、14px 模糊和 120% 饱和度；播放主按钮保留珊瑚实心。
- 地图开始拖动、缩放或键盘导航时统一收起工具浮层，手动地图信息与底部筛选按交互版本关闭；播放和筛选值保持原状，加载/错误必要信息保留。
- 普通电台核心增至 6.4px 基准，收紧外晕并放松密集区域抑制；暗化陆地和装饰点，保留每台标记与国家级空心精度；选中环半径桌面 40px、手机 28px。
- 沉浸页改为桌面双栏、手机居中、横屏紧凑构图；重绘唱片、潮汐和山峦，将播放和音量集中在底部磨砂托盘，沿用同一控制器。
- 首次欢迎页采用有限的地球淡入与轻微靠近、文案和按钮分批入场；不增加启动等待，减少动态效果与省电时关闭。
- 选中点采用暖白细环、48 根短刻度、暖色光核、珊瑚小点和投影说明；播放时光核呼吸，其他电台以不同相位轻微闪动。暂停、减少动态效果、省电和页面隐藏时停止持续绘制，装饰不作为真实声谱。

## Review 与验证

本次 Review 仅覆盖 App 的搜索结构与样式、筛选紧凑变体、相关浏览器用例和文档。审查确认搜索按钮被外部点击监听排除，避免关闭后又打开；组合输入的 Escape 在浮层内拦截，普通 Escape 仍关闭并返回焦点。检查固定顶部与滚动容器、小屏安全区、可访问名称和强制颜色模式焦点。新增动效审查核对播放状态从 App 传入引擎、暂停与省电停绘、标记完整性、投影说明不逐帧触发 React、资源统一释放以及首屏有限动画。补充审查覆盖常驻控件材质与命中区域、地图交互回调的生命周期、手动与必要信息的区别，以及沉浸页五种视口和同一音频会话。当前无未解决审查问题。

回归发现底部筛选复用了旧搜索标题样式，关闭按钮随内容滚出；已拆分 `searchHeading` 与原有 `directoryHeading`。结果行重新分组后补回显式文字空白，使英语可访问名称与可见文本一致。首批回归中止，修正并复审后重新执行完整适用批次。地图关闭用例首次在手机将滚轮落在弹窗内部，正确保持了弹窗；用例改为从暴露的画布操作后四组通过。筛选/收藏组合用例早先并行手机运行超时，单工作进程复验四组通过。
