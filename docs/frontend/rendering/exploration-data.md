# 探索目录、缓存与候选集合

## 精简场景接口

新增 `GET /api/v1/catalog/scene` 和 `GET /api/v1/catalog/scene/:version/chunks/:index`，沿用目录 UUID、每片最多 1,000 条和既有屏蔽处理。普通目录与电台详情接口保持兼容，更新时先 API 后 Web，无新增迁移。

- 格式号为 1；条目使用 13 项定序数组表示 ID、名称、国家、地区、城市、附近地名、纬度、经度、位置精度、流派、语言、码率、可用性。
- MySQL 直接投影场景字段，并通过关联约束只读取已发布版本；不为分片重复统计总数或读取完整播放详情。
- 不携带标签全文、主页、播放地址或时间详情。浏览器按电台 ID 获取完整详情和线路，不用空值冒充已确认缺失的字段。
- `restrictionsRevision` 是屏蔽 ID 集合排序后的 SHA-256。分片在查询前固定屏蔽集合，摘要与实际套用的规则对应，不因其他请求刷新缓存而错配。
- 场景接收不超过 200,000 条、200 片，与目录注册表和 API 范围一致；未知坐标仍保留在完整候选集合。

## 完整性与本地缓存

原始位置字段与地图展示位置分离：有原始坐标的电台保留原位置，缺坐标但有受支持国家代码的电台使用国家陆地内的固定分散点，以空心点标记“国家级位置”。列表仍按国家或附近位置分组，但图形将每个成员展开为独立标记，点击点直接选台；定位和选中光环指向该台的同一展示点。国家列表保留分页，不参与同城螺旋展开。同位置展开不限制成员数量，视觉错开的最大范围有界。地图数量同时报告可展示总数与国家级数量。无法确定展示位置的电台继续保留在完整候选集合。已有 API、目录快照和缓存无需转换，详见[地理资源](../../data/offline-geography.md)与[验证记录](../../iterations/2026-10-18-station-map-density/README.md)。

前端最多并发读取 4 个分片，每次请求执行统一超时和取消，整次加载有 90 秒期限。检查目录版本、规则摘要、分片序号和数量、唯一 ID 及总数；不向场景暴露半份目录。遇到版本或规则改变，最多重新获取一次清单，不无限重试。

使用 idb 访问专用 IndexedDB `haen-catalog`，只保留最近两个完整快照，按目录版本和规则摘要查找。每次进入仍先请求当前清单，命中完整缓存才复用。禁止、损坏、配额耗尽或打开阻塞时，在有界等待后继续网络加载，基本列表与播放独立可用。

网络失败时可使用最后完整快照并明确提示可能过时；实际播放仍获取当前详情，不能让旧缓存绕过屏蔽或假装音源仍可用。显式取消不会转换成成功的旧缓存结果。

## 一致候选范围

完整目录到达后，在同一集合内执行列表、随机探索、流派视图和地点图形筛选；同维多选取并集，维度之间取交集，空选择为零结果。搜索按词匹配名称、地区、城市、附近地名和中英文国家名，忽略大小写及拉丁重音。搜索“中国”“China”或“CN”时包含台湾（`TW`）电台，“台湾”“Taiwan”和“TW”仍用于单独检索；前后端复用共享搜索词规则，保留上游地区代码与地理数据。没有坐标的电台可以通过列表、流派与随机探索收听。

仅在场景目录不可用时保留原服务端分页搜索与随机探索。更换目录或筛选不会停止当前音频；若当前台不在新候选范围内，界面明确说明并保留播放。

## 语言归一化与立体探索

语言选项与客户端候选匹配复用共享规则，合并常用名称、ISO 别名与明确拼写变体，过滤错误标签。完整目录到达后按每台电台去重统计语言；列表故障回退时不把合并旧清单计数冒充精确唯一数量。服务端语言过滤同时接受旧快照中的常见别名。

流派画面改为有界取样的立体点簇，DOM 名称按钮承担选择与键盘入口；缺少 WebGL 时退回原位按钮网格。同城点展开后仅在画面上分离至多 48 个标记，实际位置字段保持原样，全部成员可通过列表分页访问。省电选项降低画面细节，不缩减可搜索电台。双端布局、沉浸与本轮验证见[体验记录](../../iterations/2026-10-18-listening-refresh/README.md)。
