# 固定中国时间与日期

## 需求与实际变更

- 页面时钟始终使用中国时间（`Asia/Shanghai`、UTC+8），展示 24 小时时间、日期和星期，不再依赖电台时区。
- 桌面保留描边数字，手机使用实心字形，保留欢迎页及横屏显示；去掉时钟下方的电台地址。
- 日期按中英文界面格式化，按中国时区跨日；每分钟刷新，页面恢复可见或重新聚焦时校准，卸载时清理计时器与监听器。
- 电台详情中的位置及有来源的当地时间保留，不涉及 API、目录或数据库变更。

## 农历补充（2026-10-18）

- 在公历下方增加农历月日，中文采用“农历九月初九”“农历闰六月初一”等写法；英文明确标示农历月份、日期和闰月。
- 使用浏览器内置 `Intl.DateTimeFormat` 的 Chinese calendar，无新增依赖或在线日历请求。公历和农历共用中国时区与分钟刷新，支持中国午夜同步换日。
- 不支持 Chinese calendar 的运行时继续显示中国时间和公历，不把回退的公历误标为农历。
- 手机日期两行靠右排列，低高度横屏适当缩小时钟，避免新增农历挤压地图提示。
- 字体生成器纳入农历月日文字，补齐“农、闰、初、冬、腊、廿”等本地中文字形；运行时继续只请求本站字体。
- 验证样例根据[香港天文台 2026 历表](https://www.hko.gov.hk/en/gts/time/calendar/text/files/T2026e.txt)及[2025 年历](https://www.hko.gov.hk/en/gts/astron2025/files/HKO_almanac_2025.pdf)核对，覆盖九月初九/初十、正月初一、闰六月初一、九月三十及腊月廿九。
