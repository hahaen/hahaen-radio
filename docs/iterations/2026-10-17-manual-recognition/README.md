# 默认关闭的手动识曲

## 需求与实现

交付独立识曲适配、状态、手动入口、限流、取消及额度保护。没有用户提供的有效令牌和明确额度时保持关闭，真实服务待单独接入；基础播放与元数据不依赖识曲。

共享契约、能力与站点绑定 POST、HTTPS 有界采样、固定供应商文件上传、独占持久化预扣、初始化命令和前端片段结果已接入。成功结果沿用歌曲收藏、外部搜索及显式歌词查询；不覆盖电台元数据，不把识别时间当直播进度。

## 验证状态

Review 仅覆盖本次新增识曲配置、契约、配额与远程调用、API 生命周期、手动界面、测试和文档。核对了单实例独占、重启保留、先持久化后上传、不确定调用保守计数、共享任务取消、站点和线路身份、跨域与旧结果、中英和双端布局。已修正供应商附加元数据与严格歌曲字段的兼容、预扣期间取消的说明、接口超时设置的验证适配，以及正常关闭时过晚取消请求可能遗留额度锁的问题。

格式、Lint、严格类型、151 项普通测试及前后端生产构建通过。六项 MySQL 集成用例本次不适用，没有表结构或 MySQL 查询变化。编译后的 API 和额度初始化命令已实际运行于隔离假配置：临时环境文件已加载、进程变量优先、能力关闭时无额度文件创建、重复初始化拒绝、已配置但无目录时持有/释放额度锁、没有供应商请求及数据库写入。真实目录和付费识曲不是本轮测试素材。

20 项识曲浏览器检查在 Chromium、Firefox、WebKit 与手机 Chromium 通过，覆盖中英未启用、显式点击、片段来源、收藏与搜索、不自动查歌词、未匹配/繁忙/冷却/失败/额度耗尽、关闭/换台旧响应与原生暂停取消、HTTP 失败后继续播放。实际媒体使用项目合成音，识曲响应为可控样例；没有用电台标题冒充识曲，没有向供应商发送真实请求，也没有真实识曲结果或实际扣费证明。

补充真实本地 HTTP 连接中断与正常关闭检查：最后一个调用者离开或 API 开始关闭后，采样信号中止，额度未预扣且没有上传；正常关闭释放独占锁，重复清理不会删除新进程的锁。全量浏览器回归 209 项通过、3 项桌面触摸合成不适用。Vite 的大分块提示保留，完整兼容和长期稳定性属于阶段 8。同步没有远端变更或冲突，54 个任务文件内容与权限完整恢复；复审后完整检查、151 项普通测试、生产构建与编译入口再次通过，52 项曲目/识曲浏览器复验通过。
