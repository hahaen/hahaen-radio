# 手动片段识曲

当前状态：2026-10-18 按用户要求移除主界面和沉浸界面的曲目与歌词、手动识曲入口。下文保留既有模块与接口行为说明；后台能力与已有本地收藏数据继续兼容，不能据此认为页面仍有这些入口。见[页面调整](../../iterations/2026-10-18-celestial-layout/README.md)。

沿用夜航曲目面板、衬线小标题、低对比边界与 44px 控件，中英双语一致。识曲区域与电台元数据分开显示，不用电台标题冒充识别结果。

用户打开曲目面板后仅检查能力；只有实际播放当前电台、有效线路与服务可用时，点击“识别当前片段”才发送 POST。界面明确告知片段会交给 AudD，不使用麦克风；未启用、不可用、等待、未匹配、繁忙、冷却、失败及额度耗尽分别说明。

等待值只用于按钮倒计时，不触发再次识别。双击不会创建重复请求，关闭面板、暂停与更换选择使旧请求失效；迟到的旧站结果不能填入新站。识曲不能自动启动播放、换台或覆盖原有电台曲目信息。

成功结果显示独立来源及完成时间，允许收藏、取消、外部搜索和显式查询歌词。沿用已有歌曲清单与文件迁移格式，不新增账号或云端收藏。结果来自短片段，直播进度仍未知；歌词仅允许原有的手动校时，不使用供应商 timecode 推测当前位置。

接口与额度以[识曲 API](../../backend/api/recognition.md)和[运维额度](../../operations/recognition-quota.md)为准。真实服务尚待独立验收；自动化使用明确的可控响应与自制音源。
