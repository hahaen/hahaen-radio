## 原生浏览器环境修复

Firefox 最小受控 MP3 复现返回 `MEDIA_ERR_DECODE / OnMediaSinkAudioError`，系统解码库已存在；为构建身份建立隔离 PulseAudio null sink 后，同一复现转为 `playing`，原先超时的中文可访问性用例在 22.3 秒通过。该修复仅作用于构建节点，不改变产品音频代码或生产浏览器行为。既有浏览器回归用例覆盖此实际故障，无需增加浅层模拟测试；临时探针已清理。

Firefox 的独立 WebGL 2 对照中，headless 返回不可用，Xvfb headed 返回可用；WebKit 两种模式均可用。CI 的普通回归与资源检查仅将 Firefox 改为虚拟屏幕模式，保留实际图形断言，不将设备降级分支冒充图形验收。

Linux WebKit 的实际媒体音量存在约 `5e-6` 的后端舍入差异，两处对应断言改用小于 `5e-5` 的数值容差；静音、暂停、错误与 CORS 状态仍严格核对，持久化偏好及滑块值仍检查精确值。产品音量逻辑未修改。
