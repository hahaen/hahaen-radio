# 后台任务调度

## 运行组织

API 与后台任务使用同一服务端工程和镜像，通过不同入口启动。基线运行一个任务进程，使用 node-cron 调度。

任务时间表达式显式配置时区，持久记录时间统一使用 UTC。任务具体周期、批次大小和并发数在实现后按数据量与运行耗时确定。

## 执行约定

- 任务可重复执行，按稳定标识去重或执行幂等更新。
- 同一任务避免重叠执行，不能仅依赖进程内布尔值。
- 通过 SQLite 原子更新或短事务取得任务租约，记录持有者、到期时间和续租状态。
- 长任务分批处理，每批短事务提交，支持从安全检查点恢复。
- 外部请求设置并发、超时、重试次数和整体运行时限。
- 任务失败保留错误摘要与进度，不无限立即重试。

租约失效后接管需要防止旧进程继续写入，采用运行令牌等校验方法；具体表结构随任务实现设计。

## 与发布的关系

数据库迁移前停止任务并等待当前写入结束。恢复后只启动一个任务进程，确认不会重复调度。

记录每次运行的标识、起止时间、状态、处理数量和错误摘要。跨重启的任务状态保存在数据库中，内存缓存不承担唯一执行记录。
