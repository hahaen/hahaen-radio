# 个人收听工具

## 本阶段构图

沿用夜航的深海 `#0B151B`、面板 `#15252D`、暖白 `#E8E9E1`、青灰 `#83AAA3` 与琥珀 `#D8AD6B`；品牌与短标题衬线、操作无衬线、时间等宽。地球继续作为主要视觉重心，搜索下方展开多维筛选，收藏和历史放在可关闭的收听面板内，不新增仪表式卡片。

```text
电脑：品牌             查找 / 我的收听 / 语言
      当前台           地球或流派
      搜索 + 筛选 + 电台列表
      固定播放器

手机：品牌与触屏入口
      地球 → 当前台 → 搜索与可折叠筛选
      我的收听：适配窄屏的原生模态面板，可正常滚动
      固定播放器，内容保留实际占位
```

正文、筛选与面板内容左对齐；移动端仍以地球和当前台为中心组织首屏。操作使用真实状态、明确文案和至少 44px 触屏目标。此方案继承现有构图，不改变颜色或字体方向。

## 数据与交互约束

- 收藏、历史与恢复项仅在浏览器本地保存，不保存播放地址或服务凭据。电台 ID 稳定，收藏的名称和国家仅为目录不可用时的快照。
- 不同收藏和历史使用独立键，跨标签页读取实际最新键值；不通过覆盖整份列表保存单个收藏动作。
- 最近收听去重并最多保留 100 台，只在实际进入播放后记录；刷新与分享打开只选择电台，等待用户播放。
- 分享电台优先于上次成功收听项；详情读取失败显示明确状态，允许继续探索，不清空已保存筛选。
- 筛选、场景、列表和随机选台共用候选范围；同维并集、维度交集，空选择为零结果。当前台不满足筛选时继续播放。
- 下线、屏蔽和缺失收藏保留记录；只有当前成功查询确认不可用的条目才可进入显式清理确认，网络错误不能推断下线。
- 文件迁移仅包含版本化收藏；先检查 2MiB 字节大小再解析，严格校验并去重合并，既有收藏优先。较大的导出拆成各自可导入的分卷，不执行文件内容。
- 存储不可用、损坏或未知版本时保留可用的会话数据并告知保存限制，不冒充已经持久化。
