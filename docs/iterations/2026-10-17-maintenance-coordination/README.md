# 数据库维护协调

## 需求与实现

补齐备份与迁移之间的数据库级互斥，避免多个进程或运维节点同时执行不兼容操作。新增 MySQL 会话维护锁、实际基线检查、每秒所有权检查和失锁取消，按目标库生成不超过 64 字符的固定锁名。备份保留本地目录锁，并增加数据库锁；迁移仍只调用固定版本 Drizzle Kit，不新增迁移机制。

迁移入口要求私有 `MIGRATION_WRITES_STOPPED=true`，表示操作者已停止所有写入方；该变量不自动停止服务。迁移子进程中断后等待 close，TERM 无效时 2 秒后 KILL；原始工具输出不进入普通日志。确认变量、额外连接预算、协作锁和维护窗口的边界已写入运维文档。

## Review 与验证

仅复审本轮维护模块、迁移入口、备份接入、验收入口、空值模板和关联文档。检查锁作用域、所有权、取消、错误输出、连接清理、旧入口兼容和测试会话归属；修正 finally 中错误抛出可能覆盖原始失败的问题，并补齐测试失败时的受控进程清理。复审后执行验证。

完整工程检查通过：格式、Lint、TypeScript、176 项普通测试与前后端生产构建；普通命令按设计跳过 10 项 MySQL 用例。4 项新增普通测试覆盖锁名隔离、缺少停写确认、客户端异常和忽略 TERM 的子进程真实退出。

专用真实 MySQL 8.0.46 验收通过：持锁时编译迁移入口和备份入口均拒绝，未产生迁移表或多余备份；释放后编译迁移入口完成空库初始化与重复执行。主动断开本轮拥有的锁会话后，受控子进程在 2065ms 内被取消且确认 PID 已不存在，快于其 15 秒自身期限。随后完成 11 表、3 迁移的备份副本恢复、约束/Unicode/额度与编译 API 就绪检查；测试库与 API 已清理。结构化结果见[证据](results.json)。

本机数据库链路沿用已核对主机密钥校验且仅监听 loopback 的 SSH 隧道。未配置或宣称已验收数据库可信 CA，跨主机和正式连接仍要求可信 TLS。

同步 upstream 无新增提交，19 个任务文件的内容、权限与空暂存状态完整恢复。同步后仅复审本轮差异，再次通过完整工程检查（176 项普通测试、10 项数据库用例按设计跳过）及专用 MySQL 入口；本轮锁会话中断后的子进程退出耗时 2057ms，测试库和进程再次确认清理。

## 交付与未完成项

本轮没有新增迁移；SQL 写入仅限本轮新建隔离测试库，开发和正式库未改动。没有执行远程发布、创建 Jenkins 任务或上传镜像。本机 Docker 实测按用户要求留到部署环境。

会话锁只协调遵循入口的操作，失锁取消不能回滚已提交 DDL，也不能证明断网或父进程强杀后所有服务端语句已停止。完整发布仍需外层 Jenkins 互斥和维护窗口，继续补齐每日调度、独立备份副本、正式恢复手册及日志保留；完整目标保持进行中。
