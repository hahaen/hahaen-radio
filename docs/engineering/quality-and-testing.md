# 代码质量与测试

## 检查工具

使用 ESLint、typescript-eslint、Prettier 和 TypeScript strict。优先通过明确类型与接口消除错误，避免用宽泛类型断言绕过契约。

## 测试分层

| 层面 | 工具 | 重点 |
| --- | --- | --- |
| 纯逻辑 | Vitest | 数据转换、坐标、状态转换和错误边界 |
| React 组件 | React Testing Library、Vitest | 用户可观察行为、焦点和状态反馈 |
| API | Fastify inject | 契约、错误码、分页和参数边界 |
| 数据库 | 临时 SQLite | 查询、约束、事务和迁移升级 |
| 浏览器 | Playwright | 关键路径、路由、兼容性和资源错误 |
| 真实设备 | 手动验收 | 音频策略、后台行为、触摸和性能 |

测试使用独立数据和可控音源，避免依赖不稳定外部服务作为唯一判断。验证实际服务的结果单独记录，不与本地模拟结果混为一谈。

## 浏览器与媒体

自动化覆盖 Chromium、Firefox 和 WebKit。明确测试是在模拟媒体、测试音源还是真实直播下执行。UI 显示“播放中”不能单独证明音频已正常输出。

图形验证包括渲染非空、尺寸变化、交互、上下文失败和资源清理；视觉比较固定视口和状态。性能预算在真实场景建立后测量。

## CI 验收

Jenkins 按顺序完成冻结依赖安装、格式检查、Lint、类型检查、必要测试、生产构建和镜像验证。镜像验证应包含服务启动与 SQLite 原生驱动加载。

测试失败阻止部署。覆盖率使用 Vitest V8，关注重要分支和风险，不用覆盖率数字替代行为验证。
