# 确定提交与镜像产物链

## 需求与实现

为后续目标发布提供可追溯产物，接通根 Jenkinsfile 的确定提交、冻结检查、浏览器回归、三类同提交镜像构建、隔离容器基础验收和人工分发。默认不分发，分发要求人工 Cause、已配置的审批人与确认；没有增加自动触发器、创建远端任务或执行发布。

工具记录 Git 提交、原生平台、镜像 ID、迁移 SQL 文件摘要与验收 run。发布阶段核对远端 manifest 的 config digest，支持从 OCI index 选出已验收的平台子 manifest；只有全部通过才生成不可变 release.json。凭据通过私有 Docker 配置，普通输出只给固定事件，归档只列三个明确的非敏感元数据文件。

镜像检查实际入口已实现：独立内部网络、临时 MySQL 8.0.46、内存数据挂载、固定测试目录、迁移重复执行/历史哈希/表选项、API/任务/Web/静态资源、优雅退出和归属检查后的清理。原生客户端和应用凭据均由私有文件运行时注入，不进入参数或镜像层。这些是工具行为，不代表本机已经运行真实容器。

## Review 与本机验证

范围仅为本轮 Jenkinsfile、release 工具、模拟 CLI 与原生进程测试、Vitest 接入及相关文档。核对提交/平台/标签的连续性、凭据绑定、输出上限、取消、归档范围和资源归属。补齐干净检出的私有产物排除：工具只写当前 Git info/exclude 的固定产物路径，并拒绝已跟踪路径，测试使用项目实际共享忽略文件，避免本机配置掩盖问题。修正了把清理查询异常当作资源不存在的风险，加入删除后实际查询；在参数错误前清理独占 Jenkins 工作区，避免归档旧任务材料；补齐 OCI index 与远端内容不符拒绝。

7 项新增测试通过：输入与进程错误脱敏、生产 CLI 在模拟引擎下的完整产物链、缺验收/标签变化阻止分发、远端内容不符拒绝最终记录、清理失败拒绝签发通过记录且不删无关资源，以及原生超量输出时取消并确认子进程不存在、完整元数据独占发布且拒绝覆盖。临时 Git 仓库、模拟状态和凭据文件均清理，未连接 Docker socket、镜像仓库或实际数据库。

完整工程检查通过：格式、Lint、TypeScript、188 项普通测试与前后端构建；普通命令中的 10 项 MySQL 用例按设计跳过。本轮没有修改应用、Schema 或迁移，无需将模拟引擎结果解释成 MySQL 验收。结构化结果与输入摘要见[证据](results.json)。

同步 upstream 无新增提交，19 个任务文件的内容、权限和空暂存状态完整恢复。同步后复审并再次通过完整工程检查（188 项普通测试、10 项数据库用例在普通命令中按设计跳过）与文档检查。复审补充禁用 Jenkins 从阶段重启，防止跳过独立审批阶段，并记录权限和目标实例验收要求；该 DSL 行为仍待目标 Jenkins 实测，不将本机检查记作通过。补齐干净检出排除规则和严格镜像引用分隔校验后，再次通过完整检查及七项相关测试复验。

## 剩余交付与外部条件

本机按用户要求不执行 Docker。目标 Jenkins 仍须 Declarative Linter、实际 Git/凭据/Input 插件、审批解析、原生 Linux 镜像、MySQL 容器、镜像仓库认证与清理的实测；本机手工语义 Review 和模拟 CLI 不能替代。没有上传镜像，也没有配置或触发外部 Jenkins。

目标主机完整/前端/后端发布执行器、数据库/文件双层发布互斥、维护状态、迁移前备份/副本、更新顺序、回退与正式恢复手册继续实现，不将当前分发工具当作完整部署交付。普通日志保留、真实设备与其他既定验收仍在完整目标范围内。
