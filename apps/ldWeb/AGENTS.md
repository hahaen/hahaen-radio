# LINUX DO 微应用协作规范

适用于 `apps/ldWeb`。同时遵循[项目协作规范](../../AGENTS.md)和 [LINUX DO 官方指南](https://github.com/linux-do/mapp-developer-guide)。

## 纯前端边界

- 声屿 HAEN 的 LINUX DO 微应用只维护无后台版本。运行时只用包内资源、论坛 SDK 和经审核的第三方直播源。禁止依赖 `radio-api`、`radio-jobs`、MySQL、自建代理、云函数或其他自建后台。现有网页、原生应用与服务按各自规则独立维护。
- 版本准备时只读导出当前已发布的公开目录，核对目录版本、规则版本、分片数量和电台 ID。随 ZIP 打包经过字段白名单投影的 JSON 和地图。应用通过 `sdk.assets.readJson()` 加载，详情、搜索、筛选、同城和随机选台用本地数据。收藏用 `sdk.localStorage` 存在当前浏览器。
- 快照禁止包含流地址、官网 URL、账号、会话、私有收藏、诊断和凭据。快照更新通过重新导出和发版完成。

## 直播与验收

- 目录与可播名单独立。音频由用户点击播放后经官方 SDK 读取，经获准的 Web Audio 在当前页面输出。禁止打开新标签页、跳转站点、隐藏外链或将跳转作为失败兜底。直播音频不随包分发。
- 只接入运营方允许第三方使用且符合平台审核要求的固定 HTTPS 音源。候选只进入独立沙箱试播包。正式可播名单仅纳入已在 LINUX DO 沙箱的桌面和手机实际听到声音，并确认停止、切台和页面留驻的电台。获取字节、本机出声或模拟 SDK 测试均独立记录。
- 使用固定版本的官方 SDK 生成运行 ZIP。应用 ID 只由用户填写在 Git 忽略的 `.env.local`，禁止提交或输出其中的配置。测试 ID 生成的 ZIP 仅供本地验证。正式上架由用户操作。

## 按影响范围交付

- 只有影响微应用运行或构建的代码、目录、音源清单、依赖和资源发生变化，才更新微应用 ZIP。微应用单独改动使用 `pnpm --filter @haen/ld-web` 验证和构建。共享地图或工具变更按实际依赖决定涉及的产物。
- 沙箱验证、正式打包及其他应用的发布分别记录，不能互相替代。缺应用 ID、许可音源或真实设备证据时，完成可独立验证的工作，并明确待验证项。
