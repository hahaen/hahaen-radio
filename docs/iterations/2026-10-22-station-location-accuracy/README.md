# 电台定位准确性修正

日期：2026-10-22。

## 需求与实际变更

地球上的电台位置应忠实表达已有地理证据。此前缺少坐标的电台按 ID 在国家或省/州范围内取样，虽然位于所属区域，却会产生看似具体台址的虚假分布；相同地理证据仅因 ID 不同便能相距上千公里。

- 删除逐台随机取样。通过范围校验的来源经纬度逐台原样定位；没有可用坐标的成员按已知省/州或国家汇总为一个固定空心圆。分组锚点取安全内陆三角形的重心，只代表区域，不代表台址。筛选、排序、展开和省电模式不移动落点。
- 全部成员仍可搜索、随机收听或从分组分页选择；绘图标记数与电台总数分开，悬停区域分组显示成员数。选中组内任意成员均定位到同一锚点。保留国家级列表已精简的可见文案。
- 光点与选中环统一使用 1.001 球面半径，减小离开球面引起的视差；珊瑚状态点居中。区域选择显示空心环与“地区分组”，不显示精确位置光核；电台详情用“来源坐标”区分目录信息与官方核验。
- 宽度 360px 及以下或高度 500px 及以下收起重复的浮动台名，保留选中环、播放器与地图精度，避免和地图信息重叠。贴地标记按朝向剔除背面，完整显示正面的空心圆。
- 国家内陆数据从每国最多 16 个三角形精简为一个，生成脚本和摘要同步更新。使用固定 SHA-256 的原始地理文件重新生成，250 个国家保留的第一个三角形与旧数据逐项一致；国家标签和覆盖网格不变。
- API、数据库、目录缓存和后台同步均未改变；未写入生产数据，没有添加外部在线地理编码请求或新增依赖。

## 数据边界

对公共目录一次最多 1,000 条中国电台记录的只读抽查中，980 条缺少经纬度；部分已有坐标明显与国家冲突。这是有上限的样本，不代表全目录比例。范围校验可以拒绝明显错误，但不能证明落在同一国家内的来源坐标就是电台真实地址。缺失、冲突或只有省/州信息的记录保持低精度，不根据台名、语言或 IP 猜城市。

技术核对：[Radio Browser 坐标字段](https://docs.radio-browser.info/#station)、[Globe.GL 球面及屏幕坐标转换](https://globe.gl/#utility)。实现保留现有 Three.js 引擎和本地地理数据。

## Review 与验证

Review 范围：位置证据与分组、全部成员索引、GPU 半径与选中显示、双语文案、地理生成脚本、相关测试及文档。修正了直接使用国家标签可能落在海上的问题；改用安全内陆重心。调整内陆资源体积，保持既有入口预算。未发现需改变 API 或数据库的问题。

- 回归先复现“相同地理证据因 ID 不同而产生不同位置”和“缺坐标电台逐台伪造散点”两项失败，再验证修复。
- 图形和详情单元测试 79 项通过，包含 250 个国家与 4,584 个省/州的范围检查、原始坐标保留、同证据固定锚点和全部成员保留。
- Chromium 桌面与手机模拟的 50 项浏览器检查通过；Firefox、WebKit 的坐标/分组检查 14 项通过；贴地标记正面显示和背面遮挡在四种浏览器配置中各 1 项通过，共 68 个浏览器用例。窄屏与低高度浮动台名收起后，相关 8 项布局检查再次通过。
- GPU 缓冲坐标误差小于 0.00002°；另检查光点半径为 1.001。确切点展开不位移、区域成员分页、双语、播放居中、缓存、减少动态效果、省电和 30,000 个合成坐标的显示均通过。正背面测试比较实际投影区域的解码像素，避免截图编码及无关海岸线的低幅栅格噪声影响判断。
- 前端 TypeScript、变更代码 ESLint/Prettier、生产构建、静态资源预算、文档链接及 `git diff --check` 通过。构建仍有既有的大分包提示，未提高预算上限。
- 两个远端同步后均无新增提交；逐文件摘要确认任务内容完整，复审后重跑位置相关 35 项单元测试与文档检查通过。
- 最终浏览器验证使用独立 Vite 测试端口、合成目录与可控音源；已有开发服务保持运行。测试配置和运行产物保留在 Git 排除的 `.local/`，不提交原始公共目录下载或运行日志。
