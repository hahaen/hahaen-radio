# 真实手机验收

移动视口自动化与真实手机分别记录。每次写明提交、服务模式、设备型号、系统、浏览器实际版本、视口和网络路径；开发服务通过 USB 回环访问的结果不能代替公开 HTTPS 部署或移动网络验收。

## 准备与证据

1. 使用手机已授权的 USB 调试与本机 Android SDK 工具，确认设备状态为 device。序列号、配对标识、已有标签页及原始系统转储只保存在被 Git 排除的私有目录，不写入报告。
2. 核对私有配置加载、开发库、目录数量及 API 启动状态，启动项目专用服务。数据库迁移与手机验收分别处理；缺少新表或维护权限时明确标记受影响接口，不把它归因于手机。
3. 为项目打开独立 Chrome 标签页。只给本轮需要的端口建立 USB 回环/调试转发，先保存既有映射；结束时只删除本轮建立的映射，不清理用户浏览器数据或其他标签页。
4. 记录浏览器报告的视口、DPR、触摸点、WebGL 和安全上下文；保存仅包含项目页面的截图。系统通知、键盘建议、账号和其他应用画面不进入公开材料。

Android 远程调试与端口转发方法见 [Chrome 官方说明](https://developer.chrome.com/docs/devtools/remote-debugging/)。使用实际设备上的 CDP 触摸事件时应如实注明，不能写成人工手指操作；软键盘会改变可见视口，坐标不匹配时先修正调试操作，不能据此断言产品有缺陷。

## 检查清单

| 范围 | 操作与观察 |
| --- | --- |
| 初次进入 | 无用户手势不自动出声；地球与列表均加载；真实目录与可用候选数量分别记录 |
| 触摸 | 单指拖动、双指缩放、地点或列表选台、地球/流派切换；页面不被错误拖走，切换视图持续播放 |
| 搜索与布局 | 软键盘输入和提交、无结果恢复、面板打开关闭；双语、竖横屏和窄视口无明显遮挡或横向溢出 |
| 播放 | 显式触摸开始、暂停恢复、换台；记录音源格式、实际线路与媒体时间推进；固定后失败不能无限跳台 |
| 本地工具 | 收藏、最近收听、刷新后恢复但不自动播放、设置和沉浸退出；导入导出另验实际系统文件选择器 |
| 系统媒体 | 确认当前媒体会话属于本项目，再通过系统播放/暂停控制；不要把 JS 手动调用注册回调算作真实系统控制 |
| 后台与锁屏 | 断开调试连接，记录桌面/息屏状态、观察时长、用户听音反馈和返回后的状态；持续计时不等于实际扬声器输出 |
| 中断 | 区分媒体按键暂停、真实来电/其他应用音频焦点中断、断网及恢复；各项独立记录，不相互代替 |
| 性能与辅助技术 | 真实帧率、持续运行、TalkBack/VoiceOver、系统字体和减少动态效果分别验收，不能从 WebGL 初始化成功推断通过 |

播放状态、解码与实际声音是三类证据。听音需由设备旁的人确认，不能由 HTMLAudioElement.currentTime、系统 PLAYING 或截图单独推断。后台结果受浏览器、系统省电和网络策略影响，有限观察不外推为全天稳定。

iOS 使用真实 Safari 单独执行同一清单。WebKit 自动化、Android 成功、已配对但未连接的设备，都不能替代 iOS 结果。
