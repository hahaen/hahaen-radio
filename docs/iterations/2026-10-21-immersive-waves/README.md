# 沉浸环境声浪动效

日期：2026-10-21。

## 需求与实际变更

用户希望全屏沉浸环境增加类似声音波动的动态效果，并要求持续优化美观、避免单一、查看网上其他人的动态视觉。

- 流光使用五层交织光带、不同相位的起伏与游走高光；潮汐使用五圈逐渐扩散、淡出的涟漪，水面遮罩与地平线对齐；远山使用八层谐波轮廓与微光。三种形态的速度与幅度分别组织，沿用暖白、灰绿与墨绿。
- 声浪位于信息区上方；低高度横屏时调整位置与幅度，保留标题与播放器可读性。播放时起伏，暂停时动态振幅归零、潮汐涟漪退去，减少动态效果与省电模式沿用静态绘制。环境与动态层共同参与原有切换过渡。
- 只修改现有全屏着色器并新增播放状态 uniform；没有引入音频分析、流请求、图形资源或逐帧 React 状态。效果表达收听氛围，不作为真实声谱。

## Review 与验证

仅 Review 声浪着色器、播放状态连接和必要文档。检查播放/暂停初始化与后续更新、正向 smoothstep 边界、平方运算、固定循环、涟漪中心角度的零值保护、水面边界与像素宽度、现有停绘/销毁路径、窄屏与横屏位置。初版仅叠加统一光线，经视觉审查后拆成三种动态形态，并将涟漪移入水面范围。当前无未解决问题。

为避开共享工作区的其他地理实现，使用当前 HEAD 的干净源码副本，仅叠加本次着色器与回归测试修改，单独启动验证前端；原有开发服务保持运行。前端 TypeScript（应用与工具）、定向 ESLint、Prettier、`HAEN_WEB_BASE_PATH=/radio/` 生产构建和静态资源预算已通过。懒加载沉浸脚本为 10.40 kB（gzip 3.74 kB）。

浏览器回归 `immersive-art.spec.ts` 与 `immersive-scene.spec.ts` 共 12 项通过，覆盖 Chromium、Firefox、WebKit 与手机 Chromium 模拟：三个环境播放时画面变化、暂停后画面稳定；省电与减少动态效果停绘；上下文丢失/恢复、离开释放资源；单音频会话、返回播放、持久化、无 WebGL 降级和可访问性。增加逐场景暂停/继续检查后，将生命周期测试总时限调为 60 秒，以容纳软件渲染；未降低断言。

## 实际查看的网络示例

在 [Butterchurn 示例页](https://butterchurnviz.com/about)实际查看三组预览与悬停后的动态图像：光迹、局部光点和连续形变带来不同视觉层次。本轮将层次与形态变化转化为夜航配色中的光带、涟漪与谐波轮廓，未引入其预设或素材。[Soundshed](https://audio-viz.soundshed.com/)页面只查看其波形、圆形、粒子等模式列表，未将未播放的模式当作已验证动态画面。
