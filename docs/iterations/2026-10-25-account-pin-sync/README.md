# 固定电台开关随账号同步

## 需求与实际变更

电脑网页、手机网页和 Android App 的图钉开关在登录同一账号后共享。同步的是“固定当前电台”开关，不改变其他设备当前选中的电台，也不自动播放。

- 登录时以账号开关为准，尚未保存过该设置的账号默认关闭；游客状态独立留在本机，退出或会话过期后恢复游客开关，不把游客开关自动导入账号。
- 网页把开关纳入账号集合三方合并、400ms 自动上传、前台 30 秒拉取以及重新聚焦和网络恢复检查。离线修改保留在当前标签页的待同步快照，刷新后可恢复；关闭标签页仍可能丢失未上传修改，沿用现有离开提示。
- Android 把开关及待同步操作存入对应账号的 Room JSON 快照与队列，重启后可继续同步；界面、地球及原生播放恢复策略读取同一账号状态。游客继续读取原有 DataStore `pinned`，其他设置保持本机保存。
- 共享集合新增可选布尔字段 `pinned`，存入已有 JSON 列，无需结构迁移、数据修正 SQL 或新增配置。
- 新客户端 GET/POST `/api/v1/account/library` 使用 `pinned=1` 查询参数请求包含开关的响应。未携带参数的旧客户端仍收到原有三项集合；旧客户端保存时省略的开关由服务端保留，继续通过 `revision` 防止冲突覆盖。
- 发布兼容策略登记修改前的精确契约摘要，支持先 API、后网页的混合版本窗口，后台任务无需更新。
- Android versionCode 从 5 递增为 6，应用身份与签名连续性保持不变；双语隐私和账号说明同步更新。

## Android 图钉状态即时刷新修复（2026-10-25）

- 需求：Android 首页与沉浸页点击图钉后无选中反馈，其他端正常。
- 复现：真机 0.1.0 / versionCode 6 连续两次测试均出现点击前后仍为“固定电台”，进出设置后才显示“取消固定”。每次复现均恢复原开关，未修改账号身份或其他收听数据。
- 原因与变更：账号开关与本机偏好合并成普通值后，被未变化的 Navigation 3 页面保留；页面没有直接订阅合并结果。改为 `rememberUpdatedState` 暴露稳定可观察状态，让页面选中图标、文案和后续点击读取最新值，覆盖本机偏好及账号同步更新。Android 更新为 0.1.1 / versionCode 7，保留正式签名及应用 ID。
