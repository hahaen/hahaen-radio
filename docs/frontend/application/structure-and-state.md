# 应用结构与状态

## 应用组织

使用 React、TypeScript、Vite 和 React Router。应用入口统一安装路由、查询客户端和国际化 Provider。按职责拆分业务模块，共用 UI 组件放入独立目录。

## 状态归属

| 数据类型 | 管理位置 | 规则 |
| --- | --- | --- |
| 单个组件的临时交互 | React 局部状态 | 保持局部 |
| 跨组件界面状态 | Zustand | 通过选择器订阅需要的字段 |
| 后端数据与请求状态 | TanStack Query | 使用稳定 Query Key，显式失效 |
| 可分享、可导航状态 | URL | 解析和序列化统一封装 |
| 高频图形数据 | Three.js 引擎内部 | 不逐帧写入 React Store |
| 播放器内部状态 | 音频引擎 | 通过事件向 UI 报告 |

服务端数据不在 Zustand 中再维护一套独立缓存。URL 和本地偏好存在冲突时，由具体模块明确优先级。

## 请求与契约

统一 Fetch 封装负责请求路径、超时、AbortSignal、响应校验和错误转换。页面卸载和查询取消能够中止请求；只对适合重试的读请求配置有限重试。

前后端共享 `contracts` 中的 Zod Schema 和 DTO。TypeScript 类型不能代替外部数据的运行时校验。

## 样式与基础组件

CSS Modules 管理组件样式，CSS Variables 管理颜色、字体、间距、圆角和层级。Radix UI 提供基础交互，Lucide React 提供图标。

字体和必要资源随构建分发；字体选择时确认字体格式、中文覆盖和使用许可。常规动画使用 CSS，尊重减少动态效果的系统设置。

## 国际化与交互约定

文案统一进入 i18next 语言资源，组件不拼接依赖特定语言顺序的句子。弹层管理焦点，控件具有可访问名称；全局快捷键避开文本输入、组合输入和浏览器保留组合。
