## 播放状态动效（2026-10-22）

当前需求（2026-10-23）：播放时耳机图标保持固定，仅下方三根信号条跳动。按用户最新要求恢复此方案，取消整体旋转。

- 保留透明耳机海湾图标及其配色，耳机保持原位，下方三根珊瑚色信号条错落起伏；仅真实 `playing` 状态启动，暂停、缓冲、失败等状态恢复原始 PNG / ICO 声明。
- `usePlaybackFavicon` 通过 Canvas 预生成 12 张 32px PNG 帧，以 240ms 间隔更新现有图标链接，不新增依赖，不逐帧触发 React 渲染，不读取或改变音频链路。这是播放状态装饰，不代表真实音频频谱。
- 系统减少动态效果、站内省电模式恢复原图；后台标签页保留静态播放帧并停止计时器，返回前台后恢复。卸载、快速状态变化会清理监听器、计时器与异步加载回调。图标图片或 Canvas 不可用时保留原图，不影响播放。
- 原始图片通过 `applicationPath` 加载，沿用开发根路径与 `/radio/` 子路径。两个 `rel="icon"` 声明同步更新，避免浏览器在 PNG 和 ICO 间选择到未更新的图标。
- 浏览器原生标签栏是否呈现动态帧受浏览器自身支持和缓存策略影响；页面脚本的更新不能等同于所有浏览器原生标签栏已验收。手机主屏图标不在本次范围。

初版 Review 范围限定为播放图标 Hook、App 两处接入、新增浏览器用例及本节文档；核对状态驱动、资源清理、异步加载失效、图片失败回退、减少动态效果、后台节能及子路径，无未解决问题。同步后重新核对本次两行接入与独立 Hook，未发现冲突。
