# 生产客户端资源与持续运行验收

## 需求与变更

推进阶段8，补充生产产物预算、按需绘制、WebGL句柄释放和持续切台证据。新增独立性能入口、测试配置与仅注入隔离页面的原生探针；抽出既有30000条目录夹具供短程与持续测试复用，原规模断言保持不变。普通check增加静态预算，手动Jenkins流水线在镜像构建前增加固定600秒持续运行阶段。

本轮不修改产品界面、渲染器、音频或API；视觉沿用夜航，未增加运行依赖、环境凭据或数据迁移。测试数据只在测试上下文使用，没有数据库写入、Docker、镜像上传或实际部署。

## Review 与发现

Review范围为新增测试/脚本、共享夹具提取、两个工程入口与文档，核对弱引用计数、原生函数透传、句柄失效与删除的区别、真实计时、查询/媒体请求上限和测试服务隔离。

初次工具类型检查把浏览器专用模块引入NodeNext检查范围，已改为夹具使用的最小类型边界，产品模块仍由原有前端类型检查覆盖。首轮60秒检查的两个持续用例通过，四个资源用例因把Three.js内部帧缓冲也要求逐项删除而失败；原生报告及锁定依赖源码确认几何缓冲、程序与顶点数组已有显式删除，内部对象随后随上下文销毁失效。修正检查方式并保留两类原始计数，未修改产品释放代码或调高堆、节点与请求阈值。复审另核对既有目录五分钟刷新，按实际清单轮询单独计数，避免将合法刷新误判为异常请求；嵌套资源超限、必需地形缺失与软链接的隔离负例均被拒绝。当前首轮报告还证明返回地球的绘制检查已通过。

修正后六项60秒快速检查全部通过，新增请求总量核对的两项快速检查再次通过。同步upstream后24个任务文件的字节与权限完整恢复、暂存区保持为空，复审无未解决问题；随后默认600秒独立验收六项全部通过、零跳过且零重试，原规模回归四项和完整工程检查再次通过。冻结安装、219项普通测试、前后端构建和静态产物预算通过，10项MySQL用例按本轮范围跳过。最终证据、时间线、SHA256与工具版本见[结构化记录](results.json)。方法、上限与局限见[资源预算](../../engineering/resource-budgets.md)。

## 正式计时与资源结果

环境为macOS arm64、Node.js 24.9.0、pnpm 12.5.1；浏览器实际版本与视口记录在结构化文件。生产包只访问测试目录与音源，实际时钟取样，没有调用真实电台、识曲或数据库。

四项目各完成12次控制器创建/销毁、每次六轮地点数据替换，合计48次重建与288次替换。应用缓冲/程序/顶点数组有显式删除证据；内部纹理/帧缓冲保留独立失效计数，实际收到context lost后所有句柄归零、画布移除。生产页面静止和隐藏各1.5秒无新增绘制，返回地球后恢复；没有把开发模块夹具当作生产包销毁路径。
