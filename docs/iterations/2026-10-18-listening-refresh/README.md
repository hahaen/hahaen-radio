# 夜航收听体验与目录整理

## 需求与设计约束

整体改善电脑和手机收听体验、空间探索与目录质量，沿用深海底色、暖白文字、青灰与琥珀、现有字体角色和非对称构图，不改变技术栈与音频直连边界。

桌面保持左侧信息、中右地球及独立播放器，收紧间距和长标题；手机采用紧凑顶栏、随屏幕高度调整的地球、当前电台与底部控制。次要资料进入可展开详情，完整目录与搜索仍保留。

## 实际变更

- 流派使用按真实数量有界取样的 Three.js 立体点簇，支持鼠标拖动、滚轮与触屏。名称按钮保留键盘与无 WebGL 路径，暂停和视图切换不重启音频。
- 同城聚合点被点击后展开展示至多 48 个螺旋点，并保留完整分页列表。偏移仅用于分离重叠标记，不修改电台真实坐标，不将附近城市冒充台址。
- 手机提供当前筛选目录内的拨动选台，松手或键盘释放后选台，保持原播放意图。它不表示真实频率，也不表示地理距离顺序；每次展示当前项附近至多 51 个目录条目。
- 沉浸画面提供随流派变化、唱片、潮汐与山峦；画面是装饰，不冒充音频频谱。省电偏好降低像素比、地形点数与流派取样，停止唱片/潮汐动画。
- 画面偏好使用独立的本地 scene 记录与缺省值，保留旧版偏好记录的结构，使旧标签页仍可解析和保存音量/收藏；不改变导入导出格式。
- 前后端共享语言归一化规则，合并常见名称、ISO 别名与明确拼写变体，拒绝数字、网址和非语言标签。完整目录的语言匹配与语言选项同步归一化；服务端查询兼容旧快照别名。
- 同步入口合并有效语言代码与名称，并扩充明确音乐标签的流派归类。保留未知类别，不根据电台名称猜测流派，不伪造缺失地理位置。
