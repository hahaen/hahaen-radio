# 迁移状态与首次初始化保护

## 需求与实际变更

为目标发布提供实际 SQL 执行前的可检查状态：新增 `pnpm db:migrate status`，复用同一数据库维护锁、连接/TLS/版本基线与完整元数据可见性验证。查询不创建或修改库、表、迁移记录；只接受当前材料的精确历史前缀，并按最后已应用版本快照校验物理表集合。最新快照的表名须与当前 TypeScript Schema 一致。

正常迁移在执行前后均核对历史；无待升级项时返回 applied=0，不再调用 Kit。真正空库要求额外的 `MIGRATION_INITIALIZE_EMPTY=true`，所有执行仍要求既有停写声明。发现不匹配、未管理表或部分建表时拒绝，不自动重试、修改记录、重建库或推断恢复办法。唯一 DDL 执行器仍是固定版本 Drizzle Kit。

镜像隔离检查脚本同步为空库测试显式提供开关；该脚本本轮未在 Docker 中运行。新增变量模板保持空值，现有实际私有配置没有提交。

## Review 与验证

Review 只覆盖本轮迁移入口、状态/计划模块、测试扩展、镜像测试开关和相关文档，读取锁、连接、Schema、快照与权限解析作为必要上下文。重点核对权限不足时不能推断为空库、历史顺序/摘要/时间、每个历史前缀的表集合、同锁内执行、取消、连接释放及输出脱敏。复审补齐中间版本快照表集合校验，避免仅在最新版本检查而遗漏升级前已创建的新表；为重复执行补充本次 applied=0 的实际断言。未扩大到无关业务修改。

本机完整工程检查通过：格式、Lint、TypeScript、192 项普通测试及前后端生产构建。普通命令按设计跳过 10 项独立数据库用例；本轮另通过专用真实 MySQL 验收，而非将跳过记为通过。新增 4 项普通用例覆盖精确前缀、无效/超限历史、journal 顺序与修改已发布 SQL 的拒绝。

使用本机官方 MySQL 8.0.46 客户端及已验证的回环 SSH 转发，只对本轮拥有的随机临时库执行：空库状态不建表；缺少停写/初始化确认被拒且仍无表；完整初始化和重复执行；历史摘要和时间被篡改时拒绝；无历史或已初始化库出现未管理表时拒绝；两条已发布迁移升级到三条并保留 Unicode 数据；模拟半完成建表被拒。负例修改仅发生在临时库并恢复，不是生产修复步骤。

同一真实入口再次覆盖备份、受控副本、每日互斥、拷贝失败保留、隔离恢复、约束/额度、编译 API 就绪及失锁取消。测试最终确认源库、升级库、恢复库均移除，测试 API 已停止。结构化结果与输入摘要见[结果](results.json)，原始日志仅在本地私有归档。

同步 upstream 无新增提交；18 个任务文件的字节、权限和空暂存状态完整恢复。同步后仅复审本轮差异，重新通过完整工程检查、192 项普通测试、文档检查及专用真实 MySQL 迁移/备份/恢复验收，三个临时库再次确认移除。

## SQL 状态与边界

没有新增或修改 Schema、SQL、迁移元数据或依赖锁文件；三个已发布迁移仅在本轮临时源库和升级库执行。开发库、正式库没有本轮迁移写入，未部署、未上传镜像、未创建或触发 Jenkins。

状态检查证明历史与表集合符合支持的基线，不证明全部列、索引、约束和数据没有漂移，也不证明停写或备份完成。实际目标 TLS/最小权限仍待部署验收；安全 SSH 隔离测试不等于已取得或验收生产 CA。
