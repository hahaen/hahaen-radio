# 目标发布执行器与维护状态

## 需求与实现

交付目标主机手动执行入口与实际更新流程，继续保持正式发布由用户操作的边界。新增完整源树专用 `pnpm deploy:target`：固定正式库/受验证 TLS、不可变 release.json、平台/镜像标签、当前容器归属与迁移材料预检；同主机 flock 和独立数据库 release 会话锁覆盖完整维护窗口，内部备份/迁移短锁仍各自生效。

执行器持久保存 attempt、候选/当前/上一组合及阶段，原子写入并 fsync。维护标记独立只读挂载到 Web；先维护再停写，非空待迁移库先受控备份/副本校验，随后单次迁移、目录就绪、API→Web→jobs、版本记录与公网 HTTPS 检查。真正空库需明确允许；没有目录时需明确开启真实同步，不注入测试数据。

支持完整/分端更新、相同迁移序列的镜像回退和人工确认后的 current/attempt 恢复。遇到中断 attempt 拒绝普通重跑；迁移失败不自动反向执行 SQL、修改历史或重试。失败尽力维持维护并停止自身写入方，持久记录清理是否确认；外部故障不能保证清理必达。恢复必须先由操作者核对实际结构/数据，入口只验证已完成的受支持历史/表集合。

迁移前备份新增创建并复制的单入口，以固定 root helper 切换到无 Docker 权限的备份用户。发布连接和备份私有配置的 host/port/库名/TLS/CA 指纹必须一致，错配在备份前拒绝。活动服务端版本以备份用户私有文件更新，日备份优先读取，避免分端更新后误标版本。模板无真实配置；没有安装 helper、修改目标 sudoers、创建远端任务、执行正式 SQL、上传镜像或上线。

## Review 与修复

范围限定本轮入口/流程/适配器、共享锁的命名抽取、备份目标绑定/版本记录、维护页与 Caddy/Compose/Docker 构建材料、适用测试和文档。读取既有备份、目录就绪和镜像产物验证作为上下文，未调整无关业务。

复审修复：维护探针必须按路由顺序执行，避免固定路径抢先返回 disabled；标记显式 chmod644，避免运行 umask 导致跨用户不可见；备份 ID 使用真实格式；持久完成状态先整体写入，防止失败时丢失 attempt；允许显式恢复中断候选但不重跑迁移；首次空库在 API 前检查/按授权同步目录；备份与外层连接绑定目标指纹；Compose raw env按原始值解析，不能用 dotenv 解引号后的结果冒充容器实际配置。

复审还区分既有健康容器的历史重启计数与本次异常重启：记录原计数，保留服务在窗口内不得新增重启；受更新服务强制重建，启动日志不复用旧进程记录。

完整工程检查（格式、Lint、TypeScript、203项普通测试及前后端构建）通过，普通命令的10项数据库用例按设计跳过；专用真实入口另行通过。新增11项普通测试。原生 Caddy/三浏览器与独立 MySQL 结果见[结构化证据](results.json)。流程测试使用明确的模拟 IO，覆盖顺序、先备份后SQL、失败保留、重跑拒绝、分端保留、变更数据库后回退拒绝、明确恢复、清理失败状态及真实文件原子发布；不把它视为 Docker CLI 实测。

原生 Caddy 2.10.2 用本轮独有临时静态目录与回环端口，验证实际配置、公共503、API POST固定503 JSON、no-store/Retry-After、回环探针及清除标记后首页200。Chromium/Firefox/WebKit 检查1440×900、390×844、320×568，共9组布局；Chromium/Firefox 实际 Tab，WebKit 默认 Tab 不聚焦链接，单列程序聚焦，未将其记作同一键盘验收。另验三浏览器200%文字重排。截图、工具状态及原始日志仅保留本地私有归档；相关进程与标记由本轮清理。

实际 MySQL 验收只使用本轮随机专用源/升级/恢复库，检查 release 锁互斥且可嵌套 maintenance、错配备份拒绝、迁移前备份副本与活动版本记录，并回归既有迁移/备份/恢复流程。没有新 Schema 或迁移 SQL；正式/开发库没有本轮迁移执行。

新增迁移前备份验收最初复用了既有主/副目录，导致旧流程“仅有一份备份”的隔离断言失败；库和API均已清理。修正为本轮独立的两个临时目录，新增错目标不产物与daily读取活动版本而非旧环境值的断言，再复审复验。该失败不记为通过。

同步 upstream 无新增提交，36个任务文件内容、权限和空暂存状态完整恢复。同步后复审并再次通过203项普通测试、完整工程检查、专用MySQL验收（源/升级/恢复库移除）及原生Caddy双端验证。最终暂存复审补齐首次部署已有完整迁移但无current记录时的候选镜像取值，维护探针和停写均使用已选择候选；重新完成相关工程检查。最终复审将独立维护页颜色改为相同夜航语义变量，不改变视觉输出；完成适用格式、文档和原生页面复验。

## 未完成与部署前补测

根 Jenkinsfile 尚未接入目标阶段；实际 Linux flock继承与/proc所有权、Compose生命周期、容器卷/用户权限、sudo/helper、真实CA/最小权限、独立存储和公网DNS/TLS均需目标演练。本机没有 Docker，按用户要求延期实测，不记录为通过。源树目标工具与备份生产包是不同部署材料，不能省略任一依赖。

首次初始化失败且无可运行版本时仍需操作者保全现场、检查实际库并制定恢复方案；不自动清理 attempt 或数据库。备份复制失败可能保留已验证主备份，目标 attempt 只在双副本成功返回后记录ID，操作者须同时检查主备份现场及独立校验，不能凭 attempt 无ID推断没有产物。

总目标继续推进 Jenkins 目标阶段、正式恢复操作手册、普通日志七天保留、完整资源预算和真实手机验收；不将本轮模块完成标记为完整产品完成。返回[执行说明](../../deployment/releases/target-executor.md)、[产品进度](../../product/progress.md)或[归档导航](../README.md)。
