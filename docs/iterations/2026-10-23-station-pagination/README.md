# 搜索电台数字分页

## 需求与变更

将探索电台的上一页／当前页／下一页改为可直接跳转的数字分页，保持现有夜航配色和圆形控件。每页仍为 30 台，结果总数继续在搜索工具行显示。

- 宽面板展示 `1 2 3 4 5 … 末页`，中间页保留首末页和当前页邻居；按面板可用宽度缩减到五个或三个位置。
- 暖白实心当前页、灰绿普通页码、细边框翻页箭头；按钮至少 44×44px，保留键盘焦点与双语可访问名称。
- 兼容完整目录的本地分页与远端查询 offset；单页和空结果不展示分页。
- 搜索和筛选仍复用已有重置逻辑；不改变 API、数据库或播放逻辑。

## Review 与验证

- Review 范围仅为本次搜索分页组件、接入、双语文案和浏览器测试；核对页码边界、数据偏移、响应式尺寸、焦点样式与观察器清理，无未解决问题。已有地球代码和性能测试改动不纳入本次提交。
- Prettier、任务范围 ESLint、前端 TypeScript 检查通过；现有 App 组件回归 3 项通过。
- 前端 Vite 生产构建通过，保留既有大包体提示；文档链接检查通过。
- Playwright 24 项通过：Chromium、Firefox、WebKit、移动 Chromium，覆盖 1440×900、768×1024、390×844、320×700、844×390。逐页、数字跳转、首末页禁用、搜索重置、单页/空结果、英文键盘激活、远端 offset 均通过。
- 已查看桌面、平板、手机、窄屏和横屏截图，分页无横向溢出。截图：[桌面](desktop.png)、[手机](mobile.png)。

- 浏览器用 390 台模拟目录及拦截接口验证，不代表真实外部电台线路验收。复用当前工作区已运行的开发服务；临时 Playwright 配置仅取消重复启动服务，保留原配置的四种浏览器项目，使用两名 worker。
