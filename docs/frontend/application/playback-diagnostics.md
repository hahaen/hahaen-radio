# 手动播放故障报告

“关于与帮助 → 问题反馈”保留原有的本地问题说明与复制，另有独立的精简报告区域。只有当前音频状态确实为 failed、带有效电台/线路标识与固定故障类型时才允许提交；播放中、缺少线路、无故障类型或缺少安全随机能力时禁用。

界面预览标识与故障类型，明确说明将向本站发送哪些字段、有效期和定期清理方式。只有用户点击提交才 POST，没有自动上报、持续遥测、后台重试或访客统计。上方本地问题说明、收藏、历史、网址和音频不在请求体中。

一次提交使用一个内存回执号。网络中断或超时后不声称已收到，手动重试沿用回执；服务暂不可用、旧 API 无报告入口或请求被拒绝时仍可复制本地说明；缺少回执生成能力时显示原因并禁用提交。429 只禁用按钮到建议等待时间结束，不自动再发请求。只有身份匹配的 202 才显示收到与有效期，并说明不会自动下线电台。

关闭、切换主题或更换电台/线路/播放状态会取消旧客户端请求并丢弃迟到结果；服务器已开始的事务可能完成，因此不能把客户端取消描述为服务器撤回。字段与字号、44px 目标、颜色和滚动沿用夜航说明面板，两种语言同时维护。
