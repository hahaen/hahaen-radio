# 关于与帮助面板精简

## 需求与实际变更

按需求移除“资源署名”和“问题反馈”。中英文面板仅保留关于、隐私、帮助，清理署名展示、本地问题说明复制、前端故障报告提交及其专用样式、翻译和测试。隐私说明同步移除已不存在的界面操作，保留播放与原生模态焦点行为。

保留本地资源许可、来源元数据、服务端诊断接口与历史数据清理机制。未改动地球效果相关的已有工作区变更。

## Review 与验证

- 已仅针对本次变更 Review：清理后无残余引用，面板不再读取播放诊断上下文，保留关闭、焦点和播放行为；未发现待修复问题。
- 前端 TypeScript、定向 ESLint、生产 Vite 构建与文档链接检查通过。构建仍有既有大体积 chunk 提示。
- `information.spec.ts` 在 Chromium、Firefox、WebKit 与 Pixel 7 模拟项目共 8 项通过，覆盖双语主题、播放保持、关闭焦点、无横向溢出和 200% 英文文字。
- 检查视口为桌面 1440×900、手机 390×844、窄屏 320×720、平板 768×1024、横屏 844×390；已查看桌面与手机截图，三个主题排列正常。
- 验证使用固定的本地生产构建、可控目录/音源、单 worker 与减少动态效果设置。首次开发服务器回归受到并行修改和热刷新影响，固定构建首轮也出现超时；串行复验全部通过，不据此宣称已验证动画性能。
- 服务端、数据库与真实设备音频专项不适用本次界面删除，未执行。
