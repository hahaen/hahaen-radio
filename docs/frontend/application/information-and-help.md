# 产品说明与本地问题反馈

顶栏“关于与帮助”提供关于、隐私、资源署名、使用帮助及问题反馈。沿用夜航深海底色、衬线短标题、正文留白、原生模态焦点管理与 44px 操作目标；手机主题按钮换行，正文单列滚动，不改变探索主构图。

## 内容与实际行为

中英文正文统一放在 `apps/web/src/locales/i18n.ts`。说明免登录与本地保存、导入合并、浏览器直连电台、按需曲目与歌词、可选识曲、背景与自动播放限制。帮助覆盖探索、固定、筛选、播放失败、睡眠和全部快捷键。打开说明不暂停播放，也不自动进入闲置沉浸。

隐私说明区分本站请求、浏览器直连电台及服务器向歌曲服务发出的请求；没有把第三方电台的处理规则描述为本站可控。收藏和历史不上传，不接入广告或访客行为统计。今后新增诊断收集或改变请求行为时，必须同步实际内容与验证。

## 资源署名

- Radio Browser：电台目录，经过归一化、筛选与周期同步，提供[官方接口入口](https://api.radio-browser.info/)。
- GeoNames cities15000：离线匹配附近城市与时区，说明筛选与归一化，保留来源及 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；[原始数据说明](https://download.geonames.org/export/dump/readme.txt)核对于 2026-10-17。
- Natural Earth：1:110m land 5.1.2，经简化后生成本地轮廓和点阵，链接[官方公有领域说明](https://www.naturalearthdata.com/about/terms-of-use/)。
- LRCLIB 与 AudD：分别说明歌词查询和默认关闭的可选识曲，不声称每首歌可匹配或拥有可靠直播位置。
- 三种本地字体：在产品面板可打开随构建分发的完整 OFL 许可；更新规则见[字体文档](../design/fonts.md)。
- Lucide：`apps/web/public/licenses/lucide.txt` 与当前安装版本的完整许可一致，保留 ISC 与包含的 Feather MIT 声明；不是重新撰写或截取后的许可。

## 本地反馈

没有用户提供的公开联系渠道，因此面板明确说明暂未配置在线联系，不编造邮箱、账号或自动提交入口。用户可以预览并复制问题说明，自行补充重现步骤、浏览器、设备和结果后转交；剪贴板拒绝时保留可选文本手动复制。复制不代表已提交。可另行通过[精简故障报告](playback-diagnostics.md)主动提交当前线路的固定故障；这不会发送上方的问题说明。

状态快照只使用明确字段：生成时间、界面语言、经过校验的电台与线路 ID、播放状态和固定错误类型。不会复制音源 URL、完整页面 URL、任意异常、收藏、历史、原始 IP、用户代理或音频。内容仅在内存存在，关闭或切换反馈主题后丢弃，不持久保存、不发送请求。该本地说明与精简故障报告是两个独立动作，各自有明确的数据边界。
