# 电影感夜航

日期：2026-10-21。

## 需求与实际变更

用户认为前一轮仍不够美观，要求继续改善地球及整体界面，并明确选择“电影感夜航：暗夜地球、克制界面、空间感更强”。

实际查看 [Radio Garden](https://radio.garden/) 的地图优先构图、[NTS](https://www.nts.live/) 的播放层级和 [Earth.fm](https://earth.fm/) 的页面留白，再结合现有产品调整。

- 地球从主要依靠均匀点阵表现陆地，改为本地真实地理生成的连续暗色陆地、深色海洋、定向侧光与薄球缘；弱化装饰点，移除经纬网。电台仍逐台绘制，国家级空心点尺寸和亮度降低，精度说明、选择与完整目录保留。
- 本地多边形扫描为 1024×512 单通道纹理，保留内洞、岛屿与南极，无新增资源下载、依赖或底图服务；纹理随引擎释放。
- 桌面宽度至少 1024px 时，地球中心偏至视口 59%，为左侧透明收听区留白；平板和手机保持居中。时钟改为小号实心等宽字，品牌与顶栏更克制，播放按钮改为实心圆。
- 全系统浮层采用 20px 无衬线标题；收藏与帮助使用珊瑚色下划线选中态，筛选复选框与语言搜索统一间距和外观。底部流派条为帮助按钮留出空间。
- 保留此前歌曲清单入口移除、历史歌曲文件兼容、地图说明精简与过时帮助内容清理。
